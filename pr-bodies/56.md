## Summary

Engine builds across lane worktrees: a smaller dev profile, rust-lld pinned for Windows, and the lane rules (job count, sccache, a faster integration binary) written down where briefs can copy them.

```diff
 engine/Cargo.toml
+  [profile.dev]               debug = "line-tables-only"
+  [profile.dev.package."*"]   debug = false
+.cargo/config.toml            # new: rust-lld linker for x86_64-pc-windows-msvc
 docs/testing.md
+  ## Engine builds across lanes
+    ### Job count             1 lane: 6 jobs, 2 lanes: 3, 3 or more: 2
+    ### sccache               machine setup, lane rules, undo
+    ### Build profile
+    ### Integration binary    CARGO_PROFILE_RELEASE_OPT_LEVEL=1 for the integration tier
+    ### Measurements
```

- sccache is a per-machine setup (user's cargo config plus sccache's own config file), not a repo setting: CI has no sccache.
- The integration binary uses `CARGO_PROFILE_RELEASE_*` environment variables, not a named profile, because the harness's `cargo run --release` lives in `eval/` code outside this change. The shipped release profile is unchanged.
- `ci.yml` is unchanged: CI already builds with no debug info, so the cached `engine/target` should not grow.

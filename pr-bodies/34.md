Closes #34

## Summary

`lancet-eval compare` is the 06.3.5 four-arm comparison: its arms, Holm families, P4 rebuild and strata all come from `PREREGISTRATION_06_3_5`. On a store-prefixed run (D-251), it used to fail late with the misleading D-120 "run `lancet-eval score --judged` first" message. It now refuses up front, before any judged dimension is looked up, with a message that names the mismatch.

```diff
 compare --run <store-prefixed judged run>
   build_comparison: D-73 check, load report.json
+  _require_06_3_5_corpus(corpus)
+    token != PREREGISTRATION_06_3_5          -> "corpus 'x' is pre-registered under <TOKEN>,
+                                                 but `compare` is the PREREGISTRATION_06_3_5
+                                                 four-arm comparison; compare this run with
+                                                 `lancet-eval compare-levers`"
+    06.3.5 token, store-prefixed arms        -> "corpus 'x' runs store-prefixed arms [...],
+                                                 but PREREGISTRATION_06_3_5 fixes the
+                                                 unprefixed four arms; `compare` cannot read
+                                                 this run"
   _check_judged_dimensions
-    answer_groundedness__hybrid ... missing  -> "run `lancet-eval score --judged` first (D-120)"
```

I refused the run instead of listing its own arms. Both options were open, and this is the smaller change that holds. Listing the run's arms would only rename the arm list: the Holm families, `_rebuild_primaries`'s arm-set check, the delta strata and the rendering all read `PREREGISTRATION_06_3_5.comparison_arms`, so a non-06.3.5 run would still fail or report the wrong families. Runs under a lever or stage pre-registration already have their comparison: `compare-levers`, which is what S1 reads.

The second guard catches a corpus with no `[preregistration]` section. Such a corpus keeps the 06.3.5 token, yet it may still list prefixed arms, and `compare-levers` refuses 06.3.5-token corpora, so its message gives no pointer to that command.

`_ARM_SLUGS` was unused and is removed. `cli.py` is unchanged.

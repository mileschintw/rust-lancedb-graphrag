```text
chunk_id                    document_id   chunk_index   before

doc:3                       doc           3             3   (engine shape, unchanged)
a#b#7 / a:b:7               a#b / a:b     7             (separator right after the whole document ID)
doc#x, doc#-3, doc#+3,      doc           0             (any other shape, or n not plain digits within i32)
doc#2147483648, other#3
```

- `engine/src/bin/generate_from_context.rs`: `chunk_index_of` accepts `:` or `#` right after the row's document ID,
  and only plain ASCII digits that fit an `i32`. The function's doc comment and the module doc comment now name both
  shapes, and say that any other shape still renders `chunk_index=0`. `chunk_index_of` now also returns `0` for a
  signed suffix (`doc:-1` used to give `-1`, `doc:+3` gave `3`). The engine never writes a signed suffix.
- `engine/src/generate_from_context_tests.rs`: a unit test covering both separators, a document ID that contains a

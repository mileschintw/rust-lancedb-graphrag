This PR is S3's writer extraction, step 4 of the issue. Steps 1-3 (the 2Wiki source, the D-243 split and the `PREREGISTRATION_S3_WRITERS` freeze) merged in #150. Haiku 5.5, Sonnet 5.5 and Opus 5.5 extracted all 6,119 2Wiki passages through OpenRouter's Batch API. Closes #145

## What changed

- **`eval/src/lancet_eval/s3_extract.py`** (new) extends #117's `writer_pilot`. It uses the pilot's request bodies, Claude rewrite, Batch client, manifests, routing check and answer parser.
  - **Units:** one request per passage, as the freeze fixes it: `title\ntext`, in file order, with no length floor. The `custom_id` is `tw-0000` to `tw-6118`.
  - **Estimate:** printed before every submit. It comes from #117's measured tokens, or from the writer's own answers once it has 50.
  - **Staged submit:** `--parts` limits a submit to a number of batches.
  - **Re-fetch:** a later fetch never replaces an answer that already succeeded.
  - **`report`:** counts per writer the runaways (`finish_reason: length`, Refs #156), the schema-invalid answers, reasoning tokens (a missing count is counted apart), spend and routing breaks.
- **`experiments/v1.1/s3-extract/`** holds the batch manifests (batch IDs and body hashes) and `summary.json`. Its `.gitignore` keeps out `chunks.jsonl` and `*.results.jsonl`, which hold Wikipedia text (about 34 MB).
- **`experiments/v1.1/RUN-S3-EXTRACT.md`** (new) is the run guide, the estimates, the result, and the deepseek options for the owner.

## Review

- **Blocker, fixed:** `summarise` subtracted 1 for each missing reasoning count, because the batch client writes -1 for one. It now counts missing reasoning apart.
- **Fixed:** a re-fetch could replace earlier succeeded answers with errors if their batch had expired. `keep_succeeded` restores them. A test covers it, as do the tests for `_pending` (staged submits).
- **Notes, left as they are:**
  - The token-model fit includes runaways. There were none here.
  - `usd` counts only succeeded answers. All of them succeeded here.
  - `_o200k_encoding` duplicates the pilot's encoder.
  - deepseek is reported as "deepseek (engine body)" rather than by its slug.

## Departure from the frozen request rule

`PREREGISTRATION_S3_WRITERS_SYNC.request_rule` says each passage is posted "one request at a time".
- **Why it changed:** at about 16 passages a minute the run would have taken more than 6 hours. The owner allowed 8 parallel shards ("Allow 8 shards", 2026-11-01, relayed by the coordinator), with no new constant.
- **What happened:** the sequential run was stopped after 469 answers, all kept. The stop could have dropped at most one in-flight request that was billed but never recorded. The remaining 5,650 passages ran as 8 disjoint shards, one request at a time within each shard.
- **What did not change:** the bodies, the pin, the model and the checks.

The owner also asked for the full text in the repo: "先不管，全都公開repo備份全文，以後真的有需要再下架就好".

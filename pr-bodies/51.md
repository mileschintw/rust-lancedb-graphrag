## Summary

A new pure module, `lancet_eval.reader_request`, turns the engine's `pack` body and a reader declaration into the request a Claude reader arm is sent, plus the exact list of top-level fields it rewrote (D-255). Nothing calls it yet; #52 wires it into `batch submit` and the replay record kind (D-257).

```text
rewrite_pack_body(pack_body: str, reader: ReaderDeclaration) -> ReaderRequest(body, body_json, rewritten_fields)
  refuse a pack body that is not the engine's 8 top-level fields, or that does not round-trip byte for byte
  openrouter: model -> slug; temperature, top_p deleted; reasoning per thinking;
              provider -> {only: ["anthropic"], allow_fallbacks: false}; every other byte unchanged
  anthropic:  Messages body: model, max_tokens, system, one user message (text byte for byte),
              thinking per declaration, output_config.format from the strict json_schema
```

- **Reader declaration.** `ReaderDeclaration(slug, target, thinking, price, effort=None)` is a frozen dataclass, so a pre-registration constant can hold it. `target` is `openrouter` or `anthropic`; `thinking` is `off`, `between_tools` or `on`, and `effort` is set exactly when `thinking` is `on`. `ReaderPrice` holds the sync list price per MTok and must be finite and non-negative. An unknown target, thinking or effort value is refused when the declaration is built.
- **Thinking per target.**
  - `off`: OpenRouter `reasoning: {enabled: false}`; Anthropic `thinking: {type: "disabled"}`.
  - `between_tools`: both targets send `thinking: {type: "between_tools"}`; on OpenRouter it replaces `reasoning`. OpenRouter documents no `between_tools`, so the S2 pilot finds out whether this field passes through (D-255). If OpenRouter drops it silently, Sonnet would run with OpenRouter's default reasoning; the pilot should check `reasoning_tokens`.
  - `on` with an effort: OpenRouter `reasoning: {effort}`; Anthropic sends no `thinking` and sets `output_config.effort` (Opus 5.5 at effort low, Q13).
- **Byte fidelity.** A `pack` body this module could not reproduce byte for byte (not serde's compact form) is refused, so "every other byte unchanged" holds by construction. `body_json` is the exact text to send and hash.
- **No `cache_control`** in any body (D-256). No body carries `temperature` or `top_p`.
- **No I/O, no network.** The module reads nothing and calls nothing.

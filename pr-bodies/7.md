## Summary

Every v1.1 run directory now carries a validated `context_export.jsonl`: one row per success record's question and arm, holding what the reader saw (D-249).

```diff
   drive()
     journal.write_header(...)
+      "context_export": true          # marks a v1.1 run
     ... drive units ...
+    export_context(journal, source)   # terminal_success checkpoints, joined on correlation_id
+      -> context_export.jsonl          # failure: logged, DriveResult.context_export_error
+lancet-eval export-context --run <dir>   # rebuilds the export the same way
 lancet-eval score
   score_run()
+    require_export_rows(journal)      # v1.1 run: refuse a success record with no row
```

```text
eval/src/lancet_eval/context_export.py
├── ContextExportRow / EvidenceEntry / DocumentMetadata   # the row contract
├── validate_row, read_export                              # the one validator (#11, #13 reuse it)
├── CheckpointSource (port)
│   ├── PostgresCheckpointSource                           # psql, batched, quoted trace IDs
│   └── InMemoryCheckpointSource                           # tests (seam S-B)
├── export_context                                         # fail closed, atomic write
└── require_export_rows                                    # score's refusal
```

- A row has the corpus, question ID, arm and question, then the ranked evidence. Each evidence entry carries its rank, chunk ID, document ID, full text, title, section path, content type, score, suspicious flag and document metadata (source, doc title, published date). After the evidence come the graph facts and, for Lancet arms, `assembled_prompt` and `correlation_id`.
- The validator rejects unknown fields, missing fields and empty IDs. It rejects evidence ranks that are not exactly 1..n in order, and a row that has one of `assembled_prompt` and `correlation_id` without the other. In a file, it also rejects a second row for the same question and arm.
- The export fails closed and writes nothing when a success record has no correlation ID, no checkpoint, two checkpoints, a snapshot naming another trace, or a snapshot that breaks the contract. The error names each failing question/arm.
- A record that ended with no evidence exports `"evidence": []`.
- `score` refuses a run whose journal header says `"context_export": true` when the export is missing, has no row for a success record, or has a row whose `correlation_id` came from another attempt. Journals written before this change have no marker and score as before.
- The eval README lists `context_export.jsonl` as the sixth required artifact of a v1.1 run record.

## Summary

A new `structure-merge` chunk strategy, accepted by the gateway and the engine at ingest. `chunk_size` and `chunk_overlap` count o200k tokens (D-251). `structure-aware`, `fixed-size` and the D-09 default are unchanged.

```text
chunk_structure_merge(text, target, overlap)
  for each section (preamble, then each heading up to the next heading)
    open chunk = heading line (if any)
    for each paragraph (split at blank lines)
      if paragraph > target
        close open chunk, except a lone heading: it joins the first window
        emit token windows of `target`, overlapping by `overlap` (never merged)
      else if open chunk + paragraph <= target
        extend open chunk
      else
        close open chunk; open = paragraph
    close open chunk            # short chunks are kept
```

Size rule: every chunk is at or under the target, except a section's heading plus its first window (at most target + the heading's tokens). A heading that does not fit with a fitting first paragraph closes alone.

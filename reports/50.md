## 給 #53 的備註

- CLI 形式與結果檔 schema 已寫在 PR body 的「For #53」兩節，可直接複製。
- Anthropic 的 `stop_reason` 要對應成 chat-completions 的值：`end_turn` → `stop`。其他值都會變成 error 行。
- `usage` 必填，且要過 adapter 的 token 預算檢查（prompt ≤ evidence 預算、completion ≤ max output、total ≥ 兩者和且 ≤ ceiling）。

- Q14 的 `pack` → rewrite → `render` 整合測試（需要已建好的 engine，預設 skip）屬於 #53。

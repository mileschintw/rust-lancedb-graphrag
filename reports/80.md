## Decided while unattended

- `row_sha256` 是對「帶過來之後」（S2 corpus）的 row 算的。理由：#53 寫的 reader row 是 S2 row 的副本，這樣 `row_hash` clause 比的是同一種東西。

- 原生 target 的 `provider` 記 `"api.anthropic.com"`，`is_byok` 記 `None`。
- 原生 target 的 thinking 檢查用新的選填欄位 `content_block_types`，歸在 `reasoning_tokens` code 下。`reasoning_tokens` 維持 `int`，因為其他 lane 的 `lever_comparison.py`、`measure.py` 會讀它。

- `provenance.py` 延遲 import `parity`，避免循環 import。

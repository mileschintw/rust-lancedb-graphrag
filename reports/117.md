## Decided while unattended

- **每批的筆數。** 選項：一個寫入者送 1 批 1,803 筆，或分成 ≤500 筆的多批。選了 ≤500：S2 的 batch 用 500 筆跑成功過，而 OpenRouter 的上限不明。
- **body 的 key 順序。** spec review 指出引擎會把 key 排序。選項：執行中途改成排序，或維持原樣並修正說法。選了維持原樣：對 API 沒有語意差別，中途改會讓同一次 run 的 bytes 不一致。
- **加入「無根據實體」這個指標。** 抽查發現 deepseek 會帶入 chunk 外的實體。這是免費、可逆的分析。報告裡明確寫了它混合了改寫與外部知識，不能當成幻覺率。

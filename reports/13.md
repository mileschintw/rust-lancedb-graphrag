- `src/lancet_llamaindex/corpus.py`：讀取 `documents.subset.jsonl`，透過 `document_map.json` 以 seeder 同一套 corpus ID（標題）對到 Lancet 的 document ID。對不到、重複、沒有內文或格式壞掉的列都會 fail closed，錯誤訊息帶檔名與行號。metadata 只放 `title`、`source`、`published_at` 三個原始值。

- `src/lancet_llamaindex/pipeline.py`：`SentenceSplitter(256, 25)`，記憶體內 `VectorStoreIndex`，dense top 20，自訂 `VoyageRerankPostprocessor` 保留 8 筆。每一列都用 harness 的 `validate_row` 檢查，`write_outputs` 先用 `read_export` 讀回暫存檔，全部通過才寫出 `context_export.jsonl` 與 `pipeline_config.json`。chunk ID 為 `<document ID>#<n>`，`index_fingerprint` 在重建後保持不變。
- `pipeline_config.json`：保留巢狀結構，頂層另有 lane 12 合約要求的 `framework`、`framework_version`、`chunk_size`、`chunk_overlap`、`dense_top_k`、`rerank_model`、`keep`、`index_fingerprint`。
- `src/lancet_llamaindex/cli.py`：`lancet-llamaindex export --corpus --arm --out`。`--arm` 為必填，#14 會傳 `llamaindex`。可用 `--questions`、`--documents`、`--document-map` 覆寫輸入檔，供 fixture 使用。沒有 `OPENROUTER_API_KEY` 時會在任何呼叫之前就停下。
- `conftest.py`（專案層）：在沒有 LlamaIndex 的環境中忽略 `tests/`，讓 repo 根目錄的 `uv run --project eval pytest` 不會收集到這些測試。
- `README.md`：設定表、`input_type` 說明（公平規則 7）、未執行的 live 檢查指令、執行方式，以及付費與 held-out 的警告。

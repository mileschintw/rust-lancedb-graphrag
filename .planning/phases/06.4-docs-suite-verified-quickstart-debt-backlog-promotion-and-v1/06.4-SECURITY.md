## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Client → gateway (HTTP JSON) | Strict decode of the RAG query body; the new `disable_default_levers` field and UTF-8 metadata checks | Untrusted request fields |
| Gateway → engine (gRPC) | Regenerated proto with explicit graph state and the lever opt-out | Validated request, notices |
| Process environment → engine/harness | `LANCET_ENGINE__GRAPH__*` and drive-environment variables, parsed fail-closed or refused | Config overrides |
| Harness → OpenRouter (paid) | Preflight canaries and quickstart queries under the D-222 spend cap | API key (never printed), prompts |
| Orchestrator → clone key file (Windows and WSL) | Key written over PowerShell or stdin, length-only output, deleted on exit | Live API key |
| Quickstart run → owner dev stack | D-230 stop and restore, never with `-v`; volume CreatedAt compared | Owner Postgres data |
| Committed docs and evidence → public repo | Transcripts, trace JSON, PNG captures and docs, all checked by redaction | Possible secret leakage |
| Run-of-record data → docs | `eval/runs/` read-only; quote checker blocks re-derived figures | Published results |

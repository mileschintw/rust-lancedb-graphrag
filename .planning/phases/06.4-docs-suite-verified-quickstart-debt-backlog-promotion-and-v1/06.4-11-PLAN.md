**Run constraints.**
- Live and paid: the declared cap is $0.30 settled for the WSL run, inside D-222's $1.00, with the Windows delta already counted.
- Run sequentially on `main`, never in a worktree.
- Every WSL action is a committed script (`qs-wsl-run.sh <clone> <ev> <step>`), invoked as `MSYS_NO_PATHCONV=1 wsl.exe -d Ubuntu -- bash /mnt/d/Repos/lancet/.planning/phases/06.4-docs-suite-verified-quickstart-debt-backlog-promotion-and-v1/qs/<script> ...`.
- The services run inside a WMI-created `wsl.exe` (`qs-wsl-host.ps1`), which keeps the distro alive between calls.
- No call is expected to exceed about 8 minutes.

**STOP PROCEDURE:**
1. `wsl.exe -d Ubuntu -- bash <qs-wsl-stop.sh> <ev>`, then `taskkill /F /PID <host.pid>`;
2. `qs-wsl-run.sh <clone> <ev> teardown` (`docker compose -p lancet-qs --profile observability down -v`);
3. from `D:/Repos/lancet`, `docker compose -p lancet --profile observability up -d`, and assert the six `lancet-*` containers run;
4. delete the clone's `.env` in WSL;
5. append `## Halt` to the transcript, run the redaction check, and commit;
6. write the SUMMARY with `status: halted` and report for the owner.

**Deviation rule,** the same as plan 06.4-09:
- (a) A doc-only, sample or `qs/` fix touching nothing under `engine/`, `gateway/`, `proto/`, `config/` or `eval/src/`:
  1. commit it in `D:/Repos/lancet`;
  2. stop the services, tear down `lancet-qs` with `-v`, and delete the clone's `data/lancedb`;
  3. `git -C <clone> pull --ff-only`;
  4. repeat from compose-up, at most ONCE.
- (b) Anything else: run the STOP PROCEDURE.

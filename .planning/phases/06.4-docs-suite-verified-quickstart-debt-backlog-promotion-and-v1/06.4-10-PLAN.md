         is absent or the process is gone.
       - `-WriteEnv -Clone <wsl path>`: it reads `[Environment]::GetEnvironmentVariable("OPENROUTER_API_KEY","User")`

       - `rescore` (offline), `teardown`;
       - `preflight-start <n>`: starts the README preflight under `setsid nohup`, with output to

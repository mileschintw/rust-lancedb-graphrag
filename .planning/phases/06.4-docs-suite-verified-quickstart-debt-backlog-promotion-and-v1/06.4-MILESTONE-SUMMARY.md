## Delivered

**Delivered:** A Go HTTP gateway and Rust gRPC engine that ingest Markdown, text and JSON into LanceDB, answer questions
over hybrid vector plus BM25 retrieval with an optional knowledge-graph context, stream workflow events over SSE, trace
every request through OpenTelemetry to Jaeger, Prometheus, Loki and Grafana, and are evaluated by a Python harness against
MultiHop-RAG with the runs of record, the limitations and the quickstart written up in the README and `docs/`.

## Key accomplishments

- **Contract and gateway (Phase 1).** A stable gRPC contract between the Go API gateway and the Rust RAG engine, with a
  local development path (`go run`, `cargo run`, Docker Compose).
- **Ingestion and storage (Phases 2 and 4.1).** Fixed-size and structure-aware chunking, LanceDB storage with the
  nodes, edges, entities, entity_edges and communities tables, and entity and relationship extraction persisted as a
  graph (DATA-04, DATA-05, RAG-05 satisfied in 4.1).
- **Hybrid retrieval and the RAG path (Phase 3).** Dense vector plus BM25 retrieval with fusion and deduplication, and
  grounded answers with citations.
- **A fixed RAG state machine with streamed events (Phase 5).** Query, reformulate, retrieve, graph, prompt, answer,
  complete or failed, with cancellation, timeouts, retries, PostgreSQL-backed checkpoints and SSE workflow events.
- **Hardening and index rebuild-and-swap (Phases 6 and 6.1).** Module-graph restructure, a consolidated wire contract,
  degraded-mode, citation-repair, bad-input and graph-unavailable hardening (RAG-03), and a rebuild-and-swap index
  lifecycle with deterministic proofs.
- **Observability (Phase 6.2).** OpenTelemetry traces, metrics and logs across Go and Rust via a Collector to Jaeger,
  Prometheus, Loki and Grafana (OBS-01).
- **An evaluation harness that can be believed (Phases 6.3 to 6.3.5).** A Python harness over MultiHop-RAG with
  failure-visible provenance, per-path health, paired ablation, latency-derived timeout budgets, an index-identity
  repair, and a held-out four-arm matrix (dense-only, BM25-only, hybrid, hybrid+graph) with Hits@k and MRR beside
  Lancet's own metrics (OBS-02, OBS-04, OBS-05, OBS-06). A first run was marked SUPERSEDED rather than rewritten.
- **Quality levers measured as arms (Phase 6.3.6).** Rerank and evidence metadata ship as defaults (rerank by owner
  disposition D-193 with the D-192 latency caveat; evidence metadata by the pre-registered rule). Graph-v2 and the binary
  answer format stay off after no Holm rejection (`06.3.6-CLOSEOUT.md`).
- **Docs, a verified quickstart and closure (Phase 6.4).** A README and `docs/` suite (design narrative, evaluation,
  observability, API contract, build history), a quickstart whose commands were run from a fresh clone on Windows and
  WSL with recorded transcripts, 18 debt items promoted to backlog phases 999.13 to 999.17 plus 27 review deferrals in
  999.18 and 999.19, and an obligations ledger.

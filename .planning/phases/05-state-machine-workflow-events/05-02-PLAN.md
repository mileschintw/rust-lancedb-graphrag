## Review dispositions carried into this plan

- The inline-remainder handoff from 05-01 is made concrete: after `ReformulateQuery`, this plan moves graph and retrieve into runner-owned nodes, then calls `run_inline_prompt_generation_remainder`; that bridge owns the next terminal and is removed only when 05-03 installs prompt/generation nodes.
- Cross-variant fusion is not left to an implementation guess. The bounded contract is at most eight ordered variants; dense retrieval/embedding is variant zero only per D-08, BM25 is evaluated for every variant, each source is deduplicated before rank assignment, total fused score is the sum of finite source contributions, public source rank/score fields use the highest-scoring contribution with lowest variant-index tie-break, and bounded per-variant provenance retains every contribution used in the sum. One variant must match the existing fusion score/order behavior.
- Graph timeout follows the research resolution of the AI-SPEC open question: inner timeout becomes the same empty-context degrade as logical graph failure, while the runner's outer timeout remains a backstop. D-30 means no new durable degraded-mode field is added.
- Reranker failure is a retrieval failure and is included in the phase matrix; it is not converted into zero evidence.

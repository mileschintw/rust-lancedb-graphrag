<objective>
Close UAT gap G-05-1's live execution blocker: OpenRouter's live `/api/v1/models` endpoint returns the complete model catalog, which is several megabytes and exceeds the 256 KB `MAX_PROVIDER_RESPONSE_BODY_BYTES` limit in `read_body_limited`. This caused `GenerateAnswer` to fail with "model capabilities response exceeds maximum body limit of 262144 bytes".

Purpose: Support multi-megabyte model metadata catalog responses from OpenRouter while preserving tight 256KB body bounds on embeddings and chat completion endpoints.
Output: Dedicated `MAX_MODELS_METADATA_BODY_BYTES` constant (10 MB), `read_body_limited_with_limit()` helper in `engine/src/client/mod.rs`, updated `fetch_capabilities()` in `engine/src/generation/openrouter.rs`, and unit tests in `engine/src/client/tests.rs`.
</objective>

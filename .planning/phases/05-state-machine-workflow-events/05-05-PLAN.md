<objective>
Complete ORCH-04 by giving the checkpoint payloads 05-01 through 05-04 have been carrying inside `WorkflowContext` an actual durable home: a new `workflow_checkpoints` Postgres table, written by Go (never by Rust directly, per D-26) as a fire-and-forget side effect of the same SSE-forwarding loop 05-01 built, sourced from a full-snapshot JSON payload the `WorkflowRunner` attaches to each `NodeCompleted` event.

</objective>

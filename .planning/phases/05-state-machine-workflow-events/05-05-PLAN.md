## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rust checkpoint event -> Go SQL parameters | Provider-derived and accumulated context bytes enter a parameterized persistence path. |
| Go sink -> PostgreSQL | Detached writes cross into the durable database using the existing Go-owned connection. |
| PostgreSQL -> test inspection | Integration fixtures create isolated schemas and inspect ordered rows. |
| client disconnect -> detached persistence | Request cancellation can overlap a background insert and must not create partial JSON. |

| T-05-05-01 | Injection | InsertWorkflowCheckpoint | high | mitigate | Use generated parameterized sqlc insert, never string-built SQL, and validate JSONB through the database. |
| T-05-05-02 | Information disclosure | context_snapshot JSONB/SSE DTO | high | mitigate | Keep raw snapshots in the explicitly accepted durable boundary, strip them from SSE, and log only safe failure metadata. |

| T-05-05-04 | Repudiation | trace/order columns | medium | mitigate | Persist trace_id and sequence_ordinal and index/query them together; do not rely on timestamp ordering. |
| T-05-05-05 | Tampering | integration test isolation | high | mitigate | Use unique per-test schema for every writer/reader and make setup/snapshot errors fatal. |

## Review dispositions carried into this plan

- The harness uses injected graph/dense/BM25/reformulator/reranker/generator fakes, so timeout, retry, and failure behavior is deterministic and does not depend on OpenRouter or LanceDB latency.
- The matrix includes reranker hard failure as RetrievalFailed, graph timeout as empty-context success, and zero evidence as a runner short-circuit; these are not interchangeable outcomes.
- Checkpoint backpressure is tested at the correct ownership boundary: this Rust harness retains the five service boundaries in order and asserts full envelope/snapshot semantics without constructing the Go `CheckpointDispatcher`; the sixth direct handoff is a Go unit test in 05-06 Task 2, not a service-path claim.
- Every focused registration guard filters comments/headers before counting and asserts a positive count; no bare unfiltered equality gate is used.
- No retry backoff/jitter test is added because D-12 locks immediate byte-identical retry without backoff.

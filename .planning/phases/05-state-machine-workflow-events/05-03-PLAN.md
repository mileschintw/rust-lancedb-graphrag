## Review dispositions carried into this plan

- The former `run_inline_prompt_generation_remainder(&mut WorkflowContext, &WorkflowDependencies, &WorkflowEventSink, &CancellationToken) -> Result<(), NodeError>` is replaced in this plan by explicit AssemblePrompt and GenerateAnswer nodes. Its contract is preserved at the handoff: the input contains identity, original query, ordered variants, variant-0 embedding, graph context, vector results, BM25 results, and final candidates; the bridge may mutate only assembled_prompt and answer, emits only its two node lifecycle/checkpoint boundaries, returns the first typed failure, and never emits a terminal. The runner, not a node or bridge, owns zero-evidence short-circuit and the single terminal builder.
- The D-17 amendment is authoritative: `generation_node_timeout_ms=65000` wraps up to two existing 30-second provider attempts. The 30-second value remains inside `Generator::generate`; using it as the outer node deadline is rejected as an arithmetic bug. The test harness overrides both values below one second when needed.
- Retry uses one immediate byte-identical request and no backoff per D-12. A suggestion for jitter/backoff is rejected and recorded rather than implemented.
- Generated response/model coverage is explicit: tests exercise valid JSON, schema validation failure, provider failure, retry success, retry exhaustion, cancellation between attempts, and no answer event on every failure path.
- Full accumulated snapshots, not deltas, are emitted after each node boundary; D-30's deferred workflow metadata is not introduced.

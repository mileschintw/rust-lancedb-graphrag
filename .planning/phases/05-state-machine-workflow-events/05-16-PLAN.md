## Review resolution

The former production snapshot guard that searched the whole file for a generic `clone()` token is vacuous because unrelated service code also clones values. Replace it with a source-scoped assertion over the BM25 adapter: the production field must use `RwLock<Arc<Bm25Index>>`, the snapshot region must clone the inner Arc before the retrieval call, and the read-guard binding must not remain live across the subsequent await. The writer-progress test remains the behavioral proof and must use its own writer because the live engine currently has no ingestion-write call site in this test.

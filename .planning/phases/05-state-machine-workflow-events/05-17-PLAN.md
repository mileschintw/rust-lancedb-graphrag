Task 2 owns the four hand-written construction and round-trip test files (`engine/src/main.rs`, `engine/src/workflow/nodes/retrieve.rs`, `engine/src/retrieval/tests.rs`, and `gateway/main_test.go`) and consumes the generated fields without editing generated output. No task overlaps the other task's files, and no new RPC or external capability is included. The plan remains one unit because 05-16 consumes the complete generated retrieval contract and 05-19 consumes the generated terminal-notice field; splitting the source/codegen and literal/test halves into separate plans would add a partial-wire state to the existing DAG without reducing file ownership. Historical 05-01, 05-02, and 05-06 retain their existing atomic scope rationales and frozen contracts; this plan does not rewrite those executed artifacts.
</scope_rationale>

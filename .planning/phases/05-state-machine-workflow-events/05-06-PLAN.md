## Review dispositions carried into this plan

- 05-01 leaves the Go generated API in its unary state; this plan is the only coordinated codegen landing. A precondition checks that transition state, then full configured Rust+Go generation and all Go call-site migration happen before the gateway suite is claimed green.
- `/rag/query` is removed from the blanket chi `middleware.Timeout(60*time.Second)` group rather than given a shorter replacement. The explicit arithmetic is 5 + 10 + 15 + 2 + 65 = 97 seconds; the workflow's node budgets and D-16 client cancellation provide the bounds.
- `generation_node_timeout_ms=65000` is mandatory per the 2026-08-12 D-17 amendment. `openrouter.generation_timeout_secs=30` remains the per-attempt provider limit; the plan never collapses those keys.
- The first gRPC frame is prefetched so session/correlation headers can be committed before SSE status. Malformed validation remains a plain HTTP 4xx/tonic Status; d1 trailer metadata is only asserted for an actual pre-stream transport error that emits it. In-stream failures are typed SSE events and normal stream closure.
- The dispatcher uses primary capacity one, owned overflow capacity five, and an explicit `Pending` result carrying the envelope if direct admission exceeds the service contract. It never treats a bounded `try_send` loss as success, and its close path drains owned records. The sixth-record scenario is named as a direct handoff unit test because the fixed workflow has at most five checkpoint boundaries.
- The review suggestion to reduce this to drop-only admission is explicitly rejected: the locked phase contract and D-27 require accepted checkpoint ownership to remain explicit, while the five-boundary workflow keeps the retained queue bounded. The implementation surface is kept narrow by placing the sixth-envelope assertion only in this Go-owned dispatcher task and reusing the same dispatcher in 05-05, rather than duplicating queue policy or claiming six service checkpoints.
- A reviewer suggestion to add retry backoff/jitter is explicitly rejected: D-12 requires one immediate byte-identical retry with no backoff.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| HTTP client → Go `/rag/query` | Untrusted request JSON and connection lifetime enter the SSE handler. |
| Go gateway → Rust QueryRAG | Generated server-streaming messages and trailer metadata cross the process boundary. |
| Rust configuration environment → engine startup | Environment overrides influence timeout and retry resource budgets. |
| Go event adapter → SSE client | Typed workflow payloads are serialized for an untrusted client without checkpoint JSON. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-23 | Tampering | QueryRAG stream/SSE adapter | high | mitigate | Prefetch the first event, preserve trailer-derived identity, serialize generated typed payloads, and keep checkpoint-only events out of the public DTO. |
| T-05-24 | Denial of Service | SSE route and timeout settings | high | mitigate | Exempt `/rag/query` from the stale global 60-second timeout, retain bounded Rust per-node budgets, and validate the two-attempt generation envelope before startup. |
| T-05-25 | Information Disclosure | SSE event serialization | medium | mitigate | Map only client-visible oneof payloads to SSE and dispatch standalone checkpoint JSON to persistence without writing it to the response. |
| T-05-26 | Spoofing | trace_id/session_id | medium | mitigate | Use server-minted correlation_id as trace_id and assert it remains independent from session_id in transport tests (D-29). |
</threat_model>

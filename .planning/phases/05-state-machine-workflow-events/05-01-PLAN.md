## Trust Boundaries

| Boundary | Description |
|---|---|
| HTTP client → Go `/rag/query` | Untrusted JSON body and connection lifetime enter the gateway. |
| Go gateway → Rust QueryRAG | Internal gRPC request and streaming event contract crosses a process boundary. |
| Rust event producer → client stream | A slow or disconnected consumer can affect event delivery and cancellation. |
| Cargo registry → engine build | Reviewed Rust dependencies enter the build graph. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | Tampering | QueryRAG/SSE contract | high | mitigate | Keep pre-stream validation before channel creation, preserve trailer identity, and serialize only typed generated WorkflowEvent payloads. |
| T-05-02 | Denial of Service | Rust event channel and detached runner | high | mitigate | Use a bounded channel, awaited client-event sends, receiver-closure cancellation, and a supervisor that terminates on both natural completion and disconnect. |
| T-05-03 | Information Disclosure | NodeFailed messages | medium | mitigate | Map internal errors to the closed D-22 taxonomy and sanitize client messages while retaining detail only in existing structured logs. |
| T-05-04 | Spoofing | trace_id/session_id identity | medium | mitigate | Mint correlation_id server-side, copy it to every event trace_id, and assert it remains distinct from session_id. |
| T-05-SC | Tampering | Cargo dependency installation | high | mitigate | Use only the RESEARCH.md package-legitimacy-approved `tokio-util` and `tokio-stream` entries, regenerate the lockfile, and run all builds with `--locked`; no [ASSUMED] or [SUS] package is introduced. |

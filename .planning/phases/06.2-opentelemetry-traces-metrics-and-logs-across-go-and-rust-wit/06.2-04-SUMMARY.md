# Phase 06.2 Plan 04 Summary: Ingestion Stage Spans & Linked Rebuild

## Executive Overview
Plan 04 completes the ingestion telemetry surface and rebuild observability requirements (OBS-01, D-30) across the Engine:
1. **Document-Scoped Ingestion Span & Context Carry**: Added `ingest_document` root span wrapping worker execution, carrying W3C traceparent injected at admission (`ingest_admission` RPC span) across the bounded Tokio queue. Preserved existing child spans (`index_document`, `chunk_document`, `embed_document`, `persist_document`) with explicit lexical construction nesting.
2. **Graph Extraction & 4 Ingestion Leaf Spans**: Added `graph_extraction` span wrapping entity extraction under `ingest_document`, plus 4 granular leaf spans wrapping external calls:
   - `extraction_attempt` (one per retry iteration of `extract_with_retry`, recording `attempt` and `outcome`)
   - `graph_entity_lookup` (`db.system = "lancedb"`, `db.operation = "select"`, `lancet.graph.known_entity_count`)
   - `entity_name_embedding` (`gen_ai.request.model = %embedder.model_id()`, `lancet.graph.new_entity_count`)
   - `graph_entity_persist` (`db.system = "lancedb"`, `db.operation = "mutate"`, `lancet.graph.prior_entity_edges`, `lancet.graph.written_entity_edges`)
3. **Observable Debounced Rebuild with Span Links**: Implemented `RebuildTriggerLinks` (bounded ring buffer with 1024 capacity to prevent unbounded growth) that captures triggering documents' span contexts at indexing completion. When debounced rebuild fires, `index_rebuild` span is created with span links to all coalesced triggering documents, recording `lancet.index.rebuild.trigger_count`, `lancet.index.generation_before`, `lancet.index.generation_after`, and `lancet.index.rebuild.degraded`.
4. **Verification & Gates**: Created 16 comprehensive unit tests in `engine/src/tests/telemetry_ingest.rs` covering all span hierarchies, queue context carry, startup recovery new root behaviour, degraded rebuild recording, trigger link coalescing and draining, and privacy protection (no raw text, filenames, or SQL predicates in attributes). All 404 engine lib tests and 98 Go gateway tests pass. Updated `scripts/engine-test-targets.sh` gate from 428 to 444 total tests.

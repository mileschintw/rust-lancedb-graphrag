# Phase 06.2 — Security Contract

> Per-phase security contract: threat register, accepted risks, and audit trail for OpenTelemetry Traces, Metrics, and Logs.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Client → Gateway HTTP | Inbound HTTP `/rag/query` and ingestion requests | Untrusted `traceparent` / `tracestate` headers |
| Gateway → Engine gRPC | Internal loopback gRPC transport | Propagated trace context metadata |
| Service processes → Collector OTLP | Telemetry export pipeline | Exported spans, metrics, and structured logs |
| Host → Container endpoints | Published container ports (Prometheus, Grafana, Loki, Jaeger) | Loopback-bound (`127.0.0.1`) query and scrape traffic |
| SDK internal diagnostics → console | Error reporting when telemetry backends are down | Bounded diagnostic messages |

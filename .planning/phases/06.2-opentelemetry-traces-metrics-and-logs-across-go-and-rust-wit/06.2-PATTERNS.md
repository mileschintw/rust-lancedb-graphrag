**Metric types per D-35:**
- Query latency histogram (by outcome: completed/failed/degraded)
- Retrieval path failure counter (dense/BM25/graph, by kind)
- Degraded-answer counter (by `answer_basis`)
- Citation repair/drop counter
- Generation retry counter
- Evidence-set size histogram
- Ingest document counter
- Ingest chunk counter
- Index rebuild duration histogram
- **Corpus generation gauge** — must use numeric `nodes_version` (NOT string generation), mapped from `CorpusSnapshot.nodes_version`

// InitProviders creates and returns trace, metric, and log providers,
// plus a shutdown function. D-38: If Collector is unreachable,
// returns non-nil providers with console/stdout fallback; error is logged as warning.
func InitProviders(ctx context.Context, collectorAddr string) (
    trace.TracerProvider,
    metric.MeterProvider,
    *log.Logger,
    func(context.Context) error,
    error,
) {
    // D-43: Service identity
    res, err := resource.New(ctx,
        resource.WithAttributes(
            attribute.String("service.name", "lancet-gateway"),
            attribute.String("service.version", "..."), // from build
            attribute.String("deployment.environment", "dev"),
        ),
    )
    if err != nil {
        return nil, nil, nil, nil, err
    }

    // D-34: OTLP exporters target Collector
    traceExporter, err := otlptracegrpc.New(ctx,
        otlptracegrpc.WithEndpoint(collectorAddr),
        // D-38: No error on Collector down; async export failure is non-fatal
    )
    // ... similar for metrics and logs ...

    // D-32: Always-on sampling
    tp := trace.NewTracerProvider(
        trace.WithBatcher(traceExporter),
        trace.WithSampler(trace.AlwaysSample()),
        trace.WithResource(res),
    )
    // ... meter provider and logger provider ...

    return tp, mp, consoleLogger, shutdownFunc, nil
}

// PropagatorSetup configures W3C trace context propagation globally.

    otel.SetTextMapPropagator(propagation.NewCompositeTextMapPropagator(

    ))
}

## Shared Patterns

### W3C Trace Context Propagation (D-27, D-28)

**Apply to:** All RPC boundaries (gateway → engine) and HTTP inbound (client → gateway)

**Source:** RESEARCH.md Pattern 2, lines 556-592

**Key contract:**
1. Go `otelhttp.NewHandler` extracts inbound `traceparent` from HTTP headers
2. Go `otelgrpc.NewClientHandler` injects the active SpanContext into gRPC metadata
3. Rust must extract from tonic `Request::metadata()` before `into_inner()`
4. Both use standard propagators; no hand-rolled W3C parsing
5. Invalid/absent `traceparent` follows standard propagator fallback (local valid root)

---

### Telemetry Initialization Lifecycle (D-36, D-38, D-43)

**Apply to:** Both `engine/src/main.rs` and `gateway/main.go`

**Key contract:**
1. Providers initialized at service startup before starting servers
2. **D-38:** Missing Collector does NOT fail startup; log warning, keep console output independent
3. **D-43:** Resource includes `service.name`, `service.version`, `deployment.environment`
4. **D-36:** Reuse existing `tracing` spans + events; bridge them to OTel via `tracing-opentelemetry` (Rust) and `otelzap` (Go)
5. Explicit shutdown with bounded timeout before process exit

---

### Span Ownership and Nesting (D-29, D-31)

**Apply to:** All instrumentation points

**Key contract:**
1. Five workflow node spans are created ONLY in `WorkflowRunner::run_node`, not duplicated in node implementations
2. Leaf spans (external calls) are created at the actual I/O boundary (retrieval, embedding, LLM, graph)
3. Root span (SSE stream) covers entire query lifecycle; terminal outcome recorded before close
4. D-29: LLM retries create sibling attempt spans with attempt=1, attempt=2 attributes
5. Use `.instrument(span)` for async blocks to preserve parent-child relationships

---

### Config Validation — Fail-Closed on Invalid Present Values (D-84)

**Apply to:** Telemetry configuration keys in both services

**Source:** `gateway/internal/config/config.go:56-61` (validation pattern)

**Key contract:**
1. If a telemetry config key is **present** but **invalid** (e.g., malformed endpoint, invalid sampler), fail service startup
2. If a key is **absent**, use sensible default (e.g., localhost:4317 Collector, always-on sampling)
3. If **all** config is valid but Collector is unreachable at runtime, do not fail; treat as non-fatal async export error
4. Schema validation (endpoint URL format, sampler ratio bounds) is explicit and early

Example validation:
```rust
// In engine config validation
if let Some(otel_endpoint) = &settings.telemetry.otlp_endpoint {
    if !otel_endpoint.parse::<Uri>().is_ok() {
        panic!("TELEMETRY_OTLP_ENDPOINT is malformed: {}", otel_endpoint);
    }
}
```

### Bounded Metrics Dimensions (D-35, D-42)

**Apply to:** All metrics instruments

**Key contract:**
1. Metric labels use ONLY bounded enums: `outcome` (completed/failed/degraded), `path` (dense/bm25/graph), `kind`, `answer_basis` (RETRIEVAL/MIXED/MODEL_ONLY)
2. Never use query text, session ID, document ID, trace ID, or arbitrary model names in labels
3. Corpus generation gauge uses numeric `nodes_version` (u64), not string generation
4. Metric names follow OTel semantic conventions where they exist (`gen_ai.*`, `db.*`, `http.*`); domain-specific names elsewhere

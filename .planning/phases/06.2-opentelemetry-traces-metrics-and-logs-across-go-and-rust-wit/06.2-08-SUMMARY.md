# Phase 06.2 Plan 08 Summary: Configured Model Accessor Span Attributes

## Executive Overview
Plan 08 closes CR-03 by replacing hardcoded `gen_ai.request.model` span attribute literals with dynamic accessors from configured providers (D-42, D-43):
1. **Embedding Request Span Model Binding**:
   - Updated `ProductionEmbeddingPort::embed_variant_zero` in `engine/src/service.rs` to set `gen_ai.request.model = %self.embedder.model_id()`, mirroring the ingestion pipeline span in `engine/src/ingest.rs` (`entity_name_embedding`).
   - Overrode `TestEmbeddingProvider::model_id` in `engine/src/tests/telemetry_query.rs` to return `"test-embed-model-override"`.
   - Updated `leaf_span_embedding_request_wraps_real_http_call` to assert exact attribute equality with `"test-embed-model-override"`.

2. **LLM Attempt Span Model Binding**:
   - Added `fn model_id(&self) -> &str` with default `"unspecified"` to the `Generator` trait in `engine/src/generation/mod.rs` to maintain compatibility with existing test doubles.
   - Implemented `model_id(&self) -> &str` on `OpenRouterGenerator` in `engine/src/generation/openrouter.rs` to return `&self.config.model`.
   - Updated both attempt spans (attempt 1 and retry attempt 2) in `GenerateAnswerNode` (`engine/src/workflow/nodes/generate.rs`) to record `gen_ai.request.model = %generator.model_id()`.
   - Overrode `model_id` to return `"test-gen-model-override"` on `RetryableGenerator` and `SingleSuccessGenerator` in `engine/src/tests/telemetry_query.rs`.
   - Updated `llm_attempt_spans_are_two_siblings_on_retry` and `llm_attempt_span_is_single_without_retry` to assert exact attribute value equality with `"test-gen-model-override"`.

## Phase User Story

**As an** operator who set `otlp_endpoint` to an `https://` URL, **I want to** export OTLP over TLS, **so that** telemetry is not silently sent in cleartext (CR-04, D-84).

<objective>
Close CR-04: branch gateway OTLP gRPC exporters on the parsed URL scheme. http keeps insecure transport for the local Collector; https uses client TLS. Prove https does not select insecure transport.

Purpose: config validation already accepts https; Init must not strip that guarantee.
Output: shared helper, three exporters wired through it, table-driven tests.
</objective>

# Phase 06.2 Plan 06 Summary: Log Correlation, Workflow Metadata, and Degraded Mode Derivation

## Executive Overview
Plan 06 completes the telemetry integration contract across Go and Rust by hardening request vs background log correlation (D-38), implementing full D-41 workflow metadata on events and spans, and consolidating degraded mode derivation into one canonical rule (D-31):
1. **Gateway Log Trace Correlation**:
   - Explicitly mapped request-owned logs (`insert document`, `rag query stream opened`, `retain pending checkpoint failed`) to attach OpenTelemetry trace context via `telemetry.Ctx(ctx)`.
   - Verified that background logs (`compensate failed ingestion`, reconciler logs, and server lifecycle logs) omit OTel trace context while preserving plain string correlation attributes (`document_id`).
   - Added unit tests in `gateway/internal/telemetry/telemetry_test.go` and `gateway/main_test.go` verifying trace parent attachment, lack of user content in log bodies/attributes, and background log decoupling.
2. **Engine Log Correlation Across Instrumented Paths**:
   - Verified tracing subscriber composition (`tracing_subscriber::Registry` with `tracing_opentelemetry` tracer layer before `opentelemetry_appender_tracing` bridge layer).
   - Added 6 unit tests in `engine/src/tests/telemetry_query.rs` asserting that events inside node spans inherit the node span's trace and span IDs, events inside leaf spans inherit the leaf span's specific ID, events outside spans have no trace context, console logging functions without an OTLP provider, logs survive bounded provider shutdown drain, and engine logs carry no user content (query, evidence, prompt, answer text).
3. **D-41 Workflow Metadata & Canonical Degraded Derivation**:
   - Extended `WorkflowContext` with `started_at_ms: i64`, `prompt_tokens: u32`, and `completion_tokens: u32`.
   - Implemented `derive_degraded_mode(&[Notice], AnswerBasis) -> bool` with exhaustive match over all 17 `NoticeCode` variants (11 degrading codes and 6 non-degrading codes).
   - Updated `emit_terminal_once` in `engine/src/workflow/runner.rs` to construct `WorkflowMetadata` with all fields (`started_at_ms`, `completed_at_ms`, `reformulation_used`, `vector_count`, `bm25_count`, `graph_node_count`, `graph_edge_count`, `prompt_tokens`, `completion_tokens`, `degraded_mode`), record matching attributes on the root `query_rag` span, and include metadata on the terminal `WorkflowCompletedEvent` (both success and error paths).
   - Updated `gateway/main.go` to record `lancet.degraded_mode` on the request span from the terminal frame's metadata.
   - Added SSE metadata forwarding test in `gateway/internal/sse/sse_test.go` and gateway span degraded recording test in `gateway/main_test.go`.
4. **Target Invariant Verification**:
   - Go: Updated `scripts/gateway-test-targets.sh` gate to 107 total tests (gateway: 78, db: 7, config: 4, sse: 9, telemetry: 9).
   - Rust: Updated `scripts/engine-test-targets.sh` gate to 474 total tests (lib: 434, inspect_lancedb: 18, seed_rag_fixture: 0, config_startup: 22).

## Sampling Rate

- **After every task commit:** Run the quick command matching the task's language (`cargo test --manifest-path engine/Cargo.toml --lib -- telemetry` for Rust work, `cd gateway && go test ./internal/telemetry` for Go work).
- **After every plan wave:** Run `cargo test --manifest-path engine/Cargo.toml --locked && (cd gateway && go test ./...)`.
- **After dependency/module changes:** `bash scripts/engine-test-targets.sh` and `bash scripts/gateway-test-targets.sh`.
- **Before `/gsd-verify-work`:** Full suite green, plus `cargo clippy -- -D warnings`, `cargo fmt --check`, `go vet ./...`, and Collector/Compose observability config validation.
- **Max feedback latency:** not yet measured (Wave 0 — no telemetry tests exist to time).
- **Shell:** every `docker`, `sh` and `curl` command in this phase's plans runs under Git Bash, not PowerShell — `$(pwd)` in bind-mount arguments malforms under PowerShell, and Node.js is not assumed to be on `PATH`.

> **D-85: there is no CI.** These commands *are* the verification path.

# Phase 06.2 Plan 12 Summary: Bounded OpenTelemetry Export Diagnostics (G-06.2-4)

## Executive Overview
Plan 12 closes G-06.2-4 by implementing bounded export diagnostics across both Go and Rust services so a dead or disconnected OpenTelemetry Collector degrades cleanly to standard console logging without an unbounded stream of export error messages (D-38).

### Key Actions Completed
1. **Go Gateway Bounded Error Handler (Task 1)**:
   - Implemented `boundedErrorHandler` (`otel.ErrorHandler`) in `gateway/internal/telemetry/telemetry.go` limiting errors to 1 error line + 1 suppression line per 5-minute rolling window before re-arming.
   - Wired `SetupErrorHandler()` through package-level `setupErrorHandlerOnce` called in `Init()` ahead of `SetupPropagator()`.
   - Added table/mock clock test `TestOTelErrorHandlerBoundsRepeatedExportErrors` in `gateway/internal/telemetry/telemetry_test.go` verifying 1000 calls at frozen instant emit 2 lines, re-arm after 5m, and emit no credential/endpoint substrings.
2. **Rust Engine Subscriber-Side Diagnostic Filters (Task 2)**:
   - At `opentelemetry` 0.32, `global::set_error_handler` was removed from the Rust SDK; diagnostics are emitted as standard `tracing` events on crate-named targets (`opentelemetry*`).
   - Implemented `BoundedOtelDiagnostics` + `OtelDiagnosticsFilter` applied exclusively to `fmt_layer` to cap console export diagnostics to 1 warning per 5-minute window.
   - Implemented `DropOtelDiagnosticsFilter` applied to `otel_log_layer` (`OpenTelemetryTracingBridge`) to completely drop `opentelemetry*` events and prevent feedback loops or layer-order race where bridge filters could consume the cap before fmt layer sees the error.
   - Added `otel_internal_diagnostics_are_bounded` in `engine/src/tests/telemetry_metrics.rs` testing properties 1-5 (app logs pass, info noise dropped, warn/error bounded, 5m re-arm, and composed layer routing).
3. **Cumulative Test Pin Updates & Validation (Task 3)**:
   - `scripts/gateway-test-targets.sh`: Raised `EXPECTED_TOTAL` from 109 to 110 and `gateway/internal/telemetry` from 11 to 12.
   - `scripts/engine-test-targets.sh`: Raised `TOTAL` from 477 to 478, `LIB_BIN_SUM` to 438, and `LIB_COUNT` to 438.
   - Updated `06.2-VALIDATION.md` in place with automated test rows for Go and Rust bounded diagnostics, and retargeted the Manual-Only Collector degrade check to `06.2-12/T3`.

<objective>
Extend the proven span mechanism to the ingestion path: one trace per document from upload through graph extraction, carried across the ingestion queue, plus an observable `index_rebuild` span linked to the documents that triggered it.

Purpose: SC3 of the phase, and the thing that makes Phase 6.1's debounced rebuild-and-swap visible. Today the two most interesting ingestion behaviours — that graph extraction happens after the document span has already closed, and that a burst of documents coalesces into one rebuild — are invisible.
Output: a document-scoped ingest span with the existing stage spans nested inside it, a graph-extraction span, queue-crossing trace context, and a linked rebuild span.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gateway upload → engine ingest RPC | Untrusted document bytes and an untrusted inbound trace parent cross here. |
| Ingest RPC → bounded Tokio queue | The serialized trace parent crosses a process-internal async boundary. |
| Worker → rebuild trigger buffer | Span contexts accumulate in shared mutable state between the worker and the debounce task. |
| Document content → span attributes | Everything recorded leaves the process over OTLP. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.2-04-01 | Information Disclosure | Ingestion span attributes | high | mitigate | Document identifier, byte size and counts only; filename, raw bytes, chunk text and entity text are prohibited, with a dedicated test asserting no content appears in exported attributes. |
| T-06.2-04-02 | Spoofing | Caller-supplied trace parent on the ingest RPC | medium | mitigate | The standard propagator validates and falls back to a local root; the value is carried as data on the job and re-parsed by the same propagator, never interpreted as identity or authorization. |
| T-06.2-04-03 | Tampering | Malformed `trace_parent` value on a queued job | medium | mitigate | The field is optional and re-extracted through the propagator, which rejects invalid values and yields a new local root; the recovered-staged-job test pins that behaviour. |
| T-06.2-04-04 | Denial of Service | Unbounded growth of the rebuild trigger buffer | medium | mitigate | The buffer is drained on every rebuild and the drain-isolation test proves it does not accumulate across rebuilds; a bounded cap with a recorded overflow count is applied so a pathological burst cannot grow it without limit. |
| T-06.2-04-05 | Repudiation | Instrumentation altering the rollback or degrade path | high | mitigate | Spans are strictly additive around the existing branches; Phase 6.1's rebuild, degrade and debounce tests plus the ingestion rollback tests are the regression evidence. |
| T-06.2-04-06 | Denial of Service | Span volume during a large ingestion batch | low | accept | Ingestion is operator-initiated and locally bounded by the existing queue capacity; the span count per document is fixed at six and the rebuild coalesces to one span per debounce window. |
</threat_model>

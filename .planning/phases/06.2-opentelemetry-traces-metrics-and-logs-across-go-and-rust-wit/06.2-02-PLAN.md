<objective>
Expand the proven tracer into the full query-path span surface: five node spans owned by the runner, one leaf span per real external call including one per LLM attempt, and the terminal outcome plus span status recorded on the SSE root span.

Purpose: SC2 of the phase. This is where a Jaeger trace stops being "a request happened" and becomes an explanation of the query — which retrieval path ran, how long the graph traversal took, whether the model needed a second attempt.
Output: five node spans, five leaf span families, terminal attributes on the root span, and span-hierarchy tests driven by in-memory exporters.
</objective>

# Phase 06.2 Plan 09 Summary: Gateway OTLP Endpoint Scheme Branching & Security

## Executive Overview
Plan 09 closes CR-04 by branching OpenTelemetry gRPC exporters on the configured OTLP URL scheme (D-84, D-38):
1. **Endpoint Scheme Parsing & Credentials Branching**:
   - Implemented `otlpEndpointSecurity(endpoint string) (target string, useTLS bool)` in `gateway/internal/telemetry/telemetry.go` to trim `http://` or `https://` prefixes and determine whether TLS credentials should be utilized.
   - Implemented `otlpGRPCOptions(useTLS bool) (traceOpts []otlptracegrpc.Option, metricOpts []otlpmetricgrpc.Option, logOpts []otlploggrpc.Option)` to build TLS credentials (`credentials.NewClientTLSFromCert(nil, "")`) when `useTLS` is true, and insecure transport (`WithInsecure()`) only when `useTLS` is false.
   - Updated `Init` to use `otlpEndpointSecurity` once and share `otlpGRPCOptions` across trace (`otlptracegrpc`), metric (`otlpmetricgrpc`), and log (`otlploggrpc`) exporter constructors.
   - Preserved D-38 guarantee: `Init` signature never returns an error and exporter failures remain non-fatal bounded warnings.

2. **Verification & Named Wiring Gate**:
   - Added table-driven `TestOTLPEndpointSecurity` in `gateway/internal/telemetry/telemetry_test.go` covering `http://`, `https://`, loopback, remote hosts, and whitespace-padded configurations.
   - Added `TestOTLPExportersFollowEndpointSecurity` in `gateway/internal/telemetry/telemetry_test.go` as a coverage-only test exercising both option branches. Because OTel constructor option slices are opaque closures, wiring verification (that `https://` does not select insecure transport) is enforced via the `WithInsecure` source region grep: `grep -n 'WithInsecure' gateway/internal/telemetry/telemetry.go` confirms `WithInsecure` appears solely inside `otlpGRPCOptions` (lines 56–58).
   - Updated `scripts/gateway-test-targets.sh` pin from 107 to 109 total tests (`gateway/internal/telemetry` count moved from 9 to 11).
   - Updated `.planning/phases/06.2-opentelemetry-traces-metrics-and-logs-across-go-and-rust-wit/COVERAGE.md` OTLP TLS row from `OPT-OUT` to `INTEGRATE` for client export scheme honoring.

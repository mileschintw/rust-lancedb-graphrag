<objective>
Turn scored dimensions into a committed, dated, fully attributed run record — Markdown for a reader, JSON for a machine, and a metadata file that lets anyone trace every number back to the commit, the models, the seed and the index state that produced it. Then perform the recorded run itself.

Purpose: an evaluation report is a claim about one's own work, and a wrong claim is worse than no claim. The whole value of these numbers is that they are traceable, so the report generator's job is to make an untraceable number unrenderable — missing metadata, a smoke-test journal, or a cross-corpus average are all refused by construction rather than by discipline.
Output: the widened report models with their publication preconditions, the `report` command and the run-record layout, the regenerated committed schema, and the recorded run.
</objective>

## User Story (MVP mode)

**As a** reader of the Lancet README, **I want to** open a dated evaluation report and see every number next to the commit, models, seed, sample sizes and index generation that produced it, **so that** I can decide how much to believe it and recompute the deterministic half myself.

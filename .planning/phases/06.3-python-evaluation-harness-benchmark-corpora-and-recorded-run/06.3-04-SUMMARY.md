## Probe Results & Decisions

### Task 0: Atlas Schema-Isolation Probe
- **Probe A Output:**
  ```text
  $ atlas schema apply --env local --url "postgres://postgres:postgres@127.0.0.1:5432/lancet?sslmode=disable&search_path=lancet_eval" --dry-run
  Error: mismatched HCL and database schemas: "lancet_eval" <> "public"
  ```
  *Verdict:* Atlas rejects `search_path` scoped URLs when HCL declares literal `schema "public"`. Branch 1 and Branch 2 are unavailable; **Branch 3 (generated `schema.eval.hcl`) selected.**
- **Probe B Output:**
  Started gateway with `LANCET_ENV=eval` and `search_path=lancet_eval`, uploaded test document `probe_b.txt`:
  ```sql
  SELECT count(*) AS eval_count FROM lancet_eval.documents;   -- 1
  SELECT count(*) AS public_count FROM public.documents;       -- 16
  ```
  *Verdict:* pgx pool honours `search_path=lancet_eval` in the DSN, directing all gateway queries and document writes to `lancet_eval` with zero leakage into `public`.

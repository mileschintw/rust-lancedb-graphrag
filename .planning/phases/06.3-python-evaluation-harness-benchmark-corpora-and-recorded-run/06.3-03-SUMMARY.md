## Accomplishments
- Implemented `CorpusConfig` and `load_corpus()` in `eval/src/lancet_eval/corpus.py`, providing corpus-agnostic TOML configuration and question loading with adapter dispatch (`multihop_rag`, `graphrag_bench`).
- Built dataset fetcher and deterministic question sampler (`sample_corpus()`), committing the reproducible 500-question sample (`questions.sample.jsonl`), 338-document subset (`documents.subset.jsonl`), selection metadata (`subset_selection.json`), and comprehensive licensing notices in `eval/corpora/ATTRIBUTION.md`.
- Implemented the deterministic metric set in `eval/src/lancet_eval/metrics.py` with zero network or LLM dependencies:
  - Evidence containment matching (`fact_matches_excerpt`), boundary straddle diagnostics (`boundary_attributable`), and overlength fact exclusions (`gold_fact_longer_than_chunk`).
  - Strict Top-k candidate filtering (`rank <= k` in preserved wire order).
  - Retrieval metrics: `recall_at_k`, `hits_at_k`, `context_precision_at_k` (denominator is returned citations at rank <= k), `mrr_at_k`, and `ndcg_at_k` (ideal DCG built from gold set).
  - Answer metrics: SQuAD v1.1 normalization `em_f1()`, notice-based `abstention_outcome()`, and reference convention MAP@10.
  - Fail-loud verification on undecidable rates (>1% truncated chunks).
- Registered all 11 evaluation dimensions in `eval/src/lancet_eval/dimensions.py` and updated `eval/report.schema.json`.
- Upgraded `lancet-eval probe` to accept `--corpus` and `--question-id`, extracting gold facts and answers from the corpus and computing deterministic IR/answer scores end-to-end.

class CorpusConfig:

### `eval/src/lancet_eval/journal.py` (JSONL append-only, file-I/O + transform)

**Analog:** `scripts/phase02_live_evidence.py:466-471` (compute_sha256, encoding handling)

**Pattern — JSONL append-read with encoding safety**

```python
# eval/src/lancet_eval/journal.py
from pathlib import Path
import json

class Journal:
    def __init__(self, path: Path):
        self.path = path
        self.path.parent.mkdir(parents=True, exist_ok=True)
    
    def append(self, record: dict) -> None:
        """Append one JSONL line with UTF-8 safety (D-68)."""
        # Must: encoding="utf-8", newline="\n" (no CRLF on Windows)
        with self.path.open("a", encoding="utf-8", newline="\n") as f:
            f.write(json.dumps(record, separators=(",", ":")) + "\n")
    
    def read_all(self) -> list[dict]:
        """Read all JSONL lines."""
        if not self.path.exists():
            return []
        result = []
        # Must: encoding="utf-8"
        with self.path.open("r", encoding="utf-8") as f:
            for line in f:
                if line.strip():
                    result.append(json.loads(line))
        return result
```

**Key pattern from phase02_live_evidence.py (line 228, 624):**  
Every file operation must have `encoding="utf-8"` to ensure cross-platform consistency (D-68 Windows/WSL verification). Without it, Windows defaults to cp950 or similar ANSI codepage, and MultiHop-RAG's curly quotes, em-dashes, accented names yield different EM/F1 scores (RESEARCH.md Pitfall 2).

### Validation Error Pattern (applies to preflight, config, dimensions)

**Source:** `scripts/phase02_live_evidence.py:136-160` (require, ValidationError, classify_*)

```python
# Fail-closed validation: raise typed exception, never return None/False silently
class ValidationError(Exception):
    """Validation failed; do not proceed."""
    pass

def require(condition: bool, message: str) -> None:
    if not condition:
        raise ValidationError(message)

# Usage:
require(isinstance(value, dict), "must be a JSON object")
require(value["key"] == expected, "key mismatch")
```

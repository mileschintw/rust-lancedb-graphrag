### Routing decision — finding 2 (`commit_sha`): fix the code, not the procedure

The review offered two branches. **Chosen: (a) route `score_run` through the existing `get_commit_sha()` helper**, adding `eval/src/lancet_eval/score.py` and `eval/src/lancet_eval/config.py` to `files_modified`.

Rejected branch (b) — requiring `GIT_COMMIT_SHA=$(git rev-parse HEAD)` in `06.3-10`'s procedure — because `06.3-10` is a multi-day, multi-session, human-gated drive with at least four separate scoring invocations, and the workstation is Windows: the POSIX `VAR=value cmd` inline-env form does not work in PowerShell at all, so the guidance would be silently wrong in the operator's default shell exactly once, days into a run, on a value the required-pin guard cannot catch (`"local"` is non-blank and passes `report.py:51`). A code fix is stamped by construction on every future run and costs one moved function.

### Routing decision — finding 3 (`sample_size_deterministic`): correct the acceptance criterion, not the field

The review offered two branches. **Chosen: (b) correct `06.3-10`'s acceptance criterion**, leaving `score.py:736` semantics alone.

Rejected branch (a) — redefining `sample_size_deterministic` to the actual count — because there is no single actual count for it to equal: `n` varies per dimension (`score.py` computes it per dimension, and error records reduce some dimensions and not others), so any single metadata scalar is either nominal or arbitrary. Introducing a second field would change `RunMetadata` and therefore `eval/report.schema.json`, breaking `tests/test_schema.py`'s byte-identity assertion, which is plan `06.3-07`'s delivered contract and off-limits under this round's additive fence. `06.3-07` already renders each dimension's actual `n` beside the value in the report body, so the truthful pairing already exists in the published artifact; what was wrong was `06.3-10` asserting the metadata field carried a number it never carries. The corrected bar: metadata carries the corpus's committed nominal sample size, `report.md` prints each dimension's actual `n` adjacent to its value, and the SUMMARY records the nominal-vs-actual delta with a cause for any nonzero delta.

### Routing decision — finding 8 (gateway remedy): emit the remedy, keep the bar

The review offered two branches. **Chosen: (a) add a one-line remedy to `preflight.py`**, adding it and `eval/tests/test_preflight.py` to `files_modified`.

# Plan 06.3-07 Summary: Evaluation Report Generation and Run Record Tooling

Plan 06.3-07 implemented the complete evaluation report generator (`lancet-eval report`), widened `RunMetadata` and `CorpusReport` to enforce full provenance and publication preconditions, established the 5-artifact run record directory layout (`eval/runs/<date>-<corpus>/`), and documented the pre-commit reviewer checklist and reference-set spot-check procedures.

## Work Completed

### 1. Widened Report Models & Preconditions (`eval/src/lancet_eval/report.py`)
- **Comprehensive Pin Surface (D-60, D-61):** `RunMetadata` mandates non-blank values for `corpus`, `run_date`, `commit_sha`, `generation_model`, `embedding_model`, `judge_model`, `judge_temperature`, `judge_prompt_version`, `sampling_seed`, `sample_size_deterministic`, `sample_size_judged`, `index_generation`, `result_hash`, `arm_labels`, and `dependency_lock_hash`.
- **Publication Preconditions (D-54):** `render_markdown()` and `render_json()` refuse to render runs with `partial: true` (stamped by the `--limit` smoke knob) or missing metadata.
- **Cross-Corpus Isolation (D-60):** `CorpusReport` strictly forbids cross-corpus aggregation fields (`aggregate`, `combined`, `overall`), guaranteeing that different benchmark corpora remain distinct without invalid combined means.
- **Run Comparison Callouts:** `render_markdown(report, compare_to_metadata)` automatically detects and warns if sample sizes changed across runs.

### 2. Methodological Caveats Template (`eval/src/lancet_eval/templates/report.md.j2`)
The rendered Markdown report includes all 7 normative caveats and notes in its own text:
1. Evidence matching rule verbatim.
2. Evidence source distinction (retrieved chunks vs cited evidence).
3. Chunk size limits and overlength fact exclusions.
4. Non-comparability to the MultiHop-RAG paper's accuracy metric (token overlap differences).
5. Ranking metric convention statement (MRR@10 / nDCG@10).
6. Failed query snapshot wire behavior.
7. Advisory status and banker's rounding rules.

### 3. Report Command & CLI Sub-commands (`eval/src/lancet_eval/cli.py`)
- Implemented `lancet-eval report --run <dir> [--compare-to <dir>]`.
- Automatically executes offline scoring if `report.json` does not exist, validates preconditions, renders `report.md`, and writes `report.json` and `metadata.json`.
- Advisory execution: exits 0 regardless of score values (D-54).

### 4. Schema & Documentation (`eval/report.schema.json`, `eval/README.md`)
- Regenerated `eval/report.schema.json` from the widened model.
- Documented the 5-artifact run-record directory layout (`eval/runs/<date>-<corpus>/`).
- Added the 5-item Pre-Commit Run-Record Reviewer Checklist.
- Added the 10-item weighted Reference-Set Spot-Check instruction.

## 2. Issues Encountered & Fixes Applied in This Session

### 2.1. Fix 1: Windows Host `psql` Path Fallback (`ea77cbf`)
- **Problem**: On Windows where PostgreSQL runs in a Docker container, the host does not have `psql` in `PATH`, causing `[WinError 2]` when `reset_eval_schema` executed `subprocess.run(["psql", ...])`.
- **Fix**: Updated `eval/src/lancet_eval/seed.py` to check `shutil.which("psql")`; if absent, it falls back to `docker compose exec -T db psql ...` directly against the running container.

### 2.2. Fix 2: Auto-Creation of LanceDB Tables on Store Wipe (`2f8f7cc`)
- **Problem**: When `reseed` wipes `eval/data/lancedb` while the engine is running, the engine's cached connection handle failed on `open_table("documents")` with `Table 'documents' was not found`.
- **Fix**: Updated `engine/src/db/mod.rs` with `get_or_create_table` so `DatabaseManager` self-heals missing LanceDB tables against their defined Arrow schemas.

### 2.3. Fix 3: Ingestion Polling Timeout & Dynamic Test Fixtures (`8255b0a`)
- **Problem**: Large articles (e.g. Document 6 with 78 chunks) took ~11 minutes under rate limiting, exceeding the seeder's 300s polling timeout. Additionally, scoring unit tests previously assumed a static document ID from Probe B.
- **Fix**: Increased `max_poll_time` in `eval/src/lancet_eval/seed.py` from 300s to 900s (15m). Updated evaluation test suites (`test_score_deterministic.py`, `test_score_judged.py`, `test_secrets.py`) to resolve document IDs dynamically. All 136 tests pass offline.

- **Remaining**: 340 documents (~7,184 chunks).

### 3.2. Root Cause of HTTP 429 Rate Limits
- In `config/config.toml`, the models are set to:
  ```toml
  embedding_model = "nvidia/llama-nemotron-embed-vl-1b-v2:free"
  generation_model = "dots-studio/dots-3-note-preview:free"
  ```
- **OpenRouter Routing Rule**: Any model ending with `:free` is routed to free-tier provider pools that enforce strict global rate limits (~20 requests/minute and low daily quotas) **regardless of whether the account has paid credits**.
- Even though the user has **>$15 credit** on OpenRouter, the `:free` model names prevent the account from using paid-tier high-throughput routing.

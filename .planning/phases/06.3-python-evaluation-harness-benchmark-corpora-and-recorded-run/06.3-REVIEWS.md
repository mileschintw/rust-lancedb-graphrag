## 3. Concerns

D-50's offline guarantee is `score --no-judge` over the journal. 06.3-05 Task 2's successful-record list is `answer, notices, node_failures, duration, session_id, correlation_id, index_generation` — no snapshot, no `retrieved_chunks`, no `structured_citations`. AI-SPEC `drive_one` only peels `index_generation` off `out.answer.snapshot` and discards the rest (`06.3-AI-SPEC.md:1143-1148`). Tool Use still tells the executor to score `structured_citations[]` for recall@k (`1197-1199`). If the executor follows AI-SPEC or the 05 field list, the wire fix never reaches the committed report. **Fix:** require `RunRecord` to persist `snapshot` (present vs null) and `retrieved_chunks` (and `structured_citations` for the judge), with a test that a gold fact in citations-only scores retrieval 0.0 from the journal.

- **MEDIUM — "Absent snapshot ⇒ retrieval never ran" is false on the failure path.** On error the runner emits `workflow_completed{success: false}` with `final_response: None` (`runner.rs:665-675`). `ctx.snapshot` was already set (`retrieve.rs:252`) but never serialized. 06.3-07 correctly excludes those queries and prints the count; 06.3-08/01/03 still teach "absent = retrieval did not run." Free-tier generation failures will be common; the skip is honest, the reason string is not. Optional later fix: put snapshot on the failure terminal (separate from 08's checkpoint prohibition).

- **MEDIUM — 06.3-05 Task 2 still says "follow the AI-SPEC reference implementation" while that snippet calls `run_query(..., graph_arm=arm)` (`AI-SPEC.md:1142`).** 06.3-01 forbids an arm string on `run_query` and keeps `GRAPH_ARMS` only in `run.py`. Copy-paste would undo HIGH-2's sibling fix. 05 `files_modified` omits `client.py`, which helps only if the executor does not "fix" the client to match the spec.

- **MEDIUM — 06.3-06 is `autonomous: true` with a blocking live calibration human-check (Task 3).** Same class of dispatch bug previously called out on 06.3-04 (now correctly `false`). Calibration will not complete under a single-subagent autonomous route.

Placing `RetrievedChunks` after `ResultHash` is JSON-fine; the order claim is wrong. Python models mirroring the DTO will also omit variant provenance — acceptable for metrics.

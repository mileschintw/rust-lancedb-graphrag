# Phase 06.3 Gap Closure Plan 09: Summary

## Overview

Plan `06.3-09` closed all operational, isolation, and methodology gaps identified during the milestone audit to guarantee reproducible, isolated, and self-attributing evaluation benchmark runs.

## Work Completed

1. **Task 1: Run Directory Git Tracking and Date Resolution**
   - Refined `.gitignore` from a blanket `eval/runs/` ignore to ignoring ephemeral run artifacts (`*.jsonl.tmp`, `judge_cache.json`, etc.) while tracking published report artifacts (`report.md`, `report.json`, `metadata.json`) within `eval/runs/*-multihop_rag/` and `eval/runs/*-graphrag_bench/`.
   - Added `resolve_run_dir(corpus, resume, runs_root)` in `eval/src/lancet_eval/cli.py` matching `????-??-??-{corpus}` date-anchored directories on `--resume` and creating fresh dated directories on `--no-resume`.
   - Updated `eval/README.md` to reference canonical dated directories and document resume semantics.
   - Added unit test `test_resolve_run_dir_reuses_newest_dated_dir_on_resume` in `eval/tests/test_run_arms.py`.

2. **Task 2 & 3: Isolated Database Reset (Branch B: Drop and Apply)**
   - Executed live Atlas dry-run probe on PostgreSQL: `atlas schema clean` failed due to single-schema migration scoping, confirming Branch B (`branch-b-drop-and-apply`) is the correct, safe strategy.
   - Implemented `assert_schema_isolated(settings)` in `eval/src/lancet_eval/seed.py` validating that `database_url` has a non-empty, non-public, non-colliding SQL-identifier schema name.
   - Implemented `assert_admin_dsn_targets_eval_database(eval_dsn, admin_dsn)` ensuring administrative connections stay on the same host, port, and database.
   - Implemented `reset_eval_schema(settings)` executing `DROP SCHEMA IF EXISTS "<schema>" CASCADE; CREATE SCHEMA "<schema>";` via `psql` and reconciling with `atlas schema apply --env eval --auto-approve`.
   - Sequenced `reseed_corpus` to invoke `reset_eval_schema` prior to LanceDB directory removal.
   - Added comprehensive isolation and injection-rejection tests to `eval/tests/test_seed.py`.

3. **Task 4: Deadline Forwarding and Accurate Containment Caveats**
   - Threaded `deadline_s: float = 600.0` through `drive_one` and `drive` in `eval/src/lancet_eval/run.py`.
   - Updated `run_benchmark` in `eval/src/lancet_eval/cli.py` to load settings via `load_settings()` and pass `settings=settings` to `drive()`.
   - Rewrote Caveat 1 in `eval/src/lancet_eval/templates/report.md.j2` to describe unidirectional containment matching (`fact_matches_excerpt`), boundary straddling resolving to misses, and `boundary_attributable_misses` as the diagnostic count.
   - Added unit tests `test_drive_passes_configured_deadline_to_run_query`, `test_run_command_loads_settings_and_forwards_to_drive`, and `test_matching_rule_caveat_matches_implemented_rule`.

4. **Task 5: Self-Attributing Metadata, Judged Calibration Rows, and Remedial Preflight**
   - Hoisted `get_commit_sha() -> str` to `eval/src/lancet_eval/config.py` beside `repo_root()` and imported it across `cli.py` and `score.py`.
   - Updated `score_run` in `eval/src/lancet_eval/score.py` to fall back to `get_commit_sha()` rather than `"local"` when `GIT_COMMIT_SHA` is unset.
   - Updated calibration worksheet emission in `score_run` to select exclusively from the judged question subset (`judged_qids`) when judging is enabled, printing emitted rows count.
   - Extended `gateway_reachable` failure message in `eval/src/lancet_eval/preflight.py` to name the exact startup remedy (`LANCET_ENV=eval`).
   - Added unit tests `test_score_run_stamps_real_commit_sha`, `test_worksheet_rows_are_drawn_from_the_judged_subset`, and `test_gateway_failure_message_names_service_and_remedy`.

# Plan 06.3-06 Summary: LLM-as-Judge Scoring, Calibration Slice, and OpenRouter Cache

Plan 06.3-06 implemented the LLM-as-judge evaluation pipeline for groundedness and faithfulness across MultiHop-RAG benchmark questions, backed by auditable plain-text caching, bounded evidence truncation, tenacity transport retries, and human calibration agreement measurement.

## Work Completed

### 1. Judge Client & Caching (`eval/src/lancet_eval/judge.py`)
- **System Rubric & Anchors (`JUDGE_SYSTEM_V1`):** Groundedness and faithfulness scored on 1–5 scale with explicit 1/3/5 anchors.
- **Model Family Differentiation (D-53):** Pinned `meta-llama/llama-3.3-70b-instruct:free` in `multihop_rag.toml` and `graphrag_bench.toml`, distinct from the engine's `dots-studio/dots-3-note-preview:free` generation model.
- **Bounded Evidence Truncation:** `truncate_evidence()` processes citations in wire ranked order, applying a 1,500-char per-passage cap before a 12,000-char total budget, appending `[TRUNCATED: N further passages omitted]` markers included in the SHA-256 cache key.
- **Auditable Plain-Text Cache (`JudgeCache`):** Keyed by `sha256(prompt_version, judge_model, question, answer, post_truncation_evidence)` and saved atomically to `judge_cache.json`.
- **Single Bounded Semantic Re-ask:** On `ValidationError`, re-asks the judge exactly once with schema errors before recording an error (never assigning an arbitrary score).
- **Transport Resilience:** Tenacity retry with `Retry-After` header extraction, exponential backoff, and jitter on 429 and 5xx responses.

### 2. Judged Dimensions & Scoring Loop (`eval/src/lancet_eval/score.py`, `eval/src/lancet_eval/dimensions.py`)
- **Result Builders:** Added `make_groundedness_result` and `make_faithfulness_result` with detail tracking for `judged_n`, `judge_errors`, `skipped_no_evidence`, `calibration_exact_match`, and `calibration_mad`.
- **Two-Sample-Size Split (D-51):** `score --sample N` evaluates deterministic metrics over all committed questions in the journal while scoping judge calls to the deterministically seeded sample `N`.
- **Offline / Zero-Judge Execution (D-50):** `score --no-judge` skips judged dimensions with explicit reason and zero network calls.
- **Empty Citation Handling:** Zero-citation records are marked `skipped_no_evidence` and excluded from judge calls.

### 3. Human Calibration Slice & Agreement Workflow
- **Worksheet Emission (`--emit-calibration-worksheet`):** Emits representative records across query types in `.jsonl` format.
- **Calibration Ingestion (`--calibration-file`):** Validates prompt version header, rejects blank human scores, and computes exact-match rate and mean absolute difference (MAD) joined with cached judge verdicts.

### 4. Secrets Leak Prevention
- `eval/tests/test_secrets.py` verifies that sentinel API keys are never serialized to `report.json`, `report.md`, `judge_cache.json`, `journal.jsonl`, `report.schema.json`, or log streams.

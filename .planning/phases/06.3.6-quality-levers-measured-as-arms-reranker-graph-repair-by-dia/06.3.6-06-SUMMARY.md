# Phase 06.3.6 Plan 06: Query-embedding retry and IN-02 degraded-mode fix Summary

**One bounded query-embedding retry with a blake3 jitter on every arm, nested inside the graph node budget (verify overlay raised to 25000 ms by owner decision D-188), plus the D-158 IN-02 fix so a normalised grounded abstention is no longer counted as degraded.**

## Performance

- **Tasks:** 2 (both TDD)
- **Commits:** 5 (measured: `git rev-list --count --grep='(06.3.6-06)'` over `plan_head_before..HEAD`; the raw range count is 16 because plans 07 and 08 merged into main in between)
- **Files modified:** 7 production/test files plus 1 created (`query_embedding_retry.rs`)

## Accomplishments

- **D-152 retry.** `ExtractGraphContext` loops over `QUERY_EMBEDDING_ATTEMPTS = 2`. Each attempt keeps its own `embedding_timeout` inside the cancel `select!`. On a timeout with an attempt left, `ctx.query_embedding_retries` is incremented, `query_embedding_retry` is logged with attempt and jitter only (never the query text), and the node pauses `retry_jitter_ms(trace_id, attempt, 250)` (blake3, no `rand`) in a biased `select!` against the cancel token. A non-timeout error, or a second timeout, returns exactly as before. A first-attempt success takes one call, no sleep and `retries = 0`, so the lever-free goldens stay byte-identical. The loop sits above the ablation early return, and the graph port is still called at exactly one place (`graph_cutover` pins pass, 21 tests).
- **D-152 nesting.** `WorkflowSettings::validate` now requires `graph_node_timeout_ms >= 2 x query_embedding_timeout_ms + 250 + graph_operation_timeout_ms`. The constants are imported from the node module, not mirrored. The nesting test asserts the 500 ms slack on top (`2 x 2000 + 250 + 2424 + 500 = 7174 <= 12500`), and a new boundary test shows the sum passes and one millisecond below it is refused with an error naming the key and the sum. The doc comments of `default_query_embedding_timeout_ms` and `default_graph_node_timeout_ms` describe the retry.
- **D-158 IN-02.** `derive_degraded_mode` skips the `BASIS_RECONCILED` notice whose message equals `GROUNDED_ABSTENTION_NORMALISED_NOTICE` exactly; any other reconciliation text (including one that merely contains the normalisation text) and `RerankDegraded` still degrade.
- **Test count.** `scripts/engine-test-targets.sh` now asserts TOTAL 777 / lib 679, with history lines for the three additions (768 for IN-02, 776 for the retry tests, 777 for the boundary test).

## Decisions Made

- **D-188 (owner decision, recorded in 06.3.6-CONTEXT.md, commit `9216e36b`):** "The verify overlay's graph node ceiling grows to hold the query-embedding retry." The D-152 rule passes for `config/config.toml` (6674 <= 12500) but not for the verification-only overlay `config/config.verify.toml` (query_embedding 10000, graph_operation 4000, graph_node 15000 needs 24250), which would have refused to start under `LANCET_ENV=verify`.

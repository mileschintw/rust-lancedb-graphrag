## Decisions Made

- Followed the task action's "empty default in `config.rs`; the winners in both config files" over the behavior bullet's "and the `config.rs` default (agreement test)". A non-empty code default would make every service built from `EffectiveRagSettings::default()` ask for resources the test fixtures do not hold. The agreement test pins an empty code default and file equality with the winners instead.
- Startup validation is strict: no carve-out for an empty store. The operator's explicit way to start lever-free is the empty env override or `defaults = []`.
- The environment override is read by hand in `load_settings`, like the other `LANCET_ENGINE__*` keys. The `config` crate's own `Environment` source does not match these names (its prefix pattern is `lancet__`), so a builder-level override would silently do nothing.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The `config_startup` fixtures could not start the engine once the committed config carried default levers**
- **Found during:** Task 1 (reading `engine/tests/config_startup.rs` before editing admission)
- **Issue:** Twenty-four tests boot the real engine binary with the committed `config/config.toml` over an empty temp store. With the strict startup check, an empty store has no document metadata, so `evidence_metadata` is unavailable and every one of them would have failed to reach readiness.
- **Fix:** Added the `LANCET_ENGINE__LEVERS__DEFAULTS` override (empty value means none) to `load_settings`; `spawn_engine_full` now starts every fixture lever-free unless a test removes the variable; two new tests prove the refusal (committed defaults over an empty store stop the engine, naming `evidence_metadata` and `defaults = []`) and the override (empty value starts it). The check itself was not weakened.
- **Files modified:** `engine/src/config.rs`, `engine/tests/config_startup.rs`
- **Verification:** `cargo test --test config_startup` 24 passed; full suite green.
- **Committed in:** `3d765ea3`

- **Found during:** Task 1 (first compile)

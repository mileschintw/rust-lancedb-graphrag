# Phase 06.3.6 Plan 08: Evidence metadata ingestion (outside the engine) Summary

**One Python normaliser (`evidence_meta.normalise`) now feeds both `seed.py` and a 346-of-346 backfill sidecar builder, and the gateway validates `doc_title` / `source` / `published_date` at the edge and forwards them in the existing ingest metadata map with no proto change.**

## Performance

- **Duration:** about 40 min
- **Completed:** 2026-10-09T22:21Z
- **Tasks:** 2
- **Files modified:** 11 (5 created, 6 modified)

## Accomplishments

- `evidence_meta.normalise(raw)` returns `doc_title` (`html.unescape(...).strip()`), `source` (`.strip()`), and `published_date` (UTC `YYYY-MM-DD`), with every empty, missing or unparseable value `None`. It uses stdlib only; `eval/pyproject.toml` and `eval/uv.lock` are unchanged.
- `eval/scripts/build_metadata_sidecar.py --document-map --documents --out` writes `{"schema": 1, "rows": {...}}` with sorted keys and prints the row count and sha256. Run over the committed corpus: `rows: 346`, `sha256: 3e0634c26824fcebb5333fd4205829a189108f5c3740dda76d57d63f9a5cd9af` (scratch output, not committed; plan 06.3.6-15 writes the real one under gitignored `data/`).
- `seed.py` passes `data={k: v for k, v in normalise(doc).items() if v}` next to `files=`; the retry loop is unchanged.
- Gateway: `engineclient.IngestMeta`, `ingestMetadata(strategy, chunkSize, chunkOverlap, meta)` and the new `Engine.Ingest(..., meta, src)` signature; `createDocument` reads the three form values via `parseIngestMeta` and answers `invalid doc_title` / `invalid source` / `invalid published_date` with a 400 before `store.Insert`.
- `scripts/gateway-test-targets.sh`: gateway 83, `gateway/internal/engineclient` 1, total 124 (history line names plan 08 Task 2).

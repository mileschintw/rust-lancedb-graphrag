**Baselines at research time (HEAD `0ab2dd0d`, 2026-10-09, executed):**
- Engine: lib 658 passed + 2 ignored (660 listed); `inspect_lancedb` 53; `reconcile_eval_store` 18;
  `config_startup` 22. `sh scripts/engine-test-targets.sh` exits 0 with `TOTAL: 753`.
- Gateway: `go test -p 2 ./...` ok. `sh scripts/gateway-test-targets.sh` exits 0 with `EXPECTED_TOTAL=120`
  (`gateway 80`, `gateway/db 7`, `gateway/internal/config 4`, `gateway/internal/sse 17`,
  `gateway/internal/telemetry 12`; `internal/engineclient` has no tests).
- Harness: `pytest eval/tests` 1802 passed in 280.7 s. `uv lock --project eval --check` exits 0.

**Rules that hold for every plan:**
- **Filtered commands need the non-zero-count guard.** `cargo test <filter>` and `go test -run <regex>` exit 0
  when the filter matches zero tests. Every filtered Rust or Go command carries the guard shown above, and the
  matching count script runs in the same step. pytest needs no guard.
- **Count scripts move with the tests.** A plan that adds tests sets the script constants to the newly
  measured values in the same commit as those tests, with a history line, and never lowers a value to pass. A
  new engine bin with tests needs its own `awk` line, `*_COUNT` variable, `TOTAL` addend and assertion. A new
  gateway package with tests needs an `EXPECTED_PACKAGES` line. New `levers` rejection shapes should be
  subtests of one gateway test function.
- **Do not use** `uv run --project eval pytest` from the repo root. It also collects
  `scripts/test_phase02_live_evidence.py`, which needs `python -O`.
- **Lint gate:** `ruff check --preview` reports **no new finding on touched files**. The repo-wide count is 556
  before any change (RESEARCH C7), so "clean" is not the gate.
- **Goldens that must stay green and unregenerated through the held-out drive:**
  `engine/src/retrieval/testdata/retrieve_node_default.golden`,
  `engine/src/retrieval/testdata/graph_off_fusion.golden`, and the provider-message golden that plan 03 records
  at the pre-change HEAD. They are updated only by the D-157 default-flip commit, and only if a default flips.

## Sampling Rate

- **After every task commit:** run the quick command for the touched stack (a guarded cargo filter, `go test`
  on the touched package, or the touched pytest files).
- **After every plan wave:** run every full-suite command above, both count scripts, and proto idempotence.
- **Before `/gsd-verify-work`:** every full suite is green; both test-count scripts exit 0;
  `eval/tests/test_recorded_gate_verdicts.py` is green (drives 1, 1b, 2 and 06.3.5 re-read unchanged, D-151);
  `buf generate` is idempotent.
- **Max feedback latency:** 180 seconds for a quick command.

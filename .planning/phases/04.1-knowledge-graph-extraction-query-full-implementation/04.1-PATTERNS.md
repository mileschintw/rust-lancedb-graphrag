**Fail-fast/no-auto-migrate pattern** (lines 145–158, `validate_schema`):
```rust
async fn validate_schema(name: &str, table: &Table, expected: &SchemaRef) -> Result<(), String> {
    let actual = table.schema().await.map_err(|error| format!("failed to read LanceDB schema for {name}: {error}"))?;
    if actual.fields() != expected.fields() {
        return Err(format!("LanceDB schema drift detected for {name}: expected {:?}, found {:?}", expected.fields(), actual.fields()));
    }
    Ok(())
}
```
Reuse this verbatim for `entities` — no special-casing. Extend `table_schemas()` (currently `[(&'static str, SchemaRef); 5]`, lines 257–265) to a 6-tuple array including `("entities", entities_schema())`, and add `pub async fn entities_table(&self) -> Result<Table, String>` mirroring `nodes_table()`/`edges_table()` (lines 128–142) exactly.

**EntityResolver wiring (D-05)** (lines 267–291, already shipped, ready to call):
```rust
#[tonic::async_trait]
pub trait EntityResolver: Send + Sync {
    async fn resolve(&self, entity: &str, known_entities: &[String]) -> Result<Option<String>, String>;
}
#[derive(Debug, Default)]
pub struct ExactMatchResolver;
#[tonic::async_trait]
impl EntityResolver for ExactMatchResolver {
    async fn resolve(&self, entity: &str, known_entities: &[String]) -> Result<Option<String>, String> {
        Ok(known_entities.iter().find(|known| known.as_str() == entity).cloned())
    }
}
```
The extraction pipeline calls `resolve()` per extracted entity name against the corpus-global set of existing entity names (case-normalize before comparing per D-05) — no new resolver code needed, only a caller.

   - Added characterization tests for Cypher narrowing, bidirectional Cypher traversal, and direction-changing multi-hop path bounds.

   - Added `fetch_neighborhood_returns_both_edges_when_two_documents_share_identical_fact` proving distinct edges sharing identical (source, target, relation, confidence) facts across documents both survive.

3. **WR-01 & Edge Count Bounds:**
   - Relocated `MAX_FRONTIER_SIZE` check from loop entry to immediately after `next_frontier` construction, ensuring final-hop fan-out is bounded.
   - Added tests verifying rejection on oversized edge batches (`MAX_TOTAL_EDGES`) and oversized final-hop frontiers (`MAX_FRONTIER_SIZE`).

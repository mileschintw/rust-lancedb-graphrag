## Sampling Rate

- **After every task commit:** Run the specific `cargo test <name>` filter each `PLAN.md` task's `<verify><automated>` block names (already scoped per task, per this phase's plan-checker convention of avoiding vacuous zero-match filters).
- **After every plan wave:** Run `cargo test --manifest-path engine/Cargo.toml --locked && (cd gateway && go test ./...)` (full suite), matching every plan's own `<verification>` block.
- **Before `/gsd-verify-work`:** Full suite must be green.
- **Max feedback latency:** 30 seconds.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Concurrent extraction results → shared in-memory known-entities accumulator | `buffer_unordered(5)`'s results are gathered into a `Vec` and re-sorted before the merge/persist step runs sequentially — no concurrent write access to the accumulator itself |
| Multi-batch IPC stream → bridged RecordBatch | A larger real `entities`/`edges` read may legitimately split across multiple Arrow IPC stream messages depending on writer-side batching (e.g. dictionary-encoded columns per 04-CONTEXT.md's WR-01 note) |

# Plan 04.1-02 Summary: Knowledge Graph Extraction and Query Augmentation Implementation

## Work Completed

### Task 1: End-to-End Knowledge Graph Extraction, Persistence, Cypher Traversal, and Query Augmentation

Implemented complete knowledge graph extraction, persistence, Cypher-constrained neighborhood traversal, and context augmentation for RAG queries adhering strictly to project guidelines (`rust-guidelines.md`) and AI-SPEC specifications.

Key deliverables:
1. **Extraction Infrastructure (`engine/src/graph/extraction.rs`)**:
   - Implemented `ExtractionGenerator` trait returning `BoxFuture<'a, Result<ExtractionOutput, GenerationError>>`.
   - Built `OpenRouterExtractionGenerator` with structured JSON Schema matching AI-SPEC §4b.1 (`type: "json_schema"`, `strict: true`, maxLength/maxItems bounds).
   - Built `FakeExtractionGenerator` for mock and offline testing.
   - Declared `MIN_CHUNK_CONTENT_LENGTH = 40`.

2. **Context Strategy & Prompt Formatting (`engine/src/graph/context_strategy.rs` & `engine/src/prompt.rs`)**:
   - Implemented `ContextAssemblyStrategy` (`PrecomputedSemantics`, `SourceChunks`).
   - Defined `GraphFact` and `GraphFactBlock` deriving `Serialize` only (no `Deserialize`) with private string fields escaped via `escape_evidence_delimiters` upon construction.
   - Implemented `pack_evidence_and_graph_prompt` enforcing the reserve-one-citable-chunk rule off the top of `max_prompt_tokens` before packing evidence and appending graph facts under `## Related Entities & Relationships`.
   - Reconciled system policy wording to explicitly inform LLMs that graph context is supplementary non-citable background.

3. **Cypher Neighborhood Traversal & Fail-Open Fallback (`engine/src/graph/mod.rs`)**:
   - Implemented `fetch_neighborhood` querying `entity_edges_table()` with candidate limits (`MAX_FRONTIER_SIZE = 200`, `MAX_TOTAL_EDGES = 500`).
   - Implemented `cypher_confirmed_neighbor_ids` and `constrain_to_cypher_matched` to filter Arrow record batches against Cypher-confirmed neighbor sets.
   - Implemented `narrow_via_cypher` with fail-open fallback to 1-hop vector neighborhood when Cypher returns 0 confirmed neighbors or fails (D-32).

4. **Ingestion & Persistence (`engine/src/main.rs`)**:
   - Implemented `extract_and_persist_entities` using a two-phase transactional pattern: Phase A read-only extraction & exact match resolution, Phase B mutation with table version capture and automatic rollback on failure.
   - Integrated extraction into worker loops (`spawn_worker`, `spawn_worker_with_boundary`).

5. **Query Augmentation (`engine/src/main.rs`)**:
   - Implemented `attempt_graph_augmentation` performing vector search over `entities_table` for seed match (`_distance` converted via `dense_score`), fetching neighborhood, narrowing via Cypher, and assembling `GraphFact`s.
   - Threaded graph facts into `query_rag` and recorded augmentation outcomes on tracing span.

6. **Configuration & Tests (`engine/src/main.rs`, `engine/src/graph/tests.rs`, `engine/src/tests.rs`)**:
   - Added `GraphConfigSettings` (`seed_match_min_score: 0.5`, `max_hop_cap: 3`) to `EngineSettings` and `GraphSettings` to `EffectiveRagSettings`.
   - Added unit tests covering all required scenarios (JSON schema validation, exact match dedup, cross-doc resolution, unmapped relation endpoint dropping, Cypher fail-open, graph fact prompt escaping, and augmentation scoring).

<objective>
Upgrade Plan 02's append-only graph-context integration (graph facts placed after chunk evidence, unconditionally) into the score-interleaved, configurably-weighted integration D-29/D-30 specify — the RAG-path's production-grade shape, not the tracer's proof-of-concept shape. Prove the `graph_augmentation` outcome tag Plan 02 already built is genuinely observable through the full query handler for all three outcomes, not just in isolation.

Purpose: an always-on feature that runs on every `/rag/query` call must not silently degrade answer quality (unranked graph facts crowding out higher-value chunk evidence) or silently degrade observability (a failing traversal looking identical to "no relevant graph context existed").
Output: score-interleaved evidence packing with a configurable, validated `graph_weight`; end-to-end proof (behavioral + tracing-capture) that every outcome is observable.
</objective>

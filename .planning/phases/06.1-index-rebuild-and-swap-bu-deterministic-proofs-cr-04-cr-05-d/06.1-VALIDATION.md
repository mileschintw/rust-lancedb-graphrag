## Sampling Rate

- **After every task commit:** Run focused command (`cargo test --manifest-path engine/Cargo.toml --lib -- <focused>` for engine work, `python3 -O -I scripts/test_phase02_live_evidence.py -k <TestName>` for BU-01/BU-02 work).
- **After every plan wave:** Run `cargo test --manifest-path engine/Cargo.toml --locked && (cd gateway && go test ./...)` plus `python3 -O -I scripts/test_phase02_live_evidence.py`.
- **Before `/gsd-verify-work`:** Full suite green + clippy + fmt + go vet.
- **Max feedback latency:** 30 seconds (quick run), full gate at wave boundaries.

> **D-85: there is no CI.** These commands *are* the verification path.

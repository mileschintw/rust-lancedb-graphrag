### `engine/src/ingest.rs` — corpus-wide generation (service, CRUD)

**Analog:** `get_max_staged_generation` (lines 391–419).

**Core query pattern:**
```rust
pub async fn get_max_staged_generation(
    table: &Table,
    document_id: &str,
) -> Result<Option<i64>, String> {
    let pred = format!("document_id = '{}'", escape_sql_literal(document_id));
    let batches: Vec<RecordBatch> = table
        .query()
        .only_if(&pred)
        .execute()
        .await
        .map_err(|e| format!("query failed: {e}"))?
        .try_collect()
        .await
        .map_err(|e| format!("collect failed: {e}"))?;
    // scan Int64 "generation" column → Option<i64> max
}
```

**Copy:** same `query()` / `try_collect()` / `column_by_name("generation")` / `Int64Array` loop. **Drop** `pred` and `.only_if(&pred)` for the corpus-wide variant.

**Planner must address REVIEWS.md HIGH finding:** `staged_documents` is emptied on successful ingest (`ingest.rs` staging delete ~814–816; Phase 02 evidence requires `staged_document_rows == 0`). A corpus-wide `MAX(generation)` on that table is **None in steady state**, so `"gen-0"` would be constant and D-21/D-24 proofs become tautological. Prefer a durable source already in this file: `nodes.version()` (used at `restore_version` / ingest rollback ~532–540, version capture ~610). D-26 still holds if generation is **derived from persisted LanceDB state** (table version), not a second stored counter.

### `engine/src/ingest.rs` — dense pin / rebuild checkout (service, transform)

**Analog:** `restore_version` (lines 532–541) — checkout on a **Table** handle.

```rust
pub async fn restore_version(table: &Table, version: u64) -> Result<(), String> {
    table
        .checkout(version)
        .await
        .map_err(|error| format!("checkout rollback version {version}: {error}"))?;
    table
        .restore()
        .await
        .map_err(|error| format!("restore rollback version {version}: {error}"))
}
```

**Copy for D-24 read-pinning:** `checkout(version)` error-map shape. **Do not** call `restore()` on query path. **Do not** checkout the shared writer handle:

```rust
let pinned = self.nodes.clone();
pinned.checkout(pinned_version).await.map_err(|e| /* NodeError::RetrievalFailed */)?;
// query against `pinned` only
```

LanceDB docs (RESEARCH Pattern 3): checkout is a per-handle detached head; other clones stay at live HEAD.

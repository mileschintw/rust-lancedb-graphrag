# Phase 06.1 Plan 04 Summary: Independent Table Checkout Isolation and Checkout Failure Degradation

---

## 1. Plan Overview
- **Plan ID**: `06.1-04` (Gap Closure)
- **Goal**: Close VERIFICATION.md gaps SC2, SC3, and SC4 (and REVIEW.md CR-01, CR-02, WR-01, WR-02) for RAG-03 / DEBT-RAG-04 by:
  1. Giving `ProductionDenseRetrievalPort` and `rebuild_and_swap` / debounce tasks `DatabaseManager` handles to open independent `Table` instances via `database.nodes_table()` per call, preventing concurrent checkout races on LanceDB's shared `pinned_version` cell.
  2. Handling `checkout_latest` failures in `rebuild_and_swap` by logging, preserving the prior generation snapshot under write lock with `rebuild_degraded = true`, and returning `Err`.
  3. Adding regression test proofs for LanceDB clone coupling vs. independent open isolation (`shared_table_clone_checkout_mutates_sibling_pin`, `independent_nodes_table_checkout_stays_isolated`), checkout degradation (`rebuild_checkout_latest_failure_degrades_not_fails`), and updating invariant test target pins.
- **Status**: `COMPLETED`
- **Requirements Addressed**: `RAG-03` / `DEBT-RAG-04` (D-21, D-22, D-24, D-25; SC2, SC3, SC4).

## 2. Key Architecture & Production Changes

### A. Independent Table Handles for Dense Retrieval (`engine/src/service.rs`)
- `ProductionDenseRetrievalPort` now owns:
  ```rust
  pub struct ProductionDenseRetrievalPort {
      pub database: DatabaseManager,
      pub nodes_version: u64,
      pub retrieval_settings: retrieval::RetrievalSettings,
  }
  ```
- `retrieve_dense` opens a fresh `Table` via `self.database.nodes_table().await?`, then invokes `checkout(self.nodes_version).await?` before running `DenseRetriever::query`.
- `build_production_workflow` passes `self.database.clone()` and `snapshot.nodes_version`.

### B. Independent Table Handles and Checkout Failure Propagation in Rebuild-and-Swap (`engine/src/ingest.rs`, `engine/src/main.rs`)
- `rebuild_and_swap` signature updated:
  ```rust
  pub async fn rebuild_and_swap(
      database: &DatabaseManager,
      corpus_store: &crate::workflow::ports::CorpusStore,
      bm25_settings: crate::retrieval::Bm25Config,
  ) -> Result<Arc<crate::workflow::ports::CorpusSnapshot>, String>
  ```
- Body opens `nodes_latest` via `database.nodes_table().await` per rebuild.
- Replaced discarded `checkout_latest()` result with an explicit error handler: on `Err`, logs error, stores degraded snapshot with `rebuild_degraded: true`, and returns `Err`.
- Added test fault injection hooks `arm_rebuild_checkout_fail_next()` and `clear_rebuild_checkout_fail_next()`.
- `spawn_rebuild_debounce_task` and `main.rs` pass `DatabaseManager` / `database.clone()`.

### C. Regression Proofs & Test Updates (`engine/src/tests.rs`, `scripts/engine-test-targets.sh`)
- `shared_table_clone_checkout_mutates_sibling_pin`: Proves that `Table::clone()` shares `Arc<Mutex<DatasetState>>` `pinned_version` cell, so checking out one clone mutates the version observed by sibling clones.
- `independent_nodes_table_checkout_stays_isolated`: Proves that handles opened independently via `DatabaseManager::nodes_table()` maintain version isolation under separate checkout calls.
- `rebuild_checkout_latest_failure_degrades_not_fails`: Proves that `checkout_latest` failure during `rebuild_and_swap` retains the prior generation with `rebuild_degraded = true` and surfaces `NoticeCode::IndexRebuildFailed` (`NoticeSeverity::Warning`).
- Updated all call sites in `tests.rs` for `ProductionDenseRetrievalPort`, `rebuild_and_swap`, and `spawn_rebuild_debounce_task`.
- Updated `scripts/engine-test-targets.sh` pins to reflect 407 total tests (370 lib + 18 inspect_lancedb + 19 config_startup).

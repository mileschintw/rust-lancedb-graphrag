## Phase User Story

**As a** Lancet user ingesting documents and issuing RAG queries, **I want** the hybrid retrieval index (dense LanceDB and lexical BM25) to rebuild and atomically swap after ingestion batches without blocking active queries or serving mixed-generation evidence, **so that** query responses reflect one consistent corpus generation and post-ingest rebuild failures degrade with a clear notice.

<objective>
Implement index rebuild-and-swap, durable LanceDB-derived corpus generation, same-snapshot dense+BM25 pinning, worker debounce, degrade-with-notice, and fail-closed debounce config for RAG-03 / DEBT-RAG-04 (D-20 through D-26, D-74, D-76, D-83, D-84).

Purpose: Closes DEBT-RAG-04. Generation is `lance-{nodes.version()}` so D-21/D-24 proofs are discriminating (addresses review concern: staged_documents MAX is vacuous). Query path pins BM25 Arc and dense checkout from one snapshot (addresses review concern: mixed generations). Debounce is new code with an explicit counted seam (addresses pattern-mapper: no analog).
Output: CorpusStore, rebuild_and_swap, debounce loop, fail-closed rebuild_debounce_ms, concurrency proofs.
</objective>

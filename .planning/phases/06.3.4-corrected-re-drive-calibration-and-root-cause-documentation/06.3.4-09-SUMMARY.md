## 1. Accomplishments & Architecture Changes

### Task 1: T-06.3.4-25 — Meter Judged Spend, Then Cap It
- **Provider Usage Surfacing (`judge.py`)**:
  - Added `JudgeUsage` Pydantic model (`prompt_tokens: int`, `completion_tokens: int`), parsed defensively from OpenRouter's `usage` payload dict without raising on missing or malformed blocks.
  - Updated `judge_once` return signature to 3-tuple: `tuple[JudgeVerdict | None, str | None, JudgeUsage | None]`.
  - Updated all 5 call sites: `score.py:433` and 4 direct test call sites in `eval/tests/test_judge.py` (lines 119, 157, 179, 205).
  - Re-ask loop accumulates usage across attempts so total token cost of both attempts is metered.
- **Dedicated Judge Pricing Constants (`measure.py`)**:
  - Added `JUDGE_INPUT_PRICE_PER_1M = 0.59` and `JUDGE_OUTPUT_PRICE_PER_1M = 0.79` pricing `meta-llama/llama-3.3-70b-instruct` (recorded 2026-09-12 from OpenRouter pricing). Distinct from generator pricing.
  - Added `compute_judge_spend(prompt_tokens: int, completion_tokens: int) -> float` taking plain integers, avoiding circular dependencies between `judge.py` and `measure.py`.
  - Added `estimate_judge_cost_per_question(judge_max_tokens: int = 400, estimated_prompt_tokens: int = 1200) -> float` providing deterministic per-question spend bounds.
- **Fail-Closed Spend Cap on `score_run` & `score` CLI (`score.py`, `cli.py`)**:
  - Added `stage_spend_cap: float | None = None` keyword parameter to `score_run`. Raises `ScoreError` when judging is enabled without an explicit cap. Does not raise when judging is disabled (`no_judge=True`).
  - Added `--stage-cap` option to the `score` command in `cli.py` and forwarded to `score_run`.
- **Metered Judge Loop with Pre-Call Guard (`score.py`)**:
  - Compares accumulated judge spend against `stage_spend_cap` **before** dispatching calls. Breaks loop and sets `cap_stopped = True` if cap is reached.
  - Cached verdicts consume $0 and do not consume cap headroom.

### Task 2: T-06.3.4-24 / IN-03 / WR-03 — Reachable Slice-Size Refusal & Ambiguity Refusal
- **Reordered `derive_judged_slice_size` Guards (`gate.py`)**:
  - Evaluates `n_cap` first, then evaluates `cached_verdict_count` refusal (`if n_cap < cached_verdict_count or judgeable_count < cached_verdict_count: raise ValueError(...)`), and only then executes the `judgeable_count <= 0` shortcut.
  - Zero judgeable population with cached verdicts now raises `ValueError` naming the cached count as documented. Truly empty populations (`cached_verdict_count == 0`) continue returning `(0, "judgeable_count_is_zero")`.
- **Wired Slice Sizing into `score_run` Judged-Subset Selection (`score.py`)**:
  - Call site at `score.py:417` feeds `judgeable_count`, `cached_verdict_count` (reusing existing expression at `score.py:348`), `cost_per_question` from `estimate_judge_cost_per_question`, and `stage_spend_cap`.
  - Replaced unbounded `else` branch (which previously judged all primary-arm questions) with `derived_slice_size`.
  - Refuses `--sample` larger than `derived_slice_size` with explicit `ScoreError` explaining both requested sample and derived cap bound.
  - Questions are selected via existing deterministic seeded sampling (`sample_questions(..., seed=config.sample_seed)`).
- **WR-03: Deterministic File Finders (`gate.py`)**:
  - `_find_budgets_file` and `_find_store_baseline_file` sort matches deterministically and raise `FileNotFoundError` naming all candidates when more than one matches, removing all `matches[0]` indexing.

### Task 3: T-06.3.4-43 / IN-02 — Judged Slice Provenance & Unified Yield Floor
- **Judged Slice States (`dimensions.py`)**:
  - Followed `CALIBRATION_STATE_*` float encoding precedent: defined `JUDGED_SLICE_STATE_NOT_JUDGED = 0.0`, `JUDGED_SLICE_STATE_COMPLETED = 1.0`, `JUDGED_SLICE_STATE_CAP_BOUND = 2.0`, `JUDGED_SLICE_STATE_CAP_STOPPED = 3.0`.
  - Defined authoritative code-to-string dictionary `JUDGED_SLICE_STATES`.
- **Provenance on `RunMetadata` & Schema Regeneration (`report.py`, `eval/report.schema.json`)**:

  - Added validator rejecting values outside `JUDGED_SLICE_STATES.values()` and added to `_validate_non_blank_fields`.
  - Regenerated `eval/report.schema.json` via `emit_schema()` with explicit `newline="\n"`.
- **Carried Provenance into Judged Dimensions (`dimensions.py`, `score.py`)**:
  - Added keyword-only parameters `judged_slice_committed`, `verdicts_obtained`, `judged_slice_state` to `make_groundedness_result` and `make_faithfulness_result`, populating them in `detail` as floats for both normal and early/skipped results.
  - Passed provenance in `score.py` for both judged and unjudged (`no_judge=True`) paths.
  - Prioritized state resolution: `cap_stopped` > `cap_bound` > `completed`.
- **IN-02: Unified Investigation Floor Relocation (`thresholds.py`, `gate.py`, `dimensions.py`)**:

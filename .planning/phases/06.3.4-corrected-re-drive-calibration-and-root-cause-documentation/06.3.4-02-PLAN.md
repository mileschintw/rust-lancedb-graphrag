<objective>
Give the report the two agreement statistics the calibration decision actually requires, on the
standard library, before there is any human score to compute them from.

Purpose: D-48 requires quadratic weighted kappa **and** Spearman rank correlation on the paired
human and judge integers, against a target of at-or-above `0.70`, with judged numbers published as
uncalibrated below it. The harness computes neither today — `score.py` carries only a calibration
exact-match rate and a mean absolute deviation (`score.py:403-406,470-471`), and `dimensions.py`
exposes only those two as detail floats (`dimensions.py:124-125,174-175`). Neither answers the
question the target is stated against. The stated evaluation contract also forbids adding a
dependency, so both statistics are written here rather than imported.

This plan runs before any human score exists, deliberately. Writing the statistic after seeing the
ratings is how a target quietly becomes whatever the ratings happened to produce.

Output: `agreement.py`, the wiring through scoring and the report surface, and golden-vector tests.
</objective>

    - Perfect agreement returns one; agreement equal to chance returns zero; systematic disagreement returns a negative value.
    - Kappa where one rater used a single value throughout, so the expected-agreement denominator vanishes, returns a named, defined outcome rather than raising a division error.
    - Spearman rank correlation over two equal-length sequences returns the value the standard definition gives, with tied values resolved by the mid-rank convention; a published worked example with ties is used as the golden vector.
    - Rank correlation over a sequence with no variance returns a named, defined outcome rather than a division error.
    - Both functions reject sequences of unequal length, and both reject an empty input, naming the reason.
    - Both functions are order-invariant when the two sequences are permuted together, proven by permuting a fixture and asserting the same value.

    Create `eval/src/lancet_eval/agreement.py` with two pure functions and no third-party import.

    The first computes quadratic weighted kappa over two equal-length sequences of integer ratings on
    a stated scale, taking the scale bounds as arguments rather than inferring them from the observed
    ratings, so a worksheet where nobody used the extremes still scores against the full scale.
    Build the observed and expected matrices, apply quadratic weights over the rating distance, and
    return the weighted statistic. Where the expected-agreement term vanishes, return the defined
    outcome named in the behaviour block rather than dividing.

    The second computes Spearman rank correlation over two equal-length sequences, ranking each
    sequence with ties resolved to their mid-rank, then taking the Pearson correlation of the two
    rank vectors — which is the tie-correct formulation and avoids the closed-form shortcut that is
    wrong in the presence of ties. Where either rank vector has no variance, return the defined
    outcome rather than dividing.

    Both reject unequal lengths and empty input with a message naming which condition failed.

    Take the golden vectors from published worked examples rather than from values this
    implementation produces, so the tests check the definition rather than the code's own arithmetic.

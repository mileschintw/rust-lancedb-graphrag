## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| committed decision input → authorised spend | A threshold constant decides whether a paid drive starts | spend authorization |
| scored report → gate verdict | Gate reads numbers from code in an unexecuted sibling plan | gate telemetry |
| journal file → published report | Reconciliation rewrites the run-of-record line | run completeness metadata |
| superseded run directory → forensic record | Every forensic number in the shared decision record came from this directory | historical run evidence |
| eval harness → paid provider | Real queries against a metered external service (drive + judge calls) | provider spend |
| human calibration file → published judged scores | External file decides whether judged numbers are published as calibrated | calibration ratings |
| engine-reported index generation → run provenance | Hand-written generation makes the record set unattributable | run provenance |
| forensic evidence → published explanation | The root-cause doc is the project's own account of its failure | public documentation |
| roadmap file → every other phase entry | A wholesale write would silently destroy entries outside the edit window | planning bookkeeping |

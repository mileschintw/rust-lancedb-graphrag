# Phase 06.3.4 Plan 02: Summary

## Overview
Plan 06.3.4-02 implemented the agreement metrics, completed dual-scores reporting, and calibration label plumbing required by D-48 and OBS-05 on the standard library, before any human ratings exist:
1. **Agreement Statistics (`eval/src/lancet_eval/agreement.py`)**:
   - Standard-library-only implementation of Quadratic Weighted Kappa (Cohen 1968 formulation, quadratic weights across explicit rating scale bounds).
   - Standard-library-only implementation of Spearman Rank Correlation (mid-rank convention for ties, Pearson rank correlation).
   - Seeded bootstrap confidence intervals (`bootstrap_agreement_ci`) resampling paired rows with replacement to report sampling uncertainty at $n=12$.
   - Explicit disjoint state code constants:
     - `CALIBRATION_STATE_NONE = 0.0`, `CALIBRATION_STATE_BELOW_TARGET = 1.0`, `CALIBRATION_STATE_AT_OR_ABOVE_TARGET = 2.0`
     - `KAPPA_STATE_COMPUTED = 10.0`, `KAPPA_STATE_UNDEFINED_EXPECTED_AGREEMENT = 11.0`
     - `SPEARMAN_STATE_COMPUTED = 20.0`, `SPEARMAN_STATE_UNDEFINED_ZERO_VARIANCE = 21.0`
2. **Dimension Detail & Schema Protection (`eval/src/lancet_eval/dimensions.py`)**:
   - Accepted and populated 9 new calibration detail fields on `make_groundedness_result` and `make_faithfulness_result`: `calibration_kappa`, `calibration_spearman`, `calibration_kappa_state`, `calibration_spearman_state`, `calibration_state`, `calibration_kappa_ci_lower`, `calibration_kappa_ci_upper`, `calibration_spearman_ci_lower`, `calibration_spearman_ci_upper`, `calibration_pairs_n`, `calibration_excluded_n`.
   - Preserved `DimensionResult._validate_consistency` unchanged (`status 'ok' cannot have a reason`). Added explicit test guard in `eval/tests/test_dimensions.py` (`test_dimension_result_ok_with_reason_raises`) ensuring regression safety.
3. **Scorer Integration (`eval/src/lancet_eval/score.py`)**:
   - Evaluated agreement per judged dimension independently over each dimension's own 12 paired ratings (never pooled or copied).
   - Counted and reported excluded rows (missing either human rating or judge verdict, including worksheet rows missing judge cache entries).
   - Evaluated calibration against `AGREEMENT_TARGET` (0.70) strictly using point estimates alone (bootstrap CIs remain informational context).
   - Formulated human-readable shortfall and uncalibrated notes into `RunMetadata.notes` without touching `DimensionResult.reason`.
   - Counted completed human dual-scores into `calibration_completed_n`.
4. **Report Model & Schema Updates (`report.py`, `templates/report.md.j2`, `report.schema.json`)**:
   - Added `calibration_completed_n: int = 0` to `RunMetadata` with `extra="forbid"`.
   - Updated Markdown report template to render `Completed Calibration Dual Scores` in the metadata table.
   - Re-emitted matching `eval/report.schema.json`.

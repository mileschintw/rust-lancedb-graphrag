### Diagnostic Analysis of Preflight Failures

1. **Timeout Budget Verification**: All five production budgets derived by Phase 06.3.3 were satisfied across all 7 canaries without a single timeout violation:
   - `ReformulateQuery`: 0.0 ms (budget: 5,000 ms)
   - `RetrieveHybrid`: max 10,682 ms (budget: 16,647 ms)
   - `ExtractGraphContext`: max 31,332 ms (budget: 45,674 ms)
   - `AssemblePrompt`: max 778 ms (budget: 1,070 ms)
   - `GenerateAnswer`: max 16,211 ms (budget: 65,000 ms)
2. **Inner `query_embedding_timeout_ms` (645 ms) Network Sensitivity**:
   - `query_embedding_timeout_ms = 645` derived in 06.3.3-04 from `430.0 × 1.5` was sized strictly against local test distributions.
   - Live OpenRouter embeddings API calls across public HTTPS to `voyageai/voyage-4-large` intermittently take 700–1200 ms due to variable provider response latency.
   - When network jitter exceeds 645 ms, `ExtractGraphContext` times out early, failing closed.
3. **Canary 5 (`mhr-0d5e238015ef`) Graph Floor Miss**:
   - The question asks *"Who is the individual whose legal and financial actions are being scrutinized..."* without explicitly naming Sam Bankman-Fried in the query text.
   - Semantic vector search against entity names did not activate a seed entity yielding Cypher-confirmed facts, resulting in `GRAPH_UNAVAILABLE` (0 graph nodes).
   - This failure matches the explicit prediction in `06.3.3-STORE-BASELINE.md:239`: *"entity presence and connectivity do not establish that a live query would reach the entity, because production seeds by embedding similarity gated by seed_match_min_score rather than by name."*

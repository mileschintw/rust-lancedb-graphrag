### Paired Comparison Join (D-37, D-38)

**Source:** `eval/src/lancet_eval/score.py` — `pair_arms()` helper (implemented in 06.3.2, consumed by 06.3.4)

**Apply to:** Graph ablation delta computation

**Pattern excerpt** (pseudo-code — dict-based join per AI-SPEC §4; **null questions excluded**):
```python
# Inner join on question_id where BOTH arms are usable.
# Null questions are NOT in this join (AI-SPEC: "Null questions not in this join").
off_by_id = {r.question_id: r for r in usable_graph_off if not r.gold_is_null}
pairs = [
    (r_on, off_by_id[r_on.question_id])
    for r_on in usable_graph_on
    if not r_on.gold_is_null and r_on.question_id in off_by_id
]
pairs.sort(key=lambda pr: pr[0].question_id)   # determinism for the bootstrap

# Unpaired questions are DROPPED, and coverage is reported alongside the delta.
n_pairs = len(pairs)
```

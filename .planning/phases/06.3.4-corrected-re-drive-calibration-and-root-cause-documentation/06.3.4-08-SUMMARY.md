## 1. Accomplishments & Architecture Changes

### Task 1: Journal Header as a Function of Measured Completeness
- **Four-State Reconcile Matrix (`reconcile_header`)**:
  - `(is_complete=True, header_partial=False)`: no-op, returns `(True, False, msg)`
  - `(is_complete=True, header_partial=True)`: flip to publishable, returns `(True, True, msg)`
  - `(is_complete=False, header_partial=True)`: no-op, returns `(False, False, msg)`
  - `(is_complete=False, header_partial=False)`: correct to staged, returns `(False, True, msg)`
  - Updated docstring explicitly detailing the four-state contract and noting `publishable=False` does not imply no write.
- **Fail-Closed Drive Initialization & Safe Reconcile (`run.py`)**:
  - `drive()` initiates new journals with fail-closed staged header (`partial=True`), regardless of whether `--limit` is passed.
  - Reconciles completeness on all four exit paths:
    1. Normal completion (`run.py:369` pre-change)
    2. Cap-stop (`run.py:344` pre-change)
    3. Exception stop (`finally` block at `run.py:364` pre-change)
    4. Resume with no remaining units (`run.py:269-271` pre-change)
  - Hoisted module-level `import time` out of function bodies (IN-01).
  - Explicit `GRAPH_ARMS` membership check in `drive_one` raising `ValueError` for unknown arms rather than defaulting (WR-01).
- **RunRecord Schema Preservation**:
  - Retained `RunRecord.partial` with an explicit `Field(description=...)` marking it as a record-level `--limit` knob indicator, avoiding breaking 658 existing records under `extra="forbid"`.
- **Test Integrity & New CLI Tests**:
  - Split `test_reconcile_incomplete_makes_no_change` into `test_reconcile_incomplete_with_staged_header_makes_no_change` and `test_reconcile_incomplete_with_publishable_header_corrects_to_staged`.

<objective>
Turn the corrected drive's records into judged numbers that can be believed, and then take the two
dispositions the full drive's numbers finally make possible.

Purpose: the judged half of the benchmark has never actually run. In the superseded run 98 of 100
sampled questions were skipped for want of evidence, so the sixteen human scores judged answers that
barely existed and cannot carry forward. This plan produces a genuinely populated judged slice for
the first time, has a human score a fresh worksheet, and measures how far the judge and the human
actually agree — before anything published leans on the judge.

Two things about the ordering are not stylistic. The judged slice size is derived from what the
drive actually produced, so it is measured rather than chosen; and the harness's own calibration
guards refuse a calibration file fed back without judging, or at a sample scope narrower than the
verdicts already cached. Those guards are what stop a feed-back invocation silently discarding a
paid judged population. The ordering here bends to them and leaves them untouched.

Then the two dispositions, taken once each, on the full drive's numbers: whether graph yield cleared
the floor committed before the number existed, and whether the graph makes results worse. Both are
written so that an unflattering answer is a publishable outcome rather than a failure state.

Output: the sized worksheet, the human's scores, the republished report carrying agreement and its
calibration state, and `06.3.4-FINDINGS.md`.
</objective>

## The judged-slice derivation rule

This rule is committed **here, in this plan file**, before the drive it applies to has run. That
placement is the point: by the time this plan executes, the number it consumes already exists, so
the only way the rule can be independent of the number is for the rule to predate it in the
repository. Task 1 mirrors it into `gate.py` for machine use; the rule of record is this section.

**Inputs**

| Symbol | Meaning | Kind |
|---|---|---|
| `J` | Observed count of **judgeable** records in the report's primary arm: records the harness's usable-record predicate admits, whose gold question is present, **and whose structured citations are non-empty**. | measured |
| `C_j` | The judging-stage spend cap, from `06.3.3-BUDGETS.md`'s dated entry as amended by any judging cap recorded at 06.3.4-03's decision. | committed input |
| `p` | A conservative per-judged-question cost, recorded with its source and date **before** the judged pass runs, from the judge model's published price and the judge prompt's token budget. | committed input |
| `N_cap` | `floor(C_j / p)` | derived from committed inputs |
| `K` | The committed calibration size — the worksheet's row count — read from `gate.py`. | committed input |
| `V0` | Verdict count already in `judge_cache.json` before the judged pass. Expected zero, because every prior scoring pass in this phase ran with judging off. | measured |

**Rule**

    N = min(J, N_cap)          and N must be >= V0

The empty-citation condition on `J` is not decorative. The judge loop counts a record without
structured citations as skipped for want of evidence and never requests a verdict for it, so such a
record cannot join the judged population however large a slice is requested. Sizing against total
usable records instead would produce a slice the harness silently cannot fill — which is exactly the
shape of the failure this family exists to correct.

`N >= V0` is required because the harness refuses a calibration file fed back at a sample scope
narrower than the verdicts already cached; violating it would either raise or discard paid verdicts.

**Defined outcomes**

| Condition | Outcome |
|---|---|
| `N >= K` | Judged pass at `N`; worksheet emitted at `K` rows. |
| `0 < N < K` | Judged pass at `N`; worksheet emitted at `N` rows; recorded as short of the committed calibration size, with which bound caused it; agreement computed over fewer pairs and the judged numbers carry that statement. |
| `N == 0` | No judged pass, no worksheet, no agreement. Judged dimensions are published with the no-calibration label. A recorded outcome, not a failure. |
| `N_cap < J` | The **cap** bounded the slice, not the data. Recorded as such, with both figures. |
| `N_cap == J` | Both bounds coincide; the record states both rather than picking one. |
| `N == K` exactly | Satisfies the committed calibration size, which is stated as at-or-above. |

Everything on the left of that table is a comparison against a committed input. `J`, `V0`, the
observed spend and the observed agreement are **measured** and are never asserted in advance.
</judged_slice_derivation>

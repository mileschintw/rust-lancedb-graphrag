<objective>
Make the measurement driver honour its stage spend cap at every worker count, make "capped" mean capped
in both drivers, and stop `--stage-cap` from accepting values that silently disable the cap. This closes
UAT gap G-06.3.4.1-3b (06.3.4.1-REVIEW.md CR-01, WR-02, and WR-01's ordering bullet).

ROADMAP goal (verbatim, not reframed as a user story; the phase is non-MVP): "Separate seeding/index
drift vs vector/hybrid retrieval vs graph architecture; restore a working vector baseline; then make
graph-on produce a measurable paired effect."

Purpose:
- D-86 makes every paid stage spend under a cap the user authorises. `lancet-eval measure --workers 4`
  ignores that cap today: the parallel branch queues every unit at once (repro: 20 of 20 calls, $0.200
  against a $0.005 cap). A NaN cap defeats even the serial branch, because `spend >= nan` is always false.
- `run.drive`'s window, the pattern measure must reuse, labels a complete run as capped when the last
  record crosses the cap (WR-01). Copying it unfixed would carry the mislabel into measure.

Output: a bounded measure window with a recorded `stopped_by_cap`, the WR-01 ordering fix in both
drivers, and a validated, required `--stage-cap`.
</objective>

## Flagged Assumptions

- **One window for every worker count.** The serial branch is folded into the bounded window (a window of
  one) rather than kept beside it, so the capped path and the recorded `stopped_by_cap` cannot diverge again.
  With one worker, completion order equals dispatch order, so journal line order and ordinals are unchanged.
- **Library default kept, CLI default dropped.** `run_measurement_pass` keeps its keyword default because
  four tests and the CLI call it; it now rejects a non-finite or non-positive cap. The silent default the
  review names (WR-02) is the CLI's, and that one is removed.
- **Bounded, not a hard ceiling.** After the record that crosses the cap, up to `workers - 1` units already
  in flight still finish (the debug session's blind spot). That matches `run.drive` and is disclosed here.
- **Out of scope here:** WR-01's other bullets (unreachable failed-generation branch, allowance comparison,
  `resume=False` appends) and WR-03 (`--cheap-model`). Retry provenance (G-06.3.4.1-2) is 06.3.4.1-33/-34.

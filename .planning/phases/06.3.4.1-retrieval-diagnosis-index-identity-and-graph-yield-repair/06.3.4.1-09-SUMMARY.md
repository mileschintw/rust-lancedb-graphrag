# Phase 06.3.4.1 Plan 09: Vector-Only Diagnosis on the Reconciled Store Summary

**Built `diag_probe` (dense-only top-4 + production-chunker rechunk-check), fixed a real overlap-merge bug in the (b) split-fact classifier that had misclassified 49 genuine cross-chunk facts as `absent`, and froze G=398/V=291 candidates with a vector-only Recall@4=0.7312 on the reconciled store.**

## Accomplishments

- **`engine/src/bin/diag_probe.rs`** (new): `--vector-top-k K --questions --stage-cap [--cache] [--estimate-only]` runs a dense-only top-K through the exact `ProductionDenseRetrievalPort` at the engine's startup `nodes_version`, with an embedding cache keyed by `(question_id, embedding_model)` and a `--stage-cap` that stops dispatch *before* a batch would exceed it (not merely reports after). `--estimate-only` projects spend via `cl100k_base` tokenization with zero store/API access. `--rechunk-check DOC_IDS.json` replays the production chunker (`engine::ingest::chunk_ingestion_job`) over live `documents.raw_content` and compares to stored `nodes.content`, including control documents to validate the check itself.
- **`lancet_eval.diagnostic`**: the (c) join (`build_rows` gains `vector_top4_path`), `compute_populations` (G/V per D-63/D-82, reusing `in_gold_in_index_subset` for one definition of G), and a new `coverage` subcommand that cross-references a live `inspect_lancedb --document-ids` probe to distinguish genuine document presence from the (b) tri-state's ambiguous `absent` state.
- **Rule-1 bug found and fixed:** `classify_evidence_item`'s adjacent-window (b)/split-fact check naive-space-joined two overlapping chunks (`format!("{a} {b}")`), duplicating the shared `DEFAULT_CHUNK_OVERLAP` region and inserting an artificial space that never existed in the source document — a fact crossing the boundary beyond the overlap could never match, and was misclassified `absent`. This produced 49 false `absent` states (18 documents) on the first post-reconcile probe run. Fixed via `merge_overlapping_chunks` (removes the duplicated overlap before concatenating); all 49 are now correctly `split_across_chunks`, 0 `absent` remain.
- **Rechunk-check evidence for D-59:** all 18 candidate documents *and* 5 control documents show `identical: true` — re-ingesting any of them with the current chunker would reproduce the exact same two-chunk split, so re-ingestion cannot close the gap. User decided (2026-09-26): no re-ingest, no chunker change; split-fact questions stay outside G per D-63's single-chunk rule.
- **Frozen candidates:** |G| = 398 (comparison 161 / temporal 101 / inference 136), |V| = 291 (comparison 129 / temporal 61 / inference 101), vector-only Recall@4-on-G = 0.7312 — labelled non-comparable to the 06.3.4 journal's 0.3613 hybrid Recall@4 (different index generation, retrieval mode, and denominator).
- **(c) probe spend:** $0.00346392 for all 500 sample questions against an authorised $0.05 cap; `stopped_by_cap: false`; `index_generation` (`lance-702`) matches `document_map.json` on every row.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `classify_evidence_item`'s adjacent-window check misclassified overlap-crossing split facts as `absent`**
- **Found during:** Task 2's checkpoint — the coordinator/user investigated the 49 `absent` facts Task 1 surfaced (rather than accepting them at face value) and found all 49 are substrings of the true overlap-merged chunk span.
- **Issue:** `format!("{content_a} {content_b}")` naive-space-joins two adjacent chunks without removing their shared `DEFAULT_CHUNK_OVERLAP`-sized duplicated region, so a fact whose true span crosses the boundary beyond the overlap can never match the naive join.
- **Fix:** Added `merge_overlapping_chunks` (finds the longest suffix of chunk_a that equals a prefix of chunk_b, removes it, concatenates directly; falls back to a space join with no overlap).
- **Files modified:** `engine/src/bin/inspect_lancedb.rs`, `engine/src/inspect_lancedb_tests.rs`, `scripts/engine-test-targets.sh`.
- **Verification:** 4 new tests (3 unit, 1 regression via `inspect_gold_chunks`); `sh scripts/engine-test-targets.sh` green at the new TOTAL 552; re-ran the live probe and confirmed 49→`split_across_chunks`, 0→`absent`.
- **Committed in:** `fb3691b8` (fix), `fed016f7` (regenerated artifacts).

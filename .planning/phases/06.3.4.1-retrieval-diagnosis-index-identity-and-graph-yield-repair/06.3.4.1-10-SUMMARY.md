## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `build_diag_corpus_toml` duplicated `label_format` on the real source TOML**
- **Found during:** Task 2, first real-data run of the script
- **Issue:** `multihop_rag.toml` already sets `[questions] label_format = "multihop_rag"` explicitly (the plan's read_first characterization of the source TOML as omitting it was incorrect for this specific key). The initial implementation unconditionally inserted a fresh `label_format` line right after `file =`, producing two `label_format` lines in the generated `multihop_rag_diag.toml` — the second one shadowing the first at TOML-parse time (last-key-wins), so it happened to still parse correctly, but was non-idempotent-looking output and fragile.
- **Fix:** `build_diag_corpus_toml` now detects whether the source already sets `label_format` and either overwrites that line in place or inserts one only if absent — never both.
- **Files modified:** `eval/scripts/select_diag_sample.py`, `eval/tests/test_select_diag_sample.py` (added a regression test with a source fixture that already sets `label_format`).
- **Verification:** regenerated `multihop_rag_diag.toml` against the real source and confirmed exactly one `label_format` line; `tomllib.loads` round-trip test added.
- **Committed in:** `1f6f197e` (part of Task 2's GREEN commit).

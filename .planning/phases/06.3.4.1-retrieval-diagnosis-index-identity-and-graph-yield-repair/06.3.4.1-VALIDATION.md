## Sampling Rate

- **After every task commit:** Run that task's own `<automated>` command(s) from the Per-Task Verification Map (per-module form: `uv run --project eval pytest eval/tests/<touched_module>.py -x` / `cargo test --manifest-path engine/Cargo.toml --locked <filter>`, plus `sh scripts/engine-test-targets.sh` after any Rust test change)
- **After every plan wave:** Run `uv run --project eval pytest && uv run --project eval ruff check --preview eval/src eval/tests && cargo test --manifest-path engine/Cargo.toml --locked && (cd gateway && go test ./...)`
- **Before `/gsd-verify-work`:** Full suite must be green, plus `sh scripts/engine-test-targets.sh` with the raised counts
- **Paid stages:** each paid drive or pass is one invocation with `--workers 1 --retries 0 --no-resume` under the `--stage-cap` authorised at its checkpoint; the engine PID and start time are captured before and after; the journal is scored only through `score`/`report`
- **Gated drives (added 2026-10-06, effective once 06.3.4.1-33 and -34 land):** a drive whose journal `unpark_gates` will read also passes `--gate-stage <the label later given to unpark_gates --stage>` with `--retries 0`. Without the marker, every gate reading on that journal is MISS. Only the three recorded drives are exempt, through a closed registry.
- **Max feedback latency:** 300 seconds

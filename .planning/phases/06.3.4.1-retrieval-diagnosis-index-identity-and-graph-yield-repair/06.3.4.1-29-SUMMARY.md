## Decisions Made

- **The strip decision (D-95).** When a line renders, a model-written trailing `Answer:` segment on the prose's last line is stripped first, so the visible text carries one final Answer line. It is stripped only when it starts the line (after spaces, `>` or `-`) or follows whitespace, holds no `[` or `]` (a bracketed segment could carry a counted marker), and leaves prose behind. Otherwise it is kept, and the rendered line is still the last line-start match. Pinned by `generation::final_answer::tests::d95_trailing_model_answer_segment_is_stripped_when_a_line_renders`, `d95_a_bracketed_or_non_final_model_answer_is_kept` and `d95_the_rendered_line_is_the_last_line_start_answer_line`.
- **The whole-field fit rule.** If `chars(prose) + 9 + chars(field)` exceeds `MAX_ANSWER_CHARS`, no line renders and the answer is byte-identical (no partial field, no strip). Pinned by `d95_a_field_that_does_not_fit_whole_renders_no_line` (a prose of `MAX_ANSWER_CHARS - 16` chars renders to exactly `MAX_ANSWER_CHARS`; one char more renders nothing; no result exceeds the bound).
- **Empty or absent field.** Renders nothing and strips nothing, so the committed extractor scores the answer as before D-95 (`d95_absent_or_blank_final_answer_leaves_the_answer_byte_identical`, `d95_markers_and_brackets_are_stripped_from_the_field` for the marker-only case).
- **D-96 hard-coded.** `ProviderPreferences { require_parameters: true }` is a routing invariant of the strict-schema contract, so no config key and no config-trio agreement surface was added; `config/config.eval.toml` stays `lancedb_path`-only.
- **Trailer.** The dispatch text asked for `Co-Authored-By: Claude Opus 5.5`; the harness attribution reminder names `Claude Sonnet 5.5`, the model that actually ran, and attribution should name the real author, so every commit carries the Sonnet line.

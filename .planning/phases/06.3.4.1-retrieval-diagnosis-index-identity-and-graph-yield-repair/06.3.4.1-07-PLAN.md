  window (09-06/07) had already been deleted. Loki has no retention configured. Jaeger is in-memory

  real provider call fails with 401. The 5-second `egress_443` sampling is supporting evidence only,

  provider call can happen in this plan is the `paid-replay` option at Task 5 (D-86).

  `[System.IO.File]::WriteAllText` and a `System.Text.UTF8Encoding($false)` encoder, and serialise
  JSON with `ConvertTo-Json -Depth 10`. Never use `Out-File` or `>` redirection, which write
  UTF-16LE, and never rely on the default depth of 2. Never set an env var to the empty string to
  disable something: PowerShell 5.1 deletes the variable, and the engine and gateway both ignore empty
  values.

## Phase User Story

**As a** client of Lancet's `/rag/query` endpoint, **I want to** receive an honest, machine-readable
answer even when the graph is unavailable, one retrieval path fails, evidence is absent, or the
model's citations do not resolve, **so that** I can tell a degraded answer from a healthy one — and a
grounded answer from a model-only one — without parsing prose.

> Gap closure for SC3 (failed): the opted-in empty-evidence path must produce MODEL_ONLY on the
> production packing path, not only against FakeGenerator.

<objective>
Close 06-VERIFICATION.md gap SC3: make AssemblePromptNode's model-only helper and the OpenRouter
packing path agree so an opted-in zero-evidence run reaches the model and returns MODEL_ONLY.

Purpose: Plan 06-10 wired the opt-in, runner gates, and FakeGenerator tests, but
OpenRouterGenerator::execute_one_call still always calls pack_evidence_and_graph_prompt, which
returns EmptyEvidence; that maps to non-retryable InvalidRequest and NODE_ERROR_KIND_LLM_GENERATION_FAILED
before the provider is contacted. The outbound schema also omits model_only, and pack_model_only_prompt
reuses the grounded evidence policy.
Output: empty-evidence packing branch, dedicated model-only policy, schema enum admission, and a
GenerateAnswerNode.with_settings test that exercises the production packing function.
</objective>

## Phase User Story

**As a** client of Lancet's `/rag/query` endpoint, **I want to** receive an honest, machine-readable
answer even when the graph is unavailable, one retrieval path fails, evidence is absent, or the
model's citations do not resolve, **so that** I can tell a degraded answer from a healthy one — and a
grounded answer from a model-only one — without parsing prose.

> Gap closure for SC5 (partial): citation repair must tolerate repeated and mixed-spelling markers
> that resolve to the same evidence id.

<objective>
Close 06-VERIFICATION.md gap SC5: de-duplicate repaired citation ids at construction so the repair
pass no longer converts its own target cases into LlmGenerationFailed.

Purpose: citations::extract_markers / resolve_markers are 1:1 per occurrence; generate.rs pushes
every Unchanged/Repaired id into repaired_citations; validate_grounding_with_limits rejects
duplicate IDs. Repeated [1] or mixed [ 7 ] plus [7] against evidence [7] therefore fail the run,
while the repair-disabled path compares markers as a HashSet and allows repeats.
Output: first-occurrence unique repaired_citations, matching unique structured citations, and two
named repair tests covering both reproductions.
</objective>

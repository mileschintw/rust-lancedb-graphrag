## Accomplishments

- `strata.py` (new): `type_strata`, `constant_yes_baselines`, `paired_delta_strata`, `summarize`. Every value is a float, a stratum below `COMMITTED_THRESHOLDS.min_stratum_cell_size` carries n and value only, and a question outside the three G types raises naming it. The module has no literal cell-size threshold.
- `score.py`: per-arm dimensions on P4 for the four paper metrics, their script-faithful lines (n = the split's G size, `n_no_valid_ranking`), `answer_usable_p4` and `answer_usable_sc3_definition` (each with the constant-Yes baseline per type), `abstention_rate_g`, `null_abstention_correctness`, the D-70 secondaries, coverage/precision@4, latency p50/p95 and means, retrieve-node ms, prompt tokens, per-record spend, `p4_size` (coverage and per-arm exclusions by reason) and `arm_provenance_conformance`.
- 13 secondary paired deltas per comparison arm (`dense_only`, `bm25_only`, `hybrid_graph`) with `score` = mean paired difference, `ci_lower`/`ci_upper`, `n_pairs`, `mean_x`, `mean_hybrid`, D-40 delta strata, and `count_x`/`count_hybrid`/`count_delta` on the missing rate. No p-value or Holm key exists. The primaries' deltas are left to 06.3.5-13.
- Zero-tolerance provenance refusal (a, b, c, d, f) before any dimension or judge spend; (e) stays count-and-exclude, (g) counted only. Legacy corpora never run it.
- Per-record spend: `compute_spend([rec], include_embeddings=False)` plus one embedding estimate per attempt on every arm except bm25-only with graph context off (D-125).
- `paper_text_crosscheck.py`: `--emit-ids` (distinct `pre_truncation_ranking[:10]` IDs, single `index_generation`, non-zero on mixed generations) and the main mode (text-rule verdicts, per-arm disagreement counts over P4 and the script-faithful population, per-arm text-rule `hit4` for 06.3.5-13's Holm re-run). Exit 3 on a ranked ID missing from the dump, exit 4 on a final-eight excerpt that is not the engine's 512-code-point prefix of the dumped text (store drift), and a refusal on a dump text that does not match its `content_sha256`.
- Checked against the real inputs with a scratch script (not committed): the default post-reconcile `gold_chunks.jsonl` resolves, all 308 held-out G questions pass `_load_split_inputs` (125 comparison, 105 inference, 78 temporal), all 43 held-out null questions are null, every G question's raw `evidence_list` length equals its gold-set count (0 mismatches), and `engine.retrieval.excerpt_max_chars` is 512, the script default.

## Decisions Made

- `score_run(..., gold_chunks_path=None)` defaults to the 06.3.4.1 post-reconcile table. No config field names it and `cli.py` is sibling 06.3.5-11's file, so the CLI always uses the default.
- A metric with no value on some arm for some P4 question (a skipped recall, a record with no RetrieveHybrid timing) is computed over the questions every arm can score. The loss is `n_unscorable`, which keeps each delta equal to the difference of the per-arm means.
- `n_excluded` is `n_heldout_g - |P4|` (the P4 loss, identical across rows); `n_unscorable` is the metric-specific loss inside P4.
- The null dimension uses `is_abstention` (D-118), not the inherited D-72 equality.

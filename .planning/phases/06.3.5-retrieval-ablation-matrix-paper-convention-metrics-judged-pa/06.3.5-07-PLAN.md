Make MultiHop-RAG's own retrieval convention computable from a journal, proven against the official script's
outputs. Define arm provenance conformance as one function, so every later reader can decide ok(r). Give
06.3.6 its free dev baseline (D-104).

ROADMAP goal (quoted verbatim, not reframed; see 06.3.5-01). SC-3: "MultiHop-RAG's own retrieval convention —
Hits@k (k = 4 and 10) and MRR@10 over document-level evidence match — is computed as additive, labelled
dimensions beside Lancet's substring-containment metrics". D-102 governs where the official script's matching
unit differs from "document-level": the script matches fact text inside chunks, and lancet's ID rule maps that
through the D-61 gold-chunk table.

Purpose:
- FM3 ("paper convention" in name only) is caught only by golden vectors from the official function.
- FM4 (arm provenance) is caught only if every reader uses the same conformance check.

Output: the paper metrics and fixture, `provenance.py`, and the D-104 retro and its committed report.
</objective>

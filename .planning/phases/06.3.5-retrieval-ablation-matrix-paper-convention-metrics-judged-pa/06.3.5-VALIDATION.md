## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `cargo test` (Rust engine), `go test` (Go gateway), pytest 9 via `uv run --project eval` (Python harness). Proto is regenerated with `buf generate`. |
| **Config file** | `engine/Cargo.toml`, `gateway/go.mod` (go 1.25.0), `eval/pyproject.toml` (ruff `preview = true`), `buf.gen.yaml` |
| **Quick run command** | Harness: `uv run --project eval pytest <touched test files> -x`. Engine: `bash -c "set -o pipefail; cargo test --manifest-path engine/Cargo.toml --locked --lib <filter> 2>&1 \| grep -E 'test result: ok\. [1-9][0-9]* passed'"`. Gateway: `bash -c "set -o pipefail; cd gateway && go test ./... -run '<regex>' -v 2>&1 \| grep -c -- '^--- PASS'"` |
| **Full suite command** | `cargo test --manifest-path engine/Cargo.toml --locked && sh scripts/engine-test-targets.sh`; `cd gateway && go test ./...` and `sh scripts/gateway-test-targets.sh`; `uv run --project eval pytest eval/tests -q`; `bash -c "buf generate && git diff --quiet -- engine/src/pb gateway/proto"` |
| **Estimated runtime** | Harness about 120 s (baseline 1090 passed in 117.89 s). Engine full suite several minutes. Gateway under 1 min. |

**Baselines at research time (2026-10-06):**
- Engine: lib 635 passed + 2 ignored; inspect_lancedb 44; reconcile_eval_store 18; config_startup 22. `engine-test-targets.sh` exits 0 (TOTAL 721).
- Gateway: `go test ./...` all ok, but `gateway-test-targets.sh` **exits 1 today** (118 vs 114, pre-existing drift; it must be reset in Wave 0).
- Harness: `pytest eval/tests` 1090 passed.
- Proto: `buf generate` is idempotent.
- Do **not** use `uv run --project eval pytest -q` from the repo root. It also collects `scripts/`, which needs `python -O`.

**Rule for filtered commands:** `cargo test <filter>` and `go test -run <regex>` exit 0 when the filter matches zero tests.
- Every filtered Rust or Go command carries the non-zero-count guard shown above.
- Run the matching count script (`engine-test-targets.sh` / `gateway-test-targets.sh`) in the same step.
- pytest needs no guard: a missing file or test id makes pytest exit non-zero.

## Sampling Rate

- **After every task commit:** run the quick command for the touched stack (a guarded cargo filter, `go test` on the touched package, or the touched pytest files).
- **After every plan wave:** run every full suite command above: engine plus count script, gateway plus count script, `pytest eval/tests -q`, proto idempotence.
- **Before `/gsd-verify-work`:** every full suite is green, both test-count scripts exit 0, and the recorded-verdict re-read (`eval/tests/test_recorded_gate_verdicts.py`) is green.
- **Max feedback latency:** 180 seconds for a quick command.

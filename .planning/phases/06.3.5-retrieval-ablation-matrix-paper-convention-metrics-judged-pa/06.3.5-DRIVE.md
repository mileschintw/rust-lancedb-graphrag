## D-110 decision

**Outcome: `continue-with-disclosure (owner, post-hoc)`.** The owner gave this on 2026-10-08 ("Continue with disclosure") after the stop-2 handover. It is **not** one of Task 3's three options:
- `gates-pass-continue` was not available, because SC-2 reads MISS, and it is not claimed here.
- `redrive-via-gaps` and `halt-disclose` were both declined.

**What stands.**
- SC-2 reads **MISS** on dense-only `{'timeout': 4, 'other': 1}`, hybrid `{'timeout': 6}`, hybrid+graph `{'timeout': 2}` and pooled `{'timeout': 12, 'other': 1}`. bm25-only reads PASS.
- SC-1 reads PASS everywhere.
- `gates-heldout.md` and `gates-heldout.json` are unchanged. Every downstream document must carry the MISS as read, never relabelled.

**The owner's reasoning (recorded, post-hoc).**
- All 12 timeouts are `Query embedding timed out` at 2,001–2,016 ms against the committed 2,000 ms budget. That is provider latency at the boundary, and it happens at query embedding, before any arm-specific retrieval. So it says nothing about the relative quality of dense, hybrid or graph retrieval.
- The P4 population is paired. A question that errored in any arm is excluded from every arm, so all four arms are compared on the same 296 of 308 questions (coverage 0.961 against the 0.80 floor).
- A re-drive on unchanged code would most likely reproduce a dozen boundary timeouts and miss again.
- Making a re-drive pass would need an engine change after a held-out reading, which D-106 exists to prevent. It would also cost the single D-110 iteration and about 4 hours.

**What was not done.**
- No re-drive and no re-query of the 13 error rows: first-attempt errors are what SC-2 tallies (06.3.4.1-33).
- No change to the SC-2 rule, any threshold, the prompt, `config/` or the engine.
- No record was dropped or relabelled.

**Consequence.**
- Plans 06.3.5-16 (judged pass) and 06.3.5-17 (run of record) proceed on this drive under an `<owner_amendment>` block in each plan.
- The SC-2 MISS and this post-hoc deviation are a headline caveat of the run of record, not only a table row.
- This run directory is not superseded.

**Deferred to 06.3.6.** Both must be pre-registered before the next held-out drive:
1. a minimum error count or rate for SC-2's error-mode clause, which today has no materiality floor (D-89 covers only flatness);
2. an engine-side bounded retry for the query-embedding call, or a justified embedding timeout budget.

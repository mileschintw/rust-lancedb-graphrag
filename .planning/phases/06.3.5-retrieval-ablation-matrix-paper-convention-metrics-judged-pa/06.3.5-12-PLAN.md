<objective>
Build the only path that may produce judged numbers on the held-out run. It verifies, in code and from git
evidence, that the worksheet was emitted, then scored by the owner, then had its key revealed, in that order, with
the floor committed before the worksheet existed. Only then does it compute judge–human agreement with the D-114
labels and the per-arm judged means and paired judged deltas with their abstention and selection-effect companions.

ROADMAP goal (quoted verbatim, not reframed; see 06.3.5-01). SC-6: "... quadratic weighted kappa and Spearman rho
reported through the 06.3.4 machinery (closes 06.3.4 SC-3's deferral)."

Purpose: D-113 requires the owner's scores to be committed before any judged aggregate or per-arm judged delta is
shown. The legacy path writes judged aggregates in the same call that emits the worksheet, so it must refuse on this
corpus.

Output: the ordered ingest with its git gates, agreement with companions, the D-114 labels, judged aggregates through
`score --judged`, and the legacy refusals.
</objective>

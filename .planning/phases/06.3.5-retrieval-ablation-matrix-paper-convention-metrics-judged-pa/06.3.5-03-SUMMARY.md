## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - CLAUDE.md directive] `omitzero` instead of `omitempty` on the new gateway DTO fields**
- **Found during:** Task 2 (gateway)
- **Issue:** The plan text names `omitempty`; `go-guidelines.md` (mandatory for `.go` edits via CLAUDE.md, Go 1.25) says ALWAYS `omitzero` for slices, and it behaves identically for the string, int and nil-slice fields here.
- **Fix:** `retrieval_mode`, `pre_truncation_ranking`, `vector_rank`, `bm25_rank`, `graph_rank` use `omitzero`; the empty ranking converts to a nil slice so the key is omitted.
- **Files modified:** `gateway/internal/sse/dto.go`
- **Verification:** `TestQueryRAGRetrievalModeAndRankingRoundTrip` (absent `bm25_rank` asserted), existing 10-key snapshot pins unchanged and passing.
- **Committed in:** `db870f6f`

**2. [Rule 1 - formatting] Reshaped the mode gates in `retrieve.rs` to be rustfmt-clean**
- **Found during:** review of the recovered (killed-agent) diff
- **Issue:** the inline `if let Some(p) = self.port.as_ref().filter(..)` form made `cargo fmt --check` reflow a 70-line block, and an import was out of order.
- **Fix:** hoisted `let dense_port = ...filter(|_| run_dense);` / `let bm25_port = ...` before each `if let`, and sorted the import. No behaviour change.

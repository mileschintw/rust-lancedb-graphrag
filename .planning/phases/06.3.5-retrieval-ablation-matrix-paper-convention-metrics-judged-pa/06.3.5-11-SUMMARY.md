# Phase 06.3.5 Plan 11: Judge stage and calibration emit Summary

**A cache-only, counts-only `lancet-eval judge` over every judgeable held-out record of all four arms, and a `lancet-eval calibration emit` that draws the seeded, arm-stratified, blinded 20-item slice with an off-tree commit-reveal key, all tested offline against a fake judge.**

## Performance

- **Duration:** ~50 min (start time not captured; estimated from the commit timeline)
- **Completed:** 2026-10-07T10:03Z
- **Tasks:** 2 (each a RED test commit then a GREEN feature commit)
- **Files modified:** 5 (4 created, `cli.py` modified)

## Accomplishments

- `judge_stage.run_judge_stage` judges every 06.3.5-judgeable record over the split's held-out G IDs for all registry arms (no `--sample`, no cap-bound subsetting), one call per `cache_key`, verdicts in `judge_cache.json`, counts and timings in `judge-stage.json`. Judge model, temperature, max tokens and prompt version come from the corpus TOML.
- Every refusal runs before the first call (open journal, empty key, floor not at an ancestor of a clean HEAD and older than the journal, invalid cap, `uncached x 0.000264 > cap`, unknown arm, judge equal to generator, wrong split role). Errors are re-attempted once; 5 consecutive errors or an error rate above 0.05 once 50 keys are attempted halt the stage; the spend check runs before every call.
- `--rehearsal` judges the rehearsal journal's own records and records numeric per-call latency p50 and p95 for the 06.3.5-16 checkpoint; it refuses a non-rehearsal corpus, any split ID, or a journal with nothing judgeable.
- `calibration.emit_worksheet` refuses an incomplete or early-stopped stage, draws 2 comparison / 2 inference / 1 temporal per arm from P4 judgeable records in one seeded stream (empty cells filled and noted in the key), writes `calibration-worksheet.jsonl` into the run directory and the key and a `secrets.token_hex(32)` salt under `data/calibration-keys/<run>/`, and puts `key_digest(salt, rows)` in the header. It never overwrites.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Plan arithmetic] "4 errors in 60 calls do not trip the rate tripwire" cannot hold**
- **Found during:** Task 1 (test design)
- **Issue:** with `JUDGE_ERROR_RATE_TRIPWIRE = 0.05`, 4/60 = 0.067 exceeds it, and so does 4/64 if re-attempts are counted as calls. No ordering of 4 errors inside 60 keys can stay at or below 0.05 at the 60th key.
- **Fix:** implemented exactly `keys_attempted >= 50 and errors / keys_attempted > 0.05`, checked after every key, and tested consistent cases instead: 4 errors in the first 50 trip at 50 (54 invocations incl. 4 re-attempts), 2 errors in 80 never trip, and 3 errors in 60 (exactly 0.05) do not trip.
- **Files modified:** `eval/tests/test_judge_stage.py`, `eval/src/lancet_eval/judge_stage.py`
- **Committed in:** `9340c526`, `a5cacdcd`

**2. [Rule 3 - Blocking] `draw_slice` needs the judge prompt version and model**
- **Found during:** Task 2
- **Issue:** the plan's signature `draw_slice(records, split, arms, gold_map, *, seed)` cannot reproduce the cache key (it hashes both).
- **Fix:** added keyword-only `prompt_version` and `judge_model`.
- **Files modified:** `eval/src/lancet_eval/calibration.py`
- **Committed in:** `aebbd3c2`

**3. [Rule 2 - Missing critical] floor ordering also in the emit, and `created_at` required**
- **Found during:** Tasks 1 and 2
- **Issue:** the plan lists the floor commit and clean-tree refusal for the stage only, and says happy-path journals carry `created_at`. Without the same check in the emit, `emitted_at_sha` would not pin the floor the working tree uses.
- **Fix:** one shared `require_floor_ordering` (floor commit an ancestor of a clean HEAD and older than the journal's `created_at`; a header without a numeric `created_at` refuses) used by both the stage and the emit.
- **Files modified:** `eval/src/lancet_eval/judge_stage.py`, `eval/src/lancet_eval/calibration.py`
- **Committed in:** `a5cacdcd`, `aebbd3c2`

**4. [Rule 3 - Blocking] test helpers shared by import, fixture text hashed**
- **Found during:** Task 2
- **Issue:** `test_calibration.py` reuses the judge-stage builders by importing them from `test_judge_stage.py` (no `__init__.py`, no new helper file, to keep the plan's file list). The first fixture text named the arm and the question ID in answers and evidence, which the blinding test correctly flagged.
- **Fix:** fixture text now uses a hash of the question ID and an arm-neutral word per arm.
- **Files modified:** `eval/tests/test_judge_stage.py`
- **Committed in:** `aebbd3c2`

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| HTTP client → gateway | JSON `/query` body, including the new `retrieval_mode` | Untrusted request fields: closed name set, `DisallowUnknownFields` |
| gateway → engine (gRPC) | `QueryRAGRequest.retrieval_mode`, `RetrievalSnapshot` and ranking rows | Enum value, chunk IDs and ranks; no chunk text |
| engine → OpenRouter | Generation and judge calls | Prompts with retrieved context; API key from the environment only |
| harness → git | Pre-registration, reveal ordering and hash checks | List-form subprocess calls with validated revs |
| harness → split and corpus files | Dev, held-out, rehearsal and canary roles | Question IDs. Held-out exposure is the integrity asset |
| owner ↔ calibration worksheet | Blinded rows; key and salt revealed only after the scores commit | Human scores; arm, verdict and IDs withheld |
| `inspect_lancedb --chunk-text` → eval store | Read-only lookup at a pinned version | Chunk IDs in (escaped), chunk text out to gitignored `data/` |

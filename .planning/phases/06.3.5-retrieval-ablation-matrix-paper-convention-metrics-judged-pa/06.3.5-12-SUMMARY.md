# Phase 06.3.5 Plan 12: Ordered judged pass Summary

**`lancet-eval score --judged` is now the only path that produces judged numbers on the ordered held-out run: it first proves from git ancestry that the worksheet was emitted, scored by the owner and then had its key revealed, and only then writes per-arm judged means, paired deltas against hybrid with their abstention and selection-effect companions, D-40 strata, QWK agreement and the D-114 labels.**

## Accomplishments

- `calibration.ingest_and_verify` refuses unless the worksheet, key and salt are tracked and clean, all 40 scores are raw JSON integers 1-5, the worksheet's first commit holds only null scores and its header and row texts never change, the scores commit descends from that commit and from `emitted_at_sha`, the key and the salt were first committed strictly after the scores, `key_digest(salt, key rows)` equals the header, the floor parsed from `git show <emitted_at_sha>` equals the header and the current constant, every `slice_id` joins the key and every `cache_key` the cache, and every 06.3.5-judgeable held-out record has a cache entry.
- `calibration.agreement_summary` computes QWK and Spearman per dimension with seeded bootstrap CIs at `b=10000` (spied in a test), plus exact agreement, MAD, mean signed difference (judge minus human), each rater's marginal counts, the joint 5/5 share, dropped-resample counts and per-arm exact counts. An error verdict is dropped and its slice_id listed; there is no redraw.
- `d114_label` follows the pre-committed rule in order (QWK undefined, fewer than 16 pairs, below 0.70, otherwise calibrated; exactly 0.70 reads calibrated) and maps to the float codes 1.0 / 0.0 / -1.0 / -2.0. The legacy gate is printed as "legacy (06.3), non-governing" with the one-line divergence notice.
- `score --judged` reads the cache, makes no API call and builds `answer_groundedness__<s>`, `answer_faithfulness__<s>`, `answer_groundedness_delta__<s>`, `answer_faithfulness_delta__<s>`, `judge_qwk_groundedness` and `judge_qwk_faithfulness` through the existing fail-closed report path. Every per-arm mean and every delta row carries the abstention rate and n beside it; a row whose paired abstention-rate CI excludes 0 carries "abstention differs: conditional on both arms answering; not an arm effect on grounding". No judged row has a p-value.
- D-40 judged strata for every mean and delta: `type_<qt>_*` keys with a CI only at n >= 10, and `judged-result.json` rows with `ci: null` below that, each beside that type's abstention rate and n, with every delta-stratum CI labelled "unadjusted, estimation only".
- `score --judge`, `--emit-calibration-worksheet` and `--calibration-file` without `--judged` raise `ScoreError` naming `lancet-eval judge`, `lancet-eval calibration emit` and `score --judged` on a `[judge] protocol = "ordered"` corpus; legacy corpora behave as before (the legacy suite passes unchanged).

<objective>
Expand the tracer to every mode and harden the contract edges. bm25-only becomes a real BM25-only system:
no dense call, and no query embedding when the graph is off (D-125). The flag-on and explicit-hybrid
requests are proven byte-identical to the recorded golden (D-100, D-99). An unknown mode is refused at
the gateway and at the engine, and the gateway's default and explicit snapshot key sets are pinned.

ROADMAP goal (quoted verbatim, not reframed; see 06.3.5-01): "... how much each retrieval path contributes —
dense-only, BM25-only, hybrid (dense + BM25 RRF) and hybrid + graph ...".

Purpose:
- D-99's purpose is that per-arm latency and cost show the real cost of each path. Without D-125, bm25-only
  would still pay a Voyage embedding call and inherit its timeout failure mode.
- A silent default to hybrid on an unknown mode would make an arm delta an artefact (AI-SPEC FM4).

Output: the D-125 guard, the mode and identity pins, the engine admission refusal, and the gateway 400 and
key-set pins.
</objective>

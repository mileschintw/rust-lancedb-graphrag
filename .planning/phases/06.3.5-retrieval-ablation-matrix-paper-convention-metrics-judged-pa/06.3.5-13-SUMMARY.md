# Phase 06.3.5 Plan 13: Four-arm comparison and interim chart Summary

**`lancet-eval compare --run <dir>` turns a scored, judged run into `comparison.json` / `comparison.md` (two pre-registered exact-sign-flip Holm families, secondary paired deltas, D-40 strata, matching-rule robustness, the cited Table 5 row with its caveat, judged rows read from `judged-result.json`) and `chart.json` / `chart.svg` (a byte-identical SVG rendered from the chart data), refusing on any stale or inconsistent input.**

## Accomplishments

- **Holm families.** `holm_family` computes the exact two-sided paired sign-flip p over the discordant pairs (`stats.exact_signflip_p`), Holm step-down at FWER 0.05 (`stats.holm_stepdown`), the delta with its percentile-bootstrap CI (B = 10000, seed 42, labelled `unadjusted, estimation only`), and the decision per comparison. A real four-arm run gives, for `answer_usable`, bm25-only 1/8 discordant pairs, p = 20/512 = 0.0391, Holm-adjusted 0.1172, `not significant` with the note `CI excludes 0; not significant after Holm`.
- **Coverage and robustness.** `coverage_evaluable` is exact (`Fraction`), so 0.80 evaluates and 246/308 does not. With `diagnostic/text_crosscheck.json`, Holm is re-run on the text-rule hit@4 values and a flipped decision reads `not robust to the matching rule`; without it every ID-rule paper row carries `approximation; official text rule not verified`.
- **Secondaries and strata.** 13 secondary deltas x 3 arms are read from `report.json` and never recomputed. D-40 strata cover every per-arm G metric and both judged dimensions (a CI only at n >= 10), the `answer_usable` strata carry a `constant-Yes baseline` column, and the primaries' per-type paired deltas come from `strata.paired_delta_strata` over the same P4 0/1 values the exact test uses.
- **Judged and disclosures.** Judged rows, labels, agreement companions, slice-attrition ids, the legacy non-governing line and the paired judged deltas with selection-effect columns are read from `judged-result.json`. The abstention census, the D-121 / D-122 lines, the D-124 disclosure, the FWER statement and optional gate and provider tables are printed.
- **Paper reference row.** Table 5 "Without Reranker" rows (bge-large-en-v1.5 and voyage-02) verbatim with the citation, the (a)-(f) caveat and the population, subset, chunker and embedder sentences, and the comparable lancet line named. No superlative label.
- **Chart.** `chart.json` (schema_version 1) and a Jinja2 SVG 1.1 grouped-bar chart on a fixed 0-1 scale with Wilson error bars, rendered from the chart.json text alone, fixed two-decimal coordinates, LF line endings, no PNG.

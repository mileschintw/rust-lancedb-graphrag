<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| multipart caller → Go gateway | Caller-controlled chunk parameters and file metadata enter durable state. |
| Go gateway → Rust gRPC stream | Persisted processing settings cross a runtime/wire boundary. |
| environment/filesystem → Rust config loader | Process environment and configuration paths choose provider/store/listener settings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-17-01 | Tampering | chunk metadata contract | high | mitigate | Validate strategy/size/overlap before persistence and again on first-frame Rust admission; reject missing, repeated, or inconsistent metadata. |
| T-02-17-02 | Elevation of Privilege | gateway listener | high | mitigate | Bind explicitly to loopback per D-37 and document the immediate review trigger before any wider exposure. |
| T-02-17-03 | Spoofing | configuration directory | medium | mitigate | Resolve one explicit directory, exact base/overlay filenames, and locked override order with process tests. |
| T-02-17-04 | Information Disclosure | validation errors | low | accept | Errors identify invalid setting classes only; values are low-sensitivity processing metadata under the trusted local scope. |
</threat_model>

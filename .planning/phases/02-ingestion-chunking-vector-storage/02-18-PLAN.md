<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gateway process → PostgreSQL | Transient process memory becomes durable repair state. |
| competing workers → due-intent rows | Multiple process instances could attempt the same repair. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-18-01 | Tampering | reconciliation intent | high | mitigate | Foreign key, constrained desired status/retry count, typed queries, and conditional queued-row insertion. |
| T-02-18-02 | Denial of Service | due-intent claim | medium | mitigate | Bounded batch and leased atomic claim prevent one worker from monopolizing all due rows. |
| T-02-18-03 | Repudiation | retry lifecycle | low | accept | Timestamps, retry count, and class-only last error provide sufficient local diagnostics without an audit ledger under ASVS L1. |
| T-02-18-04 | Information Disclosure | reason/error columns | medium | mitigate | Persist diagnostic classes only; exclude raw gRPC errors, filenames, content, headers, and credentials. |
</threat_model>

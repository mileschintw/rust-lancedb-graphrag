## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| request handler → durable intent | A transient request hands correctness work to process-independent storage. |
| PostgreSQL claim → background worker | Durable rows drive autonomous terminal mutations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-19-01 | Tampering | terminal status reconciliation | high | mitigate | Conditional queued-to-failed transition and terminal-winner reread preserve valid winners. |
| T-02-19-02 | Denial of Service | reconciler loop | medium | mitigate | Bounded batches, per-intent isolation, leased claims, bounded contexts, and capped exponential backoff. |
| T-02-19-03 | Repudiation | failed-admission reason | low | accept | Stable reason class, retry count, and timestamps are sufficient for the local single-user boundary. |
| T-02-19-04 | Information Disclosure | operational errors | medium | mitigate | Store and return class-only messages; keep raw database/gRPC errors only in local structured logs. |

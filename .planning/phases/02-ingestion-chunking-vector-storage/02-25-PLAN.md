<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| durable staging → startup queue | Persisted jobs autonomously re-enter the bounded worker. |
| LanceDB status query → gRPC status | Storage failure or absence controls externally visible state. |
| worker result → staging/status stores | Ordering determines whether replay and terminal state can coexist. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-25-01 | Denial of Service | startup replay | high | mitigate | Spawn the consumer first and test `QUEUE_CAPACITY + 1` production-order recovery under timeout. |
| T-02-25-02 | Tampering | status classification | high | mitigate | Preserve query errors as Unavailable and reserve NotFound for successful zero count. |
| T-02-25-03 | Tampering | terminal/staging ordering | critical | mitigate | Require staging deletion before terminal publication and prove delete-failure replay/restart convergence. |
| T-02-25-04 | Information Disclosure | recovery diagnostics | medium | mitigate | Emit document identity plus error class/context only; never durable bytes or chunk/provider content. |
</threat_model>

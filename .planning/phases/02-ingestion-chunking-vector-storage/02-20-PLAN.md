<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted LanceDB values → inspector output | Durable but untrusted fields can reach terminals, CI logs, and agent context. |
| diagnostic inspector → evidence store | A verifier opens data whose state it must not alter. |
| schema lookup failure → replacement rollback | Corruption/fault handling crosses from Arrow schema to durable multi-table state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-20-01 | Information Disclosure | inspector errors | high | mitigate | Class-only errors plus sentinel regressions for unknown persisted values and invalid vectors. |
| T-02-20-02 | Tampering | inspector open path | high | mitigate | Separate read-only connect/open/validate API and before/after durable-state assertions. |
| T-02-20-03 | Denial of Service | ingestion worker | high | mitigate | Route true schema lookup failure through rollback and prove the same worker completes a subsequent job. |
| T-02-20-04 | Tampering | non-finite embeddings | medium | mitigate | Reject null/NaN/positive-infinity/negative-infinity children with independent real LanceDB fixtures. |
</threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Go gateway → Rust gRPC engine | Transport failure may obscure whether the job was admitted. |
| Engine status → PostgreSQL metadata | Untrusted/misrouted identity and state can mutate durable metadata. |
| Detached reconciler → PostgreSQL | Retry behavior can amplify load or overwrite a concurrent terminal winner. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-11-01 | Tampering | ambiguous admission handling | high | mitigate | Resolve against matching authoritative engine UUID before any failed transition. |
| T-02-11-02 | Spoofing | gRPC response identity | high | mitigate | Require response document_id equality on ingest and polling before persistence. |
| T-02-11-03 | Denial of Service | reconciliation retry | medium | mitigate | Use finite per-attempt contexts, controlled backoff, and stop on terminal convergence or shutdown. |
| T-02-11-04 | Tampering | terminal race | medium | mitigate | Keep conditional updates and accept only a reread terminal winner. |
| T-02-11-SC | Tampering | package installs | high | mitigate | No package install is planned. |

# Phase 06.3.2 Plan 04 Summary: Paired Ablation Delta, Bootstrap Interval, Cost Deltas, WR-02 Deduplication

## Implementation Overview
Replaced the flawed independent-list ablation calculation (`make_graph_ablation_delta`) with a rigorous per-question paired difference (`compute_paired_delta`, `form_pairs`, and `make_paired_ablation_delta`).

### Key Deliverables:
1. **Deduplication per Question AND Arm (WR-02 Closed Journal-Wide)**:
   - Implemented `deduplicate_by_arm(records)` in `eval/src/lancet_eval/pairing.py`.
   - Applied journal-wide immediately upon loading records in `score.py`, before structural checks, quality loops, judging, worksheet selection, and pairing join.
   - Preserves pairs on re-runs while collapsing duplicates, and publishes `collapsed_records_n` on `unusable_record_rate`.
2. **Inner Join & Audit Drop Buckets (`form_pairs`)**:
   - Matches records on `question_id` across `graph-on` and `graph-off`.
   - Requires both arms to be usable (`is_usable`).
   - Requires `graph-off` arm to prove provenance (`has_arm_provenance`: notice 18 present, notice 10 absent). Unproven graph-off records are dropped into a separate `provenance_drops` bucket.
   - Drops null questions (`gold_question.is_null`), while counting them in `total_distinct_questions`.
   - Sorts pairs by `question_id` ascending for deterministic bootstrap resampling order.
3. **Bootstrap Confidence Intervals & Degenerate Handling (`bootstrap_mean_ci`, `compute_paired_delta`)**:
   - Nonparametric percentile bootstrap at locked B=10,000 and seed=42 using standard library `random.Random` only.
   - Zero pairs -> `status="error"`, `score=None`, detail preserves pair counts and coverage.
   - One pair -> `status="ok"`, `ci_lower == ci_upper == delta`, `degenerate_ci=1.0`.
   - Stratifies by gold `question_type` (comparison, inference, temporal), omitting unrepresented strata.
4. **Companion Paired Quality and Cost Deltas**:
   - Added 4 answer metric paired deltas: `graph_ablation_delta_exact_match`, `graph_ablation_delta_f1`, `graph_ablation_delta_context_precision`, `graph_ablation_delta_ranking_quality`.
   - Added 2 structural cost deltas: `graph_ablation_latency_delta` (total query duration difference), `graph_ablation_prompt_token_delta` (prompt token difference, skipped if no metadata present).
   - Judged dimensions (groundedness, faithfulness) deliberately left unpaired to avoid doubling evaluation spend.
   - Note on units: Latency and token deltas score in absolute units (ms, token counts). As noted in the plan, `report.py` type-aware score formatting is owned by plan 06.3.2-05 task 3.
5. **Methodology Caveat**:
   - Added methodology caveat 9 to `eval/src/lancet_eval/templates/report.md.j2` clarifying that the 2026-09-03 `0.010` independent-means calculation is non-comparable to the redefined paired dimension.

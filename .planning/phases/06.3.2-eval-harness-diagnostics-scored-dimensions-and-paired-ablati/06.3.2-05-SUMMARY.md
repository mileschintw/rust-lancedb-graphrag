### Key Deliverables:

1. **CR-01: Refusal of Calibration Worksheet with Judge Disabled (`eval/src/lancet_eval/score.py`)**:
   - When `--emit-calibration-worksheet` is requested with `--no-judge`, `score_run` raises `ScoreError` naming both flags and instructing the operator to re-run with judging enabled (`--judge`).
   - Prevents emitting unverified slices when no cached judge verdicts can be verified.
   - Preserves calibration worksheet row limit (20 rows) unchanged.

2. **WR-03: Data-Driven Primary Arm Selection (`eval/src/lancet_eval/score.py`)**:
   - Primary scoring arm dynamically selects `graph-on` if `arm_metrics["graph-on"]["total"] > 0`, else `graph-off` if `arm_metrics["graph-off"]["total"] > 0`, with a deterministic belt-and-suspenders fallback to `graph-on`.
   - Removed dictionary-iteration order (`next(iter(...))`), ensuring graph-off only journals are correctly labelled and measured.

3. **WR-02: Consumer Contract Verification**:
   - Proved that the journal-wide deduplication landed in Plan 04 properly bounds consumers: duplicate records for the same question in the primary arm collapse to a population of 1 for judging and exactly 1 row for the calibration worksheet.

4. **WR-04 & IN-02: Safe Diagnostics & Unparseable/Dropped Cache Warnings (`eval/src/lancet_eval/score.py`, `eval/src/lancet_eval/judge.py`)**:
   - `_get_engine_generation_model`: logs warnings naming configuration path and exception type without logging file contents or secrets.
   - When generation model cannot be read:
     - Non-judging run stamps `unknown-generation-model` in report metadata.
     - Judging run raises `ScoreError` to refuse self-grading when generator model identity is unknown.
   - Embedding model provenance: stamps first available snapshot's `embedding_model`, or `unknown-embedding-model` when no snapshot supplies one (eliminating hardcoded provider fallback).
   - `JudgeCache._load`: counts invalid/dropped entries and logs a warning with the dropped count; logs a warning if the cache file is unparseable JSON; stays completely silent if cache file is absent (normal first-run state).

5. **Task 3: Type-Aware Formatting & Methodology Caveats (`eval/src/lancet_eval/report.py`, `report.md.j2`)**:

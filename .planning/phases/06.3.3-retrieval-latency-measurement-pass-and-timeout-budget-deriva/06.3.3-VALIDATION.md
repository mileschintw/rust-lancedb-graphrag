# Phase 06.3.3 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Seeded from `06.3.3-RESEARCH.md` § Validation Architecture.

> **Read this first.** This phase is planned at `--granularity coarse` and its acceptance
> criteria are **procedural, not value-bearing** — the numbers it depends on are produced by
> the measurement pass this phase itself runs. Validation therefore tests **the derivation
> machinery and its invariants**, never a specific millisecond value. A test asserting
> `retrieve_timeout_ms == 8000` would be wrong here; a test asserting *"the written budget
> equals the recorded p95 × the recorded multiplier, and the nesting invariant holds"* is right.

# Phase 06.3.3 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| operator config / environment → engine startup | `config.toml`, the `LANCET_ENV` overlay, and `LANCET_*` environment variables cross into runtime timeout budgets. | Configuration / environment |
| provider contract → generation retry loop | `generation_timeout_secs` bounds one attempt; `generation_node_timeout_ms` bounds the node containing up to two. A violated relation discards work mid-retry. | Runtime limits |
| engine SSE wire → harness record | Node timings, failures, and notices cross from the engine into `MeasurementRecord`; the harness derives production timeout budgets from them. | Operational / measurement |
| harness derivation → `config/config.toml` | Proposed budgets become production timeout values; incorrect values cause live timeouts or silent drops. | Configuration |
| test fixture → analysis function | Synthetic records stand in for a live pass; fixtures must faithfully reach code under test. | Test artifacts |
| planning record → future phase | `06.3.3-BUDGETS.md` records proven facts and go/no-go decisions for subsequent phases. | Planning documentation |

<objective>
Run the pass that turns two competing hypotheses into one answer, and dispose of every node that
blew a budget as a defect or as genuinely slow before anything is widened.

Purpose: the 2026-09-03 run decayed monotonically — ten successes in the first eleven positions,
then thirteen, then four, then three, then zero across the final 436 — inside a single process
after a resume. A uniformly-too-tight budget fails uniformly from query one, so decay is not what
a tight budget looks like. But every observation in that run was clipped at the budgets, so its
latency distribution is unknown and the two hypotheses cannot be separated from it. This pass
runs the same system with the ceilings lifted out of the way, so the tail is observed rather than
clipped, and restarts the engine mid-run so that process state and accumulated store state give
different answers.

Output: a committed measurement run, and `06.3.3-MEASUREMENT.md` carrying the pass configuration,
the censoring census, the decay verdict against its pre-committed criterion, and one investigation
disposition per budget-blowing node.
</objective>

# Plan 06.3.3-02 Summary: LanceDB Store Baseline and Inspection Modes

## Overview
Plan 06.3.3-02 delivered three read-only inspection modes to `engine/src/bin/inspect_lancedb.rs` and documented the comprehensive store baseline in `06.3.3-STORE-BASELINE.md`. This established the physical population, degree distribution, and canary entity connectivity of the evaluation knowledge graph without modifying the store.

## Key Changes

1. **New `inspect_lancedb` Modes (`engine/src/bin/inspect_lancedb.rs`)**:
   - `--graph-population`: Computes row counts across all 6 LanceDB tables (`documents`, `staged_documents_v2`, `nodes`, `edges`, `entities`, `entity_edges`), calculates the full degree distribution (min, median, p90/upper_percentile, p95, max), counts isolated entities (degree = 0), and emits an unpopulated flag when tables are empty.
   - `--entity <UUID> [--max-hops N]`: Delegates bounded neighborhood expansion directly to `graph::fetch_neighborhood` (preserving production's `MAX_TOTAL_EDGES = 500` guardrail, `MAX_FRONTIER_SIZE`, and `clamp_hop_cap`). Distinguishes invalid UUID, absent, isolated, and populated outcomes.
   - `--entity-name <NAME>`: Case-folded name lookup against the `entities.name` Arrow column, emitting matching `entity_id`, `name`, and `entity_type` rows ordered ascending by identifier.
   - Preserved document-scoped inspection mode (`<DOC_UUID> [--lancedb-path PATH]`).
   - Single-mode CLI argument parser `parse_args` ensuring exactly one mode is selected.

2. **Test Suite & Invariant Updates (`engine/src/inspect_lancedb_tests.rs`, `scripts/engine-test-targets.sh`)**:
   - Added 13 unit tests covering all new modes, edge cases (empty store, non-UUID rejection, case folding, ambiguous matches, isolated entities, hop bounding, deterministic output serialization without embedding vectors or raw content).
   - Updated `scripts/engine-test-targets.sh`:
     - `BIN_INSPECT_COUNT`: Raised from 18 to 31 (+13).
     - `TOTAL`: Raised from 498 to 511 (+13).
     - `LIB_COUNT` and `LIB_BIN_SUM`: Maintained at 458.
     - All 7 test invariants verified clean.

3. **Store Baseline Execution & Record (`06.3.3-STORE-BASELINE.md`)**:

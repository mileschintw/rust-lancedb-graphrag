<objective>
Build the instrument before using it: a measurement spine that can drive queries, record what
every node actually cost, tell a real observation from one clipped by a ceiling, and turn
percentiles into a proposed budget set by a rule stated in advance — proven end to end on one
small pass before several hundred paid queries are committed to.

Purpose: the 2026-09-03 run's observed retrieval p95 is exactly 10000 ms, which is not the
latency of retrieval — it is the value of `retrieve_timeout_ms`. 904 of 1000 queries were clipped
at that ceiling. A budget derived from that percentile would reproduce the defect it is meant to
fix. Everything in this plan exists to make that failure mode impossible: censoring is counted,
percentiles over censored data are refused or flagged, and the decision inputs are committed to
the repository before any data is seen.

Output: `thresholds.py`, `latency.py`, `decay.py`, `measure.py`, a `measure` command on the eval
CLI, an environment-aware live-timeout reader in `preflight.py`, and one committed calibration
micro-pass record proving the whole chain runs.
</objective>

  <behavior>
    - **Bootstrap determinism:** the same observation set and the same committed seed produce
      identical interval bounds on repeated calls and across process restarts.
    - **Isolation:** computing an interval does not disturb the module-level random sequence — a
      caller drawing from the global generator before and after sees an unchanged sequence.
    - **Interval ordering:** the lower bound is at most the point estimate, which is at most the
      upper bound, for every sample size at which an interval is produced.
    - **Small samples:** below the stated minimum sample size the interval is returned explicitly
      as unavailable with a stated reason and the sample size, not as a degenerate pair.
    - **Single observation:** a set of one produces a point estimate with an explicitly degenerate
      interval flagged as such.
    - **Censoring propagates:** an interval computed over a set containing censored observations
      is flagged exactly as the point estimate is; the flag is never lost in the interval path.
    - **Provider-contract budget:** the generation node budget is produced from the provider
      attempt count, the per-attempt provider timeout and a recorded slack — not from measured
      generation latency — and the returned record says so in its own provenance field.
    - **Measured generation reported, not used:** measured generation latency is present in the
      output as a reported observation carrying an explicit marker that it is not derivable from
      this pass, and no derivation path consumes it.
    - **Reformulate reported, not derived:** the reformulate node's measured latency is present as
      a reported observation and no derivation path produces a value for it.
    - **Nesting groups enumerated:** the report covers every nesting relationship in the seven-field
      set, states the containing budget, the contained budgets, the slack, and which is expected to
      fire first.
    - **Wall-clock consistency:** the report states the worst-case sum of the proposed node budgets
      and compares it against the harness ceilings supplied to it, flagging the case where the sum
      exceeds either.
  </behavior>

    so an ordinary least-squares slope would be pulled around by exactly the observations that
    matter most. The pairwise slope median and the rank-correlation statistic are robust to that.

    window's size and percentile, the delta, and the materiality threshold it was compared against.

    hypothesis the comparison supports. When the interval spans zero, say inconclusive rather than
    picking a side; that is a legitimate result and the phase's own criterion allows for the
    verdict to be open.

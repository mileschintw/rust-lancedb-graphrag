## 5. Inner Budget Decomposition

`ExtractGraphContext` is an outer workflow node wrapping two sequential operations: `query_embedding` (Voyage API call) and `graph_operation` (LanceDB Cypher traversal). The wire protocol emits duration only for the enclosing node. Decomposition is performed via pinned experimental strata:

1. **Outer `graph_node` (Enclosing Budget)**:
   - Stratum: `graph-on` arm only ($n=160$).
   - Observed p95: **30,449.0 ms**
   - Observed p99: **30,551.0 ms**
   - Max Observed: **31,079.0 ms**

2. **`query_embedding` (Inner Budget 1)**:
   - Stratum: `graph-off` arm only ($n=160$), where execution early-returns before graph traversal.
   - Single-Writer Verification: Verified against `graph_context.rs:72-104` that the embedding runs idempotently and is never pre-computed by earlier nodes.
   - Observed p95: **430.0 ms**
   - Observed p99: **640.0 ms**
   - Method: Arm-isolated duration measurement.
   - Span Corroboration: **None available**. `RETAINED_GRAPH_SPAN_NAMES` (`engine/src/telemetry/mod.rs:44-47`) retains `graph_traversal` and `graph_context_extraction` only. `embedding_request` is omitted by design; this estimate rests solely on the `graph-off` arm measurement.

3. **`graph_operation` (Inner Budget 2)**:
   - Stratum: Paired per-question difference ($\text{duration}_{\text{graph-on}} - \text{duration}_{\text{graph-off}}$) over surviving clean pairs.
   - Excluded Pairs: **21 pairs** excluded due to `GRAPH_TIMEOUT` notices on the `graph-on` arm (0 node failure timeouts).
   - Surviving Pairs: 139 pairs.
   - **Survivor Guard Rule Application**:
     - Observed graph-on `GRAPH_TIMEOUT` rate: **13.125%** (21 / 160).
     - Pre-committed Maximum Tolerated Rate (`max_tolerated_graph_timeout_rate`): **10.0%**.
     - Finding: Because 13.125% > 10.0%, excluding timed-out pairs biases the surviving population toward faster traversals.
     - Mandated Action: Reported as an explicit **censored-from-above lower bound**, not a true population percentile.
   - Observed Paired Difference p95: **$\ge$ 25,730.0 ms** (lower bound).
   - Evidence Strength: **Weakest in the phase**. Traversal latency was partially clipped at the 30s ceiling for 13% of queries.

4. **Nesting Invariant Proof**:
   - Condition: $\text{graph\_node} \ge \text{query\_embedding} + \text{graph\_operation}$ (`engine/src/config.rs:321-329`).
   - Check: $30,449.0 \text{ ms} \ge 430.0 \text{ ms} + 25,730.0 \text{ ms} = 26,160.0 \text{ ms}$.
   - Result: **Satisfied with +4,289.0 ms natural slack**. No inner trimming or conflict resolution is required.

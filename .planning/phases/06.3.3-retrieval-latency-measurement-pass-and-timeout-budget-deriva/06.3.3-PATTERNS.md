### Percentile and Trend Computation (D-14, D-19)

**Source:** math stdlib functions + published statistical methods (RESEARCH.md §Code Examples)

**Applied to:** latency.py (percentiles) + decay.py (trends)
- All computation uses stdlib `statistics` and `math`, never scipy/numpy
- Bootstrap percentile CI uses seeded `random` for reproducibility (deterministic CI bounds for reporting)
- Theil–Sen slope uses rank-based pairwise comparisons (robust to outliers in latency distributions)
- Return type always `dict[str, float]` for JSON serialization to journal/report

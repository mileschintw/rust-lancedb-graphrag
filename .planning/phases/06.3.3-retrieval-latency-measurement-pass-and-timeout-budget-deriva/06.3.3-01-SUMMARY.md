# Plan 06.3.3-01 Summary: Latency Measurement Spine and Timeout Budget Derivation

## Overview
Plan 06.3.3-01 implemented the core latency measurement and budget derivation spine for Phase 06.3.3. It provides deterministic, reproducible, and censorship-aware analysis of workflow node execution timings.

## Key Changes
1. **Committed Thresholds (`thresholds.py`)**:
   - Explicitly locks decision inputs before measuring: `multiplier=1.5`, `derivation_percentile=0.95`, `decay_significance_threshold=0.05`, `materiality_delta_ms=500.0`, `window_fractions=(0.25, 0.25)`, `segment_boundary_sizes=(30, 30)`, `min_stratum_cell_size=10`, `max_tolerated_graph_timeout_rate=0.10`, `bootstrap_seed=42`, `slack_ms=500.0`.
   - Lacks defaults for multiplier and decay significance to satisfy D-14 (cannot ship uncommitted guesses as policy).

2. **Latency & Derivations (`latency.py`)**:
   - Mutually exclusive 5-way censoring classification: `OBSERVED`, `CENSORED_AT_CEILING`, `CENSORED_NODE_TIMEOUT`, `NOT_REACHED`, `INSTRUMENT_GAP`.
   - Dual classification for graph context: inner label `CENSORED_INNER_GRAPH_OP` alongside node-level `OBSERVED`.
   - Deterministic bootstrap CI using local `random.Random(seed)`.
   - Provider contract derivation for generation node budget (`engine/src/config.rs:333-344`).
   - Nesting invariant resolution raising outer budget to `inner_sum + slack` and labelling row `invariant-driven`.
   - Two distinct harness ceiling checks (`single_max < read_timeout`, `worst_case_sum < deadline`).
   - Stratified sample size derivation (`required_sample_size`) and graph survivor guard.

3. **Decay Detection (`decay.py`)**:
   - Theil-Sen slope and Mann-Kendall test in pure stdlib.
   - Window comparison between early and late slices.
   - Segment-boundary restart comparison between tail and head.
   - Precondition sorts by ordinal before validating uniqueness and continuity; physical line order is not required to be monotonic.
   - Note on Usability Predicate: The phase pattern map directing `is_usable` filtering is superseded here because applying `is_usable` would discard timeout failures, blinding the instrument to its own censoring.

4. **Measurement Driver & CLI (`measure.py`, `cli.py`, `preflight.py`, `client.py`, `run.py`)**:
   - `MeasurementRecord` extending `RunRecord` with `ordinal`, `segment`, `question_type`, `dropped_node_timings`, `warm_up` (extra="forbid").
   - Two-armed adjacent dispatch with 1-indexed monotonic ordinals.
   - Spend tracking pricing both embeddings and generation.
   - Fail-closed allowance checks and PostgreSQL schema isolation assertions.
   - Threaded SSE read timeout deriving from `EvalSettings.gateway_timeout_secs` without hardcoded `300.0`.
   - Added `@app.command("measure")` in `cli.py`.

5. **Calibration Run Artifact**:
   - Generated `eval/runs/2026-09-06-measure-multihop_rag/` containing `journal.jsonl`, `measurement.json`, and `run_record.json`.
   - Confirmed disjoint from benchmark resume glob (`measure-dir-disjoint-from-resume-glob`).

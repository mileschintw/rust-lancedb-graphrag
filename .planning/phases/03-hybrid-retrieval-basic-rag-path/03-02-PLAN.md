<interfaces>
From the tracer slice:
- `Retriever` owns query normalization, typed filters, dense/BM25 coordination, and the typed per-path outcome seam.
- `Bm25Index` is built from canonical completed-node records and exposes deterministic query results under `Bm25Config`.
- `fuse_candidates` accepts ranked dense and BM25 candidates and returns deduplicated `FusedCandidate` values.
- `Reranker` is an object-safe boxed-future port and `NoOpReranker` is the default pass-through implementation.
- `LancetServiceImpl` owns the query-ready retrieval state and registers only after startup initialization.
</interfaces>

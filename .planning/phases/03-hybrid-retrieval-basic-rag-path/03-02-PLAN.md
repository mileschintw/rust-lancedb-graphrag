<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Retrieved evidence to prompt/provider | Untrusted corpus text and user question cross into a model request. |
| Provider response to Rust validator | External structured JSON becomes answer text, basis, notices, warnings, and evidence IDs. |
| Rust configuration to OpenRouter | Endpoint/model settings and bearer credentials select an external service. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-02-01 | Tampering | Evidence prompt boundary | high | mitigate | Use engine-owned IDs, isolated evidence blocks, escaped delimiter-like source text, and explicit untrusted-data framing. |
| T-03-02-02 | Tampering | Provider structured output | high | mitigate | Deserialize a closed schema, validate answer basis and cited IDs against the evidence map, and reject unsupported fields. |
| T-03-02-03 | Denial of Service | Provider request and context | high | mitigate | Reserve the answer budget, bound evidence/excerpts, enforce one timeout-bounded call, and propagate cancellation. |
| T-03-02-04 | Information Disclosure | OpenRouter credentials and errors | high | mitigate | Load keys from environment, redact secrets/raw prompts/raw evidence, and return only typed contextual provider errors. |
| T-03-02-05 | Spoofing | Citation/evidence identity | high | mitigate | Accept only engine-issued evidence IDs and rebuild public citation fields from supplied evidence. |
</threat_model>

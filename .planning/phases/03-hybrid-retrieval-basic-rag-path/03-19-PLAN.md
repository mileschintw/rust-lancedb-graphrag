## Assumption-delta decision

Promote the existing logical GroundingLimits contract from 03-16 into the literal settings-owned carrier required by G1; do not add a parallel carrier. The carrier is Arc-backed so EffectiveRagSettings and OpenRouter configuration share one underlying instance, while all callers receive read-only accessors.

## Deferred boundaries preserved

This gap-closure set keeps RAG-03 degraded or model-only behavior, citation repair or downgrade, full BM25 re-ingestion/restart lifecycle, exhaustive filter matrices, and graph fallback as deferred boundaries. It does not add alternate providers, provider retries, tools, or streaming chat capability to the API matrix.

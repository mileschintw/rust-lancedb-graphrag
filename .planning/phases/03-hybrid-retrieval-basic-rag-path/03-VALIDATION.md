# Phase 03 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

**Scope gate:** The Phase 03 validation map covers current RAG-02/RAG-04 acceptance only: the valid dense+BM25 query path, bounded evidence, one structured generation call, valid citations, and the initial BM25 build/readiness safeguard. RAG-03 is opted out of this phase and mapped to Phase 06 hardening; DEBT-RAG-01, DEBT-RAG-03, DEBT-RAG-04, DEBT-RAG-05, and DEBT-RAG-06 remain future validation targets rather than Phase 03 gates.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust built-in tests with `#[tokio::test]`, Go standard `testing`/`httptest`, Buf CLI checks |

| **Full suite command** | `cargo test --manifest-path engine/Cargo.toml --locked; $cargoExit = $LASTEXITCODE; if ($cargoExit -ne 0) { exit $cargoExit }; Push-Location gateway; $goOutput = go test ./...; $goExit = $LASTEXITCODE; if ($goExit -ne 0) { Pop-Location; exit $goExit }; Pop-Location; buf lint; $bufExit = $LASTEXITCODE; if ($bufExit -ne 0) { exit $bufExit }` |
| **Estimated runtime** | ~60 seconds locally, excluding the explicitly ignored live OpenRouter smoke |

## Sampling Rate

- **After every task commit:** Run the task's focused Rust, Go, Buf, or API-coverage command from the map below.
- **After every plan wave:** Run the full-suite wrapper above; repeat the wrapped `buf generate` stability check after contract changes.
- **Before `/gsd-verify-work`:** Full suite must be green; the live provider smoke is run only when its user setup precondition is available.
- **Max feedback latency:** 60 seconds for local checks; external provider smoke is an explicit ignored check with network-dependent latency.

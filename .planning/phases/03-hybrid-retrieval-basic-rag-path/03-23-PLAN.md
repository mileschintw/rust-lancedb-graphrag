## Trust Boundaries

| Boundary | Description |
|---|---|
| Ingestion job -> Lance staged table | Raw payload, document identity, and chunk settings cross into durable storage. |
| Legacy Lance schema -> initialization migration | Existing table metadata and rows determine whether generation compatibility can be established safely. |
| Staged generations -> startup replay/status | Multiple visible rows can exist during deletion failure and must resolve deterministically. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-23-01 | Tampering | raw replacement order | high | mitigate | Append successor, verify exact row, then use Lance delete/deletion-index for old generations; never delete-first. |
| T-03-23-02 | Denial of Service | malformed legacy schema or generation overflow | high | mitigate | Migrate only an exact legacy schema, require non-null Int64 generation, use checked generation increment, and fail closed on drift/overflow. |
| T-03-23-03 | Integrity | latest-generation reader | high | mitigate | Select maximum visible generation per stable document_id, reject equal-generation ambiguity, and test replay after deletion failure. |
| T-03-23-04 | Availability | old-generation deletion failure | medium | mitigate | Retain both old and verified new rows, return the deletion error, and let the existing replay/status path observe the new latest row. |
| T-03-23-SC | Tampering | package-manager installs | low | accept | No package-manager install or dependency change is part of this plan; the locked repository dependencies are reused. |
</threat_model>

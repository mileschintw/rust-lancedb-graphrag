## Phase Goal

**As a** chat service API user, **I want to** ask a question over indexed content and receive a grounded answer with trustworthy citations, **so that** I can verify every claim against the retrieved evidence.

<objective>
Close the phase-goal citation safeguard in the RAG-02 query path by projecting Plan 03-06 validated citation IDs and provider diagnostics through the existing protobuf response using stable identity and Plan 03-07 effective excerpt settings.

Purpose: The caller must receive metadata for the evidence the model actually cited, not whichever block occupied the same vector position.
Output: Identity-correct citations, Unicode-bounded excerpts, severity-correct diagnostics, and service regressions.
</objective>

<scope_note>
This plan projects only already validated output through existing protobuf fields. D-24 repair/downgrade, deferred degraded/model-only branches, and RAG-03 remain outside the closure. The change is reversible and has no wire or stored-data migration.
</scope_note>

<spec_edge_resolution>
No Phase 03 SPEC exists. The citation edge is resolved concretely: resolve every unique validated cited ID through a packed-evidence map, build the entire citation/diagnostic response off to the side, and publish only after all identities succeed. Excerpt limits count Unicode characters and is_truncated states whether any characters were removed.
</spec_edge_resolution>

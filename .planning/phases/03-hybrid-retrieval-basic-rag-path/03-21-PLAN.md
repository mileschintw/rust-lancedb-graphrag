## Assumption-delta decision

Promote the provisional ADR-03-002 ceiling integers into named Rust constants shared by settings validation and tests. Set MAX_SERVICE_FILTER_VALUES_PER_KEY to 100, explicitly adjusting the ADR's provisional 64-value planning integer because locked D-56 requires the default document-ID limit of 100 to remain valid; this preserves the ADR policy of an operator-configurable limit with a separate absolute maximum and no silent clamp. Keep operator knobs configurable within those limits; do not replace them with hardcoded request behavior or a silent clamp.

## Exact ceiling contract

- MAX_SERVICE_CANDIDATE_LIMIT = 500.
- MAX_SERVICE_FINAL_LIMIT = 100.
- MAX_SERVICE_QUERY_MAX_BYTES = 8192.
- MAX_SERVICE_FILTER_KEYS = 32; the current typed QueryFilters shape has two fixed keys.
- MAX_SERVICE_FILTER_VALUES_PER_KEY = 100; this is the exact adjusted target for the ADR's provisional 64-value integer so D-56's default max_document_ids = 100 remains accepted; max_document_ids and max_content_types each must be at or below 100.
- MAX_SERVICE_RRF_WEIGHT = 16.0 by absolute magnitude.
- MAX_SERVICE_RRF_K = 1000000.0; the current 60.0 value remains unchanged.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Operator config or environment -> RetrievalSettings | Values can be intentionally or accidentally enormous and affect allocations, Lance queries, and response size. |
| HTTP/gRPC filter input -> QueryFilters | Caller-provided lists and UUID/content-type values cross into normalization and typed predicates. |
| Completed Lance snapshot -> BM25 and dense retrieval | Corpus size and score distribution are untrusted inputs to candidate work. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-21-01 | Denial of Service | RetrievalSettings and QueryRequest | high | mitigate | Reject exact over-ceiling values at startup/request boundaries; do not clamp or allocate from an unchecked filter length. |
| T-03-21-02 | Denial of Service | Bm25Index::query | high | mitigate | Retain at most candidate_limit entries with a bounded top-candidate buffer while scanning the full snapshot. |
| T-03-21-03 | Tampering | dense filter predicate | medium | mitigate | Reuse typed UUID/content-type normalization and SQL-literal escaping after bounds are validated; do not interpolate raw caller values. |

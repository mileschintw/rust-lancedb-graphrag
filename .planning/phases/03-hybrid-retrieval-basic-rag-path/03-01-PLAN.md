<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Client to Go gateway | Untrusted JSON question, session ID, filters, and body size cross into the HTTP boundary. |
| Go gateway to Rust tonic service | Shared wire fields and status codes cross the inter-service boundary. |
| LanceDB corpus to prompt/provider | Retrieved document text is untrusted data crossing into a model prompt. |
| Rust to OpenRouter | A configured bearer credential and bounded structured request cross to an external provider. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01-01 | Tampering | Query filters and LanceDB predicates | high | mitigate | Validate UUID/content-type values and construct typed pre-filters before both candidate paths; never accept arbitrary predicate text. |
| T-03-01-02 | Tampering | Retrieved evidence prompt | high | mitigate | Assign engine-owned evidence IDs, isolate each block, escape delimiter-like text, and label corpus content as untrusted data. |
| T-03-01-03 | Denial of Service | HTTP query, filters, evidence, and model context | high | mitigate | Enforce query/filter/body/candidate/final/evidence/output budgets and reserve the answer budget before packing evidence. |
| T-03-01-04 | Information Disclosure | OpenRouter request and logs | high | mitigate | Load the API key from environment/configuration, use HTTPS through reqwest, and exclude credentials, raw prompts, and raw corpus text from logs. |
| T-03-01-05 | Spoofing | Session and citation identity | medium | mitigate | Validate UUIDv4 sessions, generate missing IDs in Rust, and validate every returned citation ID against the closed evidence map. |
| T-03-01-06 | Tampering | Generated protobuf contract | medium | mitigate | Preserve field numbers, regenerate both languages from Buf, and compile/test both boundary implementations. |
| T-03-01-SC | Tampering | Cargo dependency installation | high | mitigate | Use only the three packages covered by the approved Package Legitimacy Audit, preserve locked versions, and verify with Cargo lock/check commands. |
</threat_model>

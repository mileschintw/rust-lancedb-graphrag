<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Client to Go gateway | Untrusted JSON query, session, filters, and body bytes enter the public route. |
| Go gateway to Rust tonic service | Generated contract fields and status codes cross the runtime boundary. |
| LanceDB/BM25 corpus to prompt/provider | Retrieved source text crosses into a model prompt as untrusted evidence. |
| Rust to OpenRouter | A configured bearer credential and bounded structured request cross to an external provider. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01-01 | Tampering | Query filters and LanceDB predicates | high | mitigate | Validate UUID/content-type values and construct typed filters before both candidate paths; never accept arbitrary predicate text. |
| T-03-01-02 | Tampering | Retrieved evidence prompt | high | mitigate | Use engine-owned evidence IDs, isolated blocks, escaped delimiter-like text, and explicit untrusted-data framing. |
| T-03-01-03 | Denial of Service | Query, evidence, and provider context | high | mitigate | Enforce query/filter/candidate/final/evidence/output budgets and reserve the answer budget before evidence packing. |
| T-03-01-04 | Information Disclosure | OpenRouter request and diagnostics | high | mitigate | Keep the key in environment/configuration and exclude credentials, raw prompts, and raw corpus text from logs and provider errors. |
| T-03-01-05 | Spoofing | Session and citation identity | medium | mitigate | Validate UUIDv4 sessions, generate missing IDs in Rust, and resolve numbered markers only against the closed engine evidence map. |
| T-03-01-06 | Tampering | Generated protobuf contract | medium | mitigate | Preserve field numbers, regenerate all bindings with Buf, and compile/test both language boundaries. |
</threat_model>

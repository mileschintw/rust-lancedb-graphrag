<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Rust prompt to OpenRouter | Untrusted retrieved evidence and the user question enter an external model request. |
| Provider response to Rust validator | External structured JSON becomes answer, basis, notices, and citation IDs. |
| HTTP JSON body to Go handler | Caller-controlled bytes and fields enter the public route. |
| Go response mapping to client | Generated protobuf metadata becomes public JSON and must remain intact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-03-01 | Tampering | OpenRouter structured response | high | mitigate | Use closed Serde output, semantic answer/basis checks, and evidence-map marker validation before public assembly. |
| T-03-03-02 | Spoofing | Citation/evidence identity | high | mitigate | Accept only engine-issued IDs and rebuild citation fields from bounded supplied evidence. |
| T-03-03-03 | Tampering | OpenRouter prompt boundary | high | mitigate | Separate system policy from question/evidence, escape delimiter-like text, and expose no tools or streaming controls. |
| T-03-03-04 | Denial of Service | Gateway body and query envelope | medium | mitigate | Bound body/query/filter sizes, reject unknown/trailing JSON, and keep deadlines bounded. |
| T-03-03-05 | Information Disclosure | Provider credentials and diagnostics | high | mitigate | Keep bearer credentials in environment configuration and redact credentials, raw prompts, raw evidence, and response bodies. |
| T-03-03-06 | Repudiation | Provider/API capability decisions | low | mitigate | Keep COVERAGE.md synchronized with the concrete adapter and require the API coverage gate. |
</threat_model>

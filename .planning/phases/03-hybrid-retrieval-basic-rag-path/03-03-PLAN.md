<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Protobuf caller to Rust service | Untrusted query/session/filter fields cross the generated gRPC boundary. |
| LanceDB completed corpus to query-ready service | Canonical rows become the combined dense/BM25 state used by every query. |
| Configuration/environment to provider | Endpoint/model/budget settings select provider behavior; secrets remain external. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-03-01 | Tampering | Additive protobuf contract | medium | mitigate | Preserve existing field numbers, regenerate all outputs with Buf, and compile both language bindings. |
| T-03-03-02 | Tampering | Rust QueryRAG input and typed predicates | high | mitigate | Validate query/session/filter bounds before retrieval and construct typed filters rather than interpolated predicates. |
| T-03-03-03 | Tampering | Cross-index readiness | high | mitigate | Build the initial BM25 snapshot from the canonical completed corpus before service registration/readiness and fail clearly on build errors. |
| T-03-03-04 | Information Disclosure | Provider configuration | high | mitigate | Keep credentials in environment variables, commit only non-secret endpoint/model defaults, and redact provider diagnostics. |
| T-03-03-05 | Denial of Service | Query and generation budgets | medium | mitigate | Enforce the configured UTF-8, filter, candidate, evidence, output, and timeout bounds before provider work. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Rust prompt to OpenRouter | Untrusted retrieved evidence and user question enter an external model request. |
| OpenRouter response to Rust validator | External structured JSON becomes candidate answer, citations, and notices. |
| HTTP JSON body to Go handler | Caller-controlled bytes and fields enter the public gateway route. |
| Go response mapping to client | Generated protobuf fields become public JSON and must not lose integrity metadata. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-03-01 | Tampering | OpenRouter structured response | high | mitigate | Use a closed Serde schema, semantic answer/basis checks, and evidence-map validation before public assembly. |
| T-03-03-02 | Spoofing | Citation and evidence identity | high | mitigate | Accept only engine-issued IDs and rebuild bounded citation fields from supplied evidence rather than trusting model-provided source text. |
| T-03-03-03 | Tampering | OpenRouter prompt boundary | high | mitigate | Separate system policy from question/evidence, escape delimiter-like text, and expose no tools or streaming controls. |
| T-03-03-04 | Denial of Service | Gateway body and query envelope | medium | mitigate | Bound body/query/filter sizes, reject unknown/trailing JSON, and keep middleware/request/provider deadlines bounded. |
| T-03-03-05 | Information Disclosure | Provider credentials and diagnostics | high | mitigate | Keep bearer credentials in environment configuration and redact credentials, raw prompt, raw evidence, and response bodies from errors/logs. |
| T-03-03-06 | Repudiation | Provider/API capability decisions | low | mitigate | Keep the checked-in COVERAGE.md matrix synchronized with the concrete adapter and require the API-coverage gate to pass. |
| T-03-03-SC | Tampering | Cargo dependency installation | high | mitigate | This plan adds no un-audited package; retain the Phase 03 Package Legitimacy Audit and locked Cargo verification from Plan 03-01. |
</threat_model>

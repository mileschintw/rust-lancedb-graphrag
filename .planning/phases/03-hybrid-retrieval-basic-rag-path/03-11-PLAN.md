## Phase Goal

**As a** chat service API user, **I want to** ask a question over indexed content and receive a grounded answer with trustworthy citations, **so that** I can verify every claim against the retrieved evidence.

<objective>
Complete the effective-configuration closure by wiring Plans 03-07 and 03-10 into production startup and proving both configured query behavior and the D-40 initial readiness guard.

Purpose: Validated settings and provider constructors matter only when the production service uses them, and readiness must describe the same queryable state.
Output: Production startup wiring, recording-provider integration evidence, corrected process-level failure fixtures, and a binary-target-validated operator configuration example.
</objective>

<scope_note>
This plan proves the initial Phase 03 query-ready build only. D-41 atomic re-ingestion and D-42/D-43 restart rebuild guarantees remain deferred. No protobuf, storage schema, package dependency, or public API surface changes.
</scope_note>

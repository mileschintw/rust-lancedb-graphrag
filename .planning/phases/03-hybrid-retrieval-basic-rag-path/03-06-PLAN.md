## Phase Goal

**As a** chat service API user, **I want to** ask a question over indexed content and receive a grounded answer with trustworthy citations, **so that** I can verify every claim against the retrieved evidence.

<objective>
Close the prompt and provider grounding-integrity blockers in the RAG-02 query path with one fail-closed evidence-to-validated-output path per D-17, D-22, D-23, D-28, D-29, D-31, and D-35 through D-39.

Purpose: A successful generation result must prove that the model saw bounded, unambiguous evidence and returned a complete, identity-valid structured answer.
Output: Hardened prompt/provider contracts and focused regressions integrated into query_rag.
</objective>

<scope_note>
This plan owns prompt packing and provider validation. Identity-correct public citation projection and diagnostic severity are the dependent `03-09` slice. D-24 repair-and-retry behavior, RAG-03, degraded retrieval, non-finite embedding recovery, and accepted deferred debt remain outside this gap closure. The internal changes are reversible and require neither protobuf nor persisted-schema changes.
</scope_note>

<spec_edge_resolution>
No Phase 03 SPEC exists. The unresolved edge is resolved concretely: corpus-controlled fields cross one structured encoder; a request fails closed when no complete evidence block fits; excerpts use character counts; output must be complete and strictly schema-valid; cited IDs and inline markers must be the same unique known set; invalid output is rejected without repair.
</spec_edge_resolution>

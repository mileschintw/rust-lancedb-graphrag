## Phase Goal

**As a** chat service API user, **I want to** ask a question over indexed content and receive a grounded answer with trustworthy citations, **so that** I can verify every claim against the retrieved evidence.

<objective>
Close the final RAG-02/RAG-04 integration blockers by wiring the existing NoOpReranker port into production query_rag and making zero retrieval weights disable their sources without disturbing deterministic RRF.

Purpose: Final model evidence must reflect configured retrieval sources and the required post-fusion reranker seam, with stable identities for grounded citations.
Output: Reranker injection/invocation, zero-weight exclusion, focused regressions, and phase-wide quality gates.
</objective>

<scope_note>
D-05 supplies the NoOpReranker pass-through port in Phase 03 while learned reranking remains Phase 999.2. This plan wires and proves that existing pass-through seam only. Changes are reversible internal orchestration/ranking behavior; protobuf and persisted schemas remain unchanged.
</scope_note>

<spec_edge_resolution>
No Phase 03 SPEC exists. The final integration edge is resolved concretely: reranking receives the complete fused candidate pool once, NoOp preserves its order, final_context_limit applies afterward, and only those evidence IDs enter prompt/citation validation. A weight of exactly zero disables that source entirely; a positive weight retains existing RRF math and tie-breaking.
</spec_edge_resolution>

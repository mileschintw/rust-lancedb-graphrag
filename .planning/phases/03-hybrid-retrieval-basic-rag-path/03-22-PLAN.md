<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Dense/BM25 candidates -> Rust fusion | Candidate identifiers and scores can be duplicated or non-finite before ranking. |
| Rust fused response -> gRPC/Go gateway | A corrupt score must fail closed rather than become a successful public payload. |
| Go DTO -> HTTP ResponseWriter | JSON encoding can fail after validation, before bytes are safe to commit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-22-01 | Tampering | RRF source contributions | high | mitigate | Validate every source score, deduplicate each source by chunk_id before rank enumeration, and reject non-finite contribution or accumulator values with NonFiniteScore. |
| T-03-22-02 | Denial of Service | duplicate candidate lists | high | mitigate | Apply the already validated candidate ceiling and per-source deduplication before contribution and result construction. |
| T-03-22-03 | Integrity | gateway writeJSON | high | mitigate | Encode to bytes.Buffer before WriteHeader; return HTTP 500 on encoder failure and test math.NaN(). |
| T-03-22-SC | Tampering | package-manager installs | low | accept | No package-manager install or dependency change is part of this plan; the locked repository dependencies are reused. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| OpenRouter or test provider -> reqwest response stream | An external body can be chunked, omit Content-Length, or exceed the service limit. |
| Limited bytes -> serde_json provider wrapper | Only bounded bytes may become provider metadata, usage, answer, or embedding allocations. |
| Provider error -> public engine contract | Read and limit failures must not become partial successful output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-20-01 | Denial of Service | provider response stream | high | mitigate | Check Content-Length early, stream with a hard 262144-byte ceiling, reject at 262145, and never retain more than the ceiling. |
| T-03-20-02 | Tampering | model metadata capability response | high | mitigate | Parse metadata only after the shared limit succeeds; over-limit metadata cannot authorize structured output. |
| T-03-20-03 | Denial of Service | embedding response deserialization | high | mitigate | Apply the same reader before EmbeddingResponse parsing and return a permanent fail-closed error on TooLarge or Read. |
| T-03-20-SC | Tampering | package-manager installs | low | accept | No package-manager install or dependency change is part of this plan; the locked repository dependencies are reused. |
</threat_model>

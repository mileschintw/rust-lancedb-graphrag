<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| embedding provider -> Rust query service | Provider transport and vector payload are untrusted external inputs. |
| LanceDB dense query -> Rust query service | Storage/query execution can fail or return malformed rows at the data-plane boundary. |
| Rust tonic error -> Go HTTP gateway | Status metadata crosses a service boundary and is copied into public response headers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-17-01 | Tampering | embedding vector validation | critical | mitigate | Reject transport errors and every empty, multi-vector, wrong-dimension, or non-finite payload before dense search; never fabricate a substitute vector. |
| T-03-17-02 | Denial of Service | DenseRetriever error path | high | mitigate | Propagate snapshot failures immediately, skip generation, and return bounded status text rather than continuing with weakened evidence. |
| T-03-17-03 | Information Disclosure | error identity metadata and logs | medium | accept | ADR-03-002 D1-LOG accepts the existing detailed infrastructure message for Phase 03; retain session/correlation/error-kind identity and fail-closed behavior, avoid adding raw provider payload fields or credentials, and track identity-only structured logging for Phase 06. |
| T-03-17-SC | Tampering | package-manager installs | low | accept | No package-manager install or dependency change is part of this plan; existing locked dependencies are reused. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| HTTP caller to Go gateway | Untrusted JSON bytes and filter/session values enter the public route. |
| Go gateway to Rust gRPC | Generated request/response fields and status codes cross the runtime boundary. |
| Rust embedding client to configured endpoint | Query text and a bearer credential cross to OpenRouter or the local test server. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-04-01 | Tampering | JSON request envelope | high | mitigate | Bound the body, reject unknown/trailing fields, normalize typed values, and let Rust remain authoritative for semantic validation. |
| T-03-04-02 | Spoofing | Session and response citation identity | medium | mitigate | Forward caller session values unchanged for Rust validation and map only engine-supplied effective IDs/citations. |
| T-03-04-03 | Information Disclosure | Embedding credential and endpoint errors | high | mitigate | Keep keys in environment configuration, preserve redacted client errors, and use localhost only through an explicit test endpoint setting. |
| T-03-04-04 | Denial of Service | HTTP body/query and embedding request | medium | mitigate | Enforce HTTP/body/query bounds and retain the existing client timeout, concurrency, and retry limits. |
| T-03-04-05 | Tampering | Go/Rust contract evolution | medium | mitigate | Use generated bindings from the additive proto and test exact field/status mapping. |
</threat_model>
